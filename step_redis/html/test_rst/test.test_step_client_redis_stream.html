test.test_step_client_redis_stream module

Unit tests for the StepClientRedisStream class.

This module provides comprehensive test coverage for the StepClientRedisStream class, which extends StepRedisStream to provide specialized functionality for publishing and receiving client messages in CloudEvents format via Redis Streams.

The test suite validates:

  • Class initialization and configuration with Redis pool and stream parameters

  • Asynchronous context manager protocol (__aenter__)

  • Publishing DENM (Decentralized Environmental Notification Message) data wrapped in CloudEvents format

  • Receiving and deserializing client messages from Redis Streams

  • Proper interaction with parent class methods and external dependencies

All tests utilize mocking to isolate the unit under test from external dependencies such as Redis connections, parent class implementations, and CloudEvents schemas.

Test Class:

TestStepClientRedisStream: Contains all unit tests for StepClientRedisStream.

Dependencies:

  • pytest: Testing framework

  • pytest-mock: Mocking utilities for pytest

  • step_cloud_schemas: CloudEvents schema definitions

  • step_redis: Redis Stream components and StepClientRedisStream implementation

See also

  • step_redis.StepClientRedisStream: The class being tested

  • step_redis.StepRedisStream: Parent class providing base Redis Stream functionality
