STEP Monitoring Schema

Overview

The monitoring message system provides a mechanism for stages in the pipeline to emit real-time data that can be observed and analyzed without affecting the primary data flow. These messages enable system operators and developers to track the behavior and performance of various processing stages.

Current Usage

As of now, the monitoring system is primarily utilized for transmitting trajectory data. This use case allows for real-time observation of vehicle trajectories as they are being processed through the system, enabling:

  • Real-time visualization of vehicle paths

  • Validation of trajectory predictions and forecasting

  • Performance monitoring of trajectory processing stages

  • Debugging and analysis of trajectory-related algorithms

The monitoring messages containing trajectory data are published to dedicated channels where they can be consumed by monitoring applications, visualization tools, or logging systems without impacting the main processing pipeline.

The version of JSON schema are the following:

  "time": "2018-04-05T17:31:00.000Z",
  "type": "trajectory_forecasted",
  "dataschema": "trajectory_forecasted_v1_schema",
  "data": [
    {
      "stationId": 25648,
      "objectId": 123,
      "stationType": "passengerCar",
      "stationTypeConfidence": 90,
      "referenceTime": "2018-04-05T17:31:00.000Z",
      "firstPositionType": "GNSS",
      "points": [
        {
          "diffTime": 100,
