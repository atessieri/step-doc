STEP Crash Prediction Schema

The STEP Crash Prediction schema defines the structure for messages incoming of STEP Adapter subsystem. The schema consists of 2 main parts:

  • Header: contains the metadata of the message like:

    • event id

    • source of the event

    • type of the event

    • time

    • data content type

    • name of the data field schema

  • Data: contains the data of the message. This version includes:

    • Position Array: contains the position of the vehicle in the WGS84.

This schema defines a JSON Schema version 1. For further information, please refer to the python classes.

Example of the message:

{
  "id": "56c5ecec-00ef-4a27-a5a0-bcb85a7378c1",
  "source": "adapter_1",
  "specversion": "1.0",
  "datacontenttype": "application/json",
  "time": "2018-04-05T17:31:00.000Z",
  "type": "position_array",
  "dataschema": "position_array_v1_schema",
  "data": {
    "sampleFrequency": 10,
    "vehicleLength": {
      "vehicleLengthValue": 12.3,
      "vehicleLengthConfidenceIndication": "noTrailerPresent"
    },
    "vehicleWidth": 16.0,
    "points": [
      {
        "stationInfo": {
          "stationId": 1236,
          "stationType": "passengerCar"
        },
        "objectId": 123,
        "positionType": "GNSS",
        "time": "2018-04-05T17:31:00.000Z",
        "position": {
          "latitude": 45.587878,
          "longitude": 60.458789,
          "positionConfidence": {
            "semiMajorAxisLengthConfidence": 1.23,
            "semiMinorAxisLengthConfidence": 1.23,
            "semiMajorAxisOrientation": 1.0
          },
          "altitude": {
            "value": 120.0,
            "confidence": 1.0
          }
        },
        "speed": {
          "value": 123.67,
          "confidence": 0.5
        },
        "heading": {
          "value": 12.3,
          "confidence": 5.0
        },
        "driveDirection": "forward"
      }
    ]
  }
}
