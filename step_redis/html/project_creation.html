Project Creation in GitLab

The following instructions will guide you through the process of creating a new project in GitLab and configuring it for use with CI/CD pipelines.

Follow the instructions to create the repository:

  1. Create a new project in GitLab in the group vfa-init/pnrr

  2. In the project settings, navigate to CI/CD settings -> Job token permissions and set the appropriate permissions for the job token:

    • Current project:

      • Read to Jobs

      • Read and write to Packages

    • vfa-init/pnrr group:

      • Read to Packages

  3. Navigate to CI/CD Settings -> Artifacts and disable the option Keep artifacts from most recent successful jobs to ensure that all generated artifacts are retained for future reference and analysis.

  4. Navigate to CI/CD Settings -> Variables, add the variable STEP_DOC_TOKEN with:

    • visibility: masked

    • value: project STEP_DOC token with write_repository scope
