step_redis.step_crash_prediction_redis_stream module

STEP Crash Prediction Redis Stream Integration.

This module provides the StepCrashPredictionRedisStream class, which enables real-time message streaming and Crash Prediction data processing using Redis Streams within the STEP framework.

Key Features:

  • Async context manager support for resource management

  • CloudEvents-compliant message formatting and validation

  • Automatic stream TTL management based on configuration

  • Consumer group management for reliable message processing

  • Position array data publishing to Crash Prediction streams

  • Integrated logging for operations

Note

This module is optimized for high-throughput, real-time processing scenarios.

Complexity:

  • - Time – Setup operations (__init__, __aenter__) run in O(1). Publishing (publish_position_array) runs in O(n), where n is the serialized position array size, dominated by CloudEvents JSON serialization and the Redis XADD round-trip. Receiving (receive_crash_prediction_message) runs in O(m) per yielded message, where m is the received JSON payload size, dominated by JSON parsing and Pydantic validation.

  • - Space – O(1) for setup operations. O(n) per publish call and O(m) per received message, bounded by the size of the single message being serialized or parsed at a time; no message history is retained in memory.

class step_redis.step_crash_prediction_redis_stream.StepCrashPredictionRedisStream(pool: StepRedisPool, config: StepRedisStreamParams, logger: Logger)[source]

Bases: StepRedisStream

Redis stream handler for STEP Crash Prediction messages.

Extends StepRedisStream to provide specialized methods for:

  • Publishing position array data as CloudEvents to the Crash Prediction stream

  • Receiving and validating Crash Prediction CloudEvents messages from the stream

  • Managing stream TTL, consumer groups, and logging

Usage:

Use as an async context manager. Call publish_position_array to send data, and receive_crash_prediction_message to consume messages.

Publishes a position array message to the Crash Prediction stream.

Creates a CloudEvents-compliant message containing the position array data and publishes it to the configured Crash Prediction Redis stream.

Parameters:

position_array (PositionArrayV1) – The position array data to be published.

Returns:

None

Complexity:

  • - Time – O(n), where n is the size (field count/byte length) of the position array; dominated by CloudEvents JSON serialization plus the network round-trip of the underlying Redis XADD call.

  • - Space – O(n), for the serialized JSON payload held in memory before being sent to Redis.

async receive_crash_prediction_message() → AsyncGenerator[CrashPredictionCloudEventsJsonRoot][source]

Async generator that yields Crash Prediction messages from the Redis stream.

Iterates over messages received from the Redis stream, logs each message, and parses it into a CrashPredictionCloudEventsJsonRoot object using strict validation.

A message that fails Pydantic validation is logged and discarded; it is not yielded and does not stop iteration.

Yields:

CrashPredictionCloudEventsJsonRoot – Parsed and validated Crash Prediction CloudEvents message.

Returns:

None

Complexity:

  • - Time – O(m) per yielded message, where m is the byte length of the received JSON payload; dominated by JSON parsing and Pydantic validation (the generator itself runs indefinitely).

  • - Space – O(m) per yielded message, for the parsed CrashPredictionCloudEventsJsonRoot object held in memory.
