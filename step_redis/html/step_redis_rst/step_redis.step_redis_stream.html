step_redis.step_redis_stream module

Asynchronous Redis Stream interface for message processing with consumer groups.

This module provides the StepRedisStream class and RedisStreamConfiguration dataclass for working with Redis Streams in an asynchronous context. It supports:

  • Creating and managing Redis streams and consumer groups

  • Publishing messages with configurable maximum stream length

  • Consuming messages with automatic acknowledgment

  • Managing stream TTL (Time-To-Live)

  • Connection health monitoring via ping

The StepRedisStream class is designed to be used as an async context manager. It requires a StepRedisPool, a RedisStreamConfiguration, and a Logger.

Example

>>> import asyncio
... import logging
... from step_redis.step_redis_pool import StepRedisPool
... from step_redis.step_redis_stream import (
...     StepRedisStream,
...     RedisStreamConfiguration,
... )
...
...
... async def main():
...     logger = logging.getLogger("redis_example")
...     pool = StepRedisPool(host="localhost", port=6379, db=0)
...     config = RedisStreamConfiguration(
...         stream_id="my_stream",
...         group_id="my_group",
...         wait_timeout_ms=5000,
...         max_length=1000,
...         consumer_name="consumer1",
...         ttl_seconds=3600,
...     )
...     async with StepRedisStream(pool, config, logger) as stream:
...         await stream.create_input_stream("my_stream")
...         await stream.publish_message("Hello, Redis!")
...         message = await stream.receive_message(5000)
...         print(f"Received: {message}")
...
...
... asyncio.run(main())

async get_stream_ttl() → int[source]

Get the remaining Time-To-Live (TTL) in seconds for the configured Redis stream.

This method retrieves the TTL for the stream specified in the configuration. It uses the Redis TTL command, which returns the remaining time to live for a key in seconds.

Returns:

The number of seconds until the stream expires. Returns -2 if the stream does not exist. Returns -1 if the stream exists but has no expiration set.

Return type:

int

Note

A return value of -2 indicates the stream does not exist. A return value of -1 indicates the stream exists but has no associated expiration.

Publish a message to the configured Redis stream.

This method publishes a message to the Redis stream specified in the configuration. The message is stored as a field named ‘payload’ in the stream entry. The stream is trimmed to the maximum length specified in the configuration using approximate trimming for performance.

async receive_message(block_timeout: int) → str[source]

Receive a message from the configured Redis stream using consumer groups.

This method continuously attempts to read a message from the Redis stream using the configured consumer group and consumer name. It blocks for the specified timeout (in milliseconds) on each attempt. If a message is received, its payload is returned. If a TTL is configured, the stream’s TTL is updated after each attempt.

Parameters:

block_timeout (int) – Maximum time in milliseconds to block waiting for a message.

Returns:

The payload of the received message.

Return type:

str

Note

This method uses noack=True, so messages are automatically acknowledged upon delivery and not added to the pending entries list.

async update_stream_ttl(ttl_seconds: int) → bool[source]

Update the Time-To-Live (TTL) expiration for the configured Redis stream.

This method updates the TTL expiration for the Redis stream specified in the configuration. It uses the Redis EXPIRE command to set or replace the TTL for the stream. If the TTL is successfully updated, it returns True. If the stream does not exist or the TTL could not be set, it returns False.

Parameters:

ttl_seconds (int) – The number of seconds until the stream should expire. Must be a positive integer.

Returns:

True if the TTL was successfully updated, False otherwise.

Return type:

bool
