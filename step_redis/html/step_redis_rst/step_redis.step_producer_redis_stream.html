step_redis.step_producer_redis_stream module

STEP Producer Redis Stream Module.

This module provides the StepProducerRedisStream class, a specialized Redis stream implementation for STEP (Safer Transport for Europe Platform) Producer services.

Key Features:

  • Publishes DENM (Decentralized Environmental Notification Message) and station collision array messages in CloudEvents format to Redis streams.

  • Receives and validates producer messages from Redis streams.

  • Supports asynchronous context management for efficient resource handling.

  • Integrates with step_cloud_schemas for message structures and step_redis for Redis operations.

Usage Example:
>>> async with StepProducerRedisStream(pool, config, logger) as stream:
...     await stream.publish_denm_message(denm_data)
...     await stream.publish_station_collision_array(station_collision_array)
...     message = await stream.receive_producer_message()
