Redis Usage Guide

Introduction

The STEP (Safer Transport for Europe Platform) Library provides robust Redis integration through the step_redis module. This module offers asynchronous Redis interaction capabilities specifically designed for the STEP Framework, including connection pooling, SSL/TLS support, and efficient stream management.

This guide explains how to use the Redis components in the STEP Library, with examples based on actual implementation patterns.

Key Components

The step_redis module provides three main components:

  1. StepRedisPoolParams: A dataclass containing all connection parameters for Redis, including host, port, authentication details, SSL settings, and connection parameters.

  2. StepRedisPool: An enhanced blocking connection pool with asynchronous context management, supporting both SSL and non-SSL connections.

  3. StepRedisStreamParams: A dataclass containing all stream configuration parameters, including stream ID, group ID, consumer name, timeouts, and TTL settings.

  4. StepRedisStream: A Redis Streams interface for publish/subscribe patterns, providing methods for creating streams, publishing messages, and consuming messages.

Basic Usage

General Pattern

The typical usage pattern involves:

  1. Configure Redis connection parameters using StepRedisPoolParams

  2. Configure Redis stream settings using StepRedisStreamParams

  3. Create a connection pool with StepRedisPool

  4. Initialize a stream interface with StepRedisStream

  5. Use asynchronous context managers for proper resource management

import asyncio
from logging import getLogger
from step_redis import StepRedisPoolParams, StepRedisPool, StepRedisStream, StepRedisStreamParams

async def main():
    logger = getLogger()

    # 1. Configure connection parameters
    redis_params = StepRedisPoolParams(
        host="redis.example.com",
        port=6379,
        username="user",  # Optional
        password="secret",
        db=0,
        socket_timeout=30,
        socket_connect_timeout=30,
        socket_keep_idle=30,
        socket_keep_alive=30,
        socket_keep_cnt=5,
        ssl_enable=True,
        ssl_client_key_file="/path/to/key.pem",  # Optional
        ssl_client_key_file_password=None,  # Optional
        ssl_client_cert_file="/path/to/cert.pem",  # Optional
        ssl_cert_requested=False,
        ssl_ca_certs_file="/path/to/ca.pem",  # Optional
        health_check_interval=20,
        max_connections=10,
        connection_available_timeout=2,
        protocol=3,
    )

    # 2. Configure stream parameters
    stream_params = StepRedisStreamParams(
        stream_id="demo_stream",
        group_id="demo_group",
        wait_timeout_ms=30000,
        max_length=1000,
        consumer_name="demo_consumer_1",
        ttl_seconds=60,
    )

    # 3. Create and use connection pool as context manager
    async with StepRedisPool(params=redis_params, logger=logger) as pool:
        # 4. Create a stream interface
        async with StepRedisStream(pool=pool, config=stream_params, logger=logger) as stream:
            # 5. Create a stream and consumer group
            await stream.create_input_stream()

            # 6. Publish a message
            await stream.publish_message(message="Hello, Redis!")

            # 7. Receive a message
            message = await stream.receive_message(block_timeout=30000)
            logger.info("Received message: %s", message)

if __name__ == "__main__":
    asyncio.run(main())

Advanced Usage: Stream Demo Example

The step_redis module includes a comprehensive demonstration example in the stream_demo package. This example showcases how to use the Redis components with STEP Cloud Schemas for ITS (Intelligent Transport Systems) applications, specifically for handling DENM (Decentralized Environmental Notification Message) data.

Stream Demo Components

The example uses the following key components:

  1. StepRedisPoolParams: Configuration for Redis connection

  2. StepRedisStreamParams: Configuration for stream operations

  3. StepClientRedisStream: A specialized stream implementation for STEP client applications

  4. DenmDataV1: ITS message format from step_cloud_schemas

Let’s look at how these components are used:

# Standard Library Imports
import asyncio
from logging import getLogger

# Third Party Imports
from step_cloud_schemas import DenmDataV1

# step_redis Package Imports
from step_redis import (
    StepRedisPool,
    StepRedisPoolParams,
    StepRedisStreamParams,
)
from step_redis.step_client_redis_stream import StepClientRedisStream

# Create Redis connection parameters
def create_redis_params() -> StepRedisPoolParams:
    """Create Redis connection parameters for demonstration."""
    return StepRedisPoolParams(
        host="redis-demo.example.com",
        port=6379,
        username="default",
        password="your-password",
        db=0,
        socket_timeout=30,
        socket_connect_timeout=30,
        socket_keep_idle=30,
        socket_keep_alive=30,
        socket_keep_cnt=5,
        ssl_enable=False,
        ssl_client_key_file=None,
        ssl_client_key_file_password=None,
        ssl_client_cert_file=None,
        ssl_cert_requested=False,
        ssl_ca_certs_file=None,
        health_check_interval=20,
        max_connections=2,
        connection_available_timeout=2,
        protocol=3,
    )

# Create Redis stream parameters
def create_stream_params() -> StepRedisStreamParams:
    """Create Redis stream parameters for demonstration."""
    return StepRedisStreamParams(
        stream_id="demo_stream",
        group_id="demo_group",
        wait_timeout_ms=30000,
        max_length=1000,
        consumer_name="demo_consumer_1",
        ttl_seconds=60,
    )

# Main demonstration function
async def main():
    """Main function demonstrating Redis stream usage."""
    logger = getLogger()

    # Create connection pool and stream interface
    async with StepRedisPool(
        params=create_redis_params(), logger=logger
    ) as redis_pool:
        async with StepClientRedisStream(
            pool=redis_pool,
            config=create_stream_params(),
            logger=logger
        ) as stream:
            # Create the input stream and consumer group
            await stream.create_input_stream()

            # Publish a DENM message
            await stream.publish_denm_message(
                message=DenmDataV1.get_default()
            )

            # Receive a message
            msg = await stream.receive_client_message()
            logger.info("Received message: %s", msg)

Running the Demo Application

The demo package also includes a complete runnable application that demonstrates a continuous loop of publishing and consuming messages. Here’s an excerpt from the main implementation:

# Additional imports for the demo
from asyncio import get_event_loop
from logging import Logger
from step_cloud_schemas import DenmDataV1

async def main_async(logger: Logger) -> None:
    """Main async function for the Redis stream demo."""

    # Set up exception handling for the event loop
    get_event_loop().set_exception_handler(
        handler=lambda _, context: exception_handler(context=context, logger=logger)
    )

    # Use async context managers for proper resource management
    async with (
        StepRedisPool(
            params=create_redis_params(), logger=logger
        ) as redis_pool,
        StepClientRedisStream(
            pool=redis_pool, config=create_stream_params(), logger=logger
        ) as stream,
    ):
        logger.info("Stream input connection established")

        # Create the input stream and consumer group
        await stream.create_input_stream()

        # Publish a DENM message
        await stream.publish_denm_message(message=DenmDataV1.get_default())

        # Receive and log the message
        msg = await stream.receive_client_message()
        logger.info("Received message: %s", msg)

# Run the demo
if __name__ == "__main__":
    asyncio.run(main_async(logger=getLogger()))

  1. Proper signal handling for clean shutdown

  2. Comprehensive error handling

  3. Efficient resource management with async context managers

  4. Stream TTL management for automatic cleanup

  5. Consumer group pattern for reliable message delivery

  6. CloudEvents-compliant ITS message formatting

  7. Publishing and consuming DENM messages

Best Practices

  1. Use Context Managers: Always use async context managers with Redis pools and streams to ensure proper resource cleanup.

  2. Configure Timeouts: Set appropriate socket and connection timeouts based on your network environment.

  3. Enable SSL for Production: In production environments, enable SSL/TLS encryption for secure Redis connections.

  4. Limit Pool Size: Set reasonable max_connections value to avoid exhausting system resources.

  5. Handle Errors: Implement proper error handling for common Redis exceptions, especially for network-related issues.

  6. Monitor Health: Use the health_check_interval parameter to ensure connections remain healthy.

  7. Use Configuration Dataclasses: Use StepRedisPoolParams and StepRedisStreamParams to organize connection and stream settings.

  8. Implement Ping: Periodically use the ping() method to verify Redis connectivity.

  9. Manage Stream TTL: Set appropriate TTL values to ensure automatic cleanup of streams.
