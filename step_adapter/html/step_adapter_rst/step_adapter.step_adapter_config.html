step_adapter.step_adapter_config module

Pydantic configuration models of the STEP Adapter program.

Defines the configuration that step_adapter.__main__ loads from the JSON file given with -c/–config: the root StepAdapterConfig (actor history size, input period, time and CPM span limits, output sampling, cleaner and reconnect intervals), its Redis section RedisClientConfig (step_redis RedisConnection plus the RedisStreams input and crash prediction output streams; the host, port and credentials come from the environment through RedisCredential) and its logging section (step_cloud_schemas LogConfig).

Every model is strict, frozen (immutable) and forbids extra fields; numeric and string fields carry range/length constraints, and RedisClientConfig also checks that the socket timeout outlasts the blocking stream read. The module writes the configuration JSON schema (StepAdapterConfig.print_config_schema, with $id and $schema set by make_schema_generator) and a default configuration template (StepAdapterConfig.print_config_example). The format version is StepConfigVersion.VERSION.

Data hierarchy:

StepAdapterConfig
|-- redis                       (RedisClientConfig)
|   |-- connection              (RedisConnection)
|   `-- streams                 (RedisStreams)
|       |-- outputs             (RedisStreamOutputs)
|       |   `-- crashPrediction (RedisStreamOutput)
|       `-- input               (RedisStreamInput)
`-- log                         (LogConfig)
Complexity:

  • - Time – O(s), dominated by StepAdapterConfig.print_config_schema, s = size of the generated JSON schema; validation and the defaults are O(1).

  • - Space – O(s), dominated by StepAdapterConfig.print_config_schema.

Classes:

  • StepConfigVersion: Version of the configuration format. Complexity: time O(1), space O(1).

  • RedisStreamOutput: Configuration of one Redis output stream. Complexity: time O(1), space O(1).

  • RedisStreamOutputs: Configuration of the Redis output streams (crash prediction). Complexity: time O(1), space O(1).

  • RedisStreamInput: Configuration of the Redis input stream and consumer group. Complexity: time O(1), space O(1).

  • RedisStreams: Input and output streams configuration. Complexity: time O(1), space O(1).

  • RedisClientConfig: Redis connection and streams configuration, with the socket timeout check. Complexity: time O(1), space O(1).

  • NominalSampleFrequency: Allowed output sample frequencies in Hz. Complexity: time O(1), space O(1).

  • StepAdapterConfig: Root configuration of the STEP Adapter. Complexity: time O(s), space O(s).

class step_adapter.step_adapter_config.RedisClientConfig(*, connection: RedisConnection, streams: RedisStreams)

Bases: BaseModel

Configuration class for Redis client settings.

This class defines the configuration schema for the Redis client, including connection parameters and stream settings. It uses Pydantic for validation and schema definition.

connection

step_redis connection settings; the host, port and credentials come from the environment (RedisCredential).

Type:

RedisConnection

streams

Configuration for Redis streams used by the client: the input stream with its consumer group and wait timeout, and the crash prediction output stream.

Type:

RedisStreams

Note

connection.socketTimeout must exceed streams.input.waitTimeout by at least RedisConnection.READ_TIMEOUT_MARGIN_MS (checked by step_redis RedisConnection.check_read_timeout): the blocking XREADGROUP read is bounded by the socket timeout, and a read that times out first drops the connection and loses any message the server delivered in that instant (the input stream is read with noack).

Complexity:

  • - Time – O(1), validation, _read_timeout_check and get_default handle a fixed number of fields.

  • - Space – O(1), two nested configurations are stored.
