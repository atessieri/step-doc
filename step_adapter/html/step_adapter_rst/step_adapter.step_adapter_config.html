step_adapter.step_adapter_config module

STEP Adapter Configuration Module.

This module provides comprehensive configuration models for the STEP (Safer Transport for Europe Platform) Adapter component using Pydantic for data validation and schema generation.

The module defines a hierarchical configuration structure that encompasses all aspects of the STEP Adapter’s operation, including Redis connectivity, stream processing, logging, and operational parameters.

Key Configuration Areas:

  • Redis Connection: Database connectivity with SSL/TLS support, timeouts, and connection pooling

  • Redis Streams: Input/output stream configurations for message processing

  • Logging System: Flexible logging handlers supporting file rotation, streaming, and null outputs

  • Operational Settings: Reconnection intervals and version management

Main Configuration Classes:

StepAdapterConfig: Root configuration class that orchestrates all subsystem configurations RedisClientConfig: Complete Redis client configuration including connection and streams RedisConnection: Low-level Redis connection parameters with SSL and socket options RedisStreams: Stream processing configuration for inputs and outputs LogConfig: Comprehensive logging configuration with multiple handler types

Logging Handler Types:

  • LogStreamHandler: Outputs to stdout/stderr streams

  • LogNullHandler: Discards all log messages (useful for testing)

  • LogFileHandler: Writes to a single log file

  • LogSizeFileRotateHandler: Rotates logs based on file size

  • LogTimeFileRotateHandler: Rotates logs based on time intervals

Schema Generation:

The module includes custom JSON schema generation capabilities for configuration validation and documentation. Each configuration class provides methods to:

  • Generate JSON schemas for validation

  • Create default configuration examples

  • Export configuration templates

Configuration Validation:

All configuration models use Pydantic’s strict validation with:

  • Type checking and conversion

  • Range validation for numeric fields

  • String length validation

  • Enum value validation

  • Immutable objects (frozen=True)

  • No extra fields allowed (extra=”forbid”)

Version Management:

The configuration system includes version management through StepConfigVersion to ensure compatibility and support configuration migration between versions.

Note

This module requires Python 3.10+ for proper StrEnum and typing support. All configuration objects are immutable once created to prevent accidental modification during runtime.
