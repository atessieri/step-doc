step_adapter.object_perceived_dataset module

Conversion of CPM perceived objects into position arrays at the output period.

Defines ObjectPerceivedDataset, used by StepAdapterApp to turn each perceived object of a CPM message (CpmDataV1) into a PositionArrayV1. The measured position of the object and its predicted path points are mapped to PositionInfo points sharing one Identification (sender station id, object type and type confidence); points not strictly following the previous one are dropped, the path is cut at the configured maximum CPM span, and the others are resampled on the output period grid by GapFiller.resample (interpolated when the CPM period is longer, decimated when shorter); the interpolated points are typed POSITION_PERCEIVED_PREDICTED like the predicted path. An object whose kept points span less than the minimum output period is skipped with a warning. The sample frequency is the nominal output frequency, and the object dimensions become the vehicle length (X) and width (Y). Unlike ActorDataset, no history is kept between messages.

Let:

  • o = number of perceived objects in one CPM message, at most CpmDataV1.PERCEIVED_OBJECTS_MAX_LENGTH (255).

  • p = number of predicted path points of one perceived object, at most PerceivedObject.POSITION_PREDICTED_MAX_LENGTH (255).

  • g = number of resampled points of one perceived object, at most PositionArrayV1.POINTS_MAX_LENGTH (101).

Complexity:

  • - Time – O(o*(p + g*log(p))), dominated by ObjectPerceivedDataset.add_cpm_message.

  • - Space – O(o*g + p), dominated by ObjectPerceivedDataset.add_cpm_message: o returned position arrays of at most g points each plus the transient resampling buffers of one object at a time.

Classes:

  • ObjectPerceivedDatasetConfig: Immutable configuration of ObjectPerceivedDataset. Complexity: time O(1), space O(1).

  • ObjectPerceivedDataset: Stateless converter of CPM perceived objects to position arrays. Complexity: time O(o*(p + g*log(p))), space O(o*g + p).

Stateless converter of CPM perceived objects to position arrays.

Each add_cpm_message call converts the perceived objects of one CPM message independently, resampling their points at the output period; nothing is retained between calls apart from the configuration, the gap filler and the logger.

config

Configuration converted once into the GapFillerConfig of the gap filler resampling the points of every object.

Type:

ObjectPerceivedDatasetConfig

logger

Logger used for the warnings on skipped perceived objects and points, and for the debug traces of the created position arrays.

Type:

Logger

Complexity:

  • - Time – O(o*(p + g*log(p))), driven by add_cpm_message, o = perceived objects in the message, p = predicted path points and g = resampled points per object.

  • - Space – O(o*g + p), driven by add_cpm_message: o returned position arrays of at most g points each plus the transient resampling buffers of one object at a time.

add_cpm_message(message: CpmDataV1) → list[PositionArrayV1][source]

Convert every perceived object of a CPM message into a position array.

Calls _to_position_array once per perceived object, in message order, with the message stationId, timing each call at DEBUG level through a LoggingTimer (no clock is read when DEBUG is disabled), and logs the number of entries at DEBUG level.

Parameters:

message (CpmDataV1) – CPM message whose perceived objects are converted; its stationId is used for every object.

Returns:

One entry per converted perceived object, in message

order. Objects skipped by _to_position_array (no objectId, no predicted positions or kept points spanning less than the minimum output period) are filtered out.

Return type:

list[PositionArrayV1]

Raises:

ValueError – If the resampling of an object fails (see GapFiller.resample).

Complexity:

  • - Time – O(o*(p + g*log(p))), o = perceived objects in the message, p = predicted path points and g = resampled points per object.

  • - Space – O(o*g + p), o returned position arrays of at most g points each plus the transient resampling buffers of one object at a time, released before the next object.

Immutable configuration of the CPM perceived object dataset.

No validation is done here: ObjectPerceivedDataset.__init__ converts it into a GapFillerConfig, whose __post_init__ checks the ranges, while input_max_cpm_span_ms is checked by StepAdapterConfig.

input_max_cpm_span_ms

Maximum time span (in milliseconds) of the path of one object, starting from its measured position; the part of the path beyond it is dropped.

Type:

int

input_min_altitude_trailing_point_percent

Minimum length, as a percentage of the points of one object, of the run of consecutive points with altitude ending at the last point, needed to interpolate the altitude when some points lack it.

Type:

int

output_nominal_sample_frequency

Nominal output frequency (in Hz), converted to the output period 1000 // frequency ms.

Type:

int

output_period_max_deviation_ms

Maximum allowed deviation (in milliseconds) from nominal output period.

Type:

int

Complexity:

  • - Time – O(1), construction assigns a fixed number of fields.

  • - Space – O(1), a fixed number of fields is stored.
