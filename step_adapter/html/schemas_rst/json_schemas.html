JSON Schemas

The STEP Adapter uses JSON schemas to define the structure of messages and configurations. This ensures that the data exchanged between the adapter and others adheres to a specific format, facilitating interoperability and validation.

The schema defines the structure for messages incoming of STEP Adapter subsystem.
