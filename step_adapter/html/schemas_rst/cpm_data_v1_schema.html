CPM Data V1 Schema

The CPM (Collective Perception Message) Data Schema defines the structure for the objects perceived by an ITS station in the C-ITS system. This schema captures essential data including:

  • Reference time, station id and reference position of the sender

  • Identification and type of each perceived object, with its confidence

  • Measurement time, position and kinematics (speed, heading) of each perceived object

  • Physical characteristics of each perceived object (dimensions X, Y and Z)

  • Perception quality and predicted path of each perceived object

This schema defines a JSON Schema version 1. For further information, please refer to the python classes.

Example of the message:

{
  "type": "CPM",
  "referenceTime": "2022-04-05T17:31:00.000Z",
  "stationId": 25648,
  "referencePosition": {
    "latitude": 45.587878,
    "longitude": 60.458789,
    "positionConfidence": {
      "semiMajorAxisLengthConfidence": 1.23,
      "semiMinorAxisLengthConfidence": 1.23,
      "semiMajorAxisOrientation": 1.0
    },
    "altitude": {
      "value": 120.0,
      "confidence": 1.0
    }
  },
  "perceivedObjects": [
    {
      "objectId": 123,
      "objectType": "passengerCar",
      "objectTypeConfidence": 90,
      "measurementTime": "2022-04-05T17:31:00.000Z",
      "position": {
        "latitude": 45.587878,
        "longitude": 60.458789,
        "positionConfidence": {
          "semiMajorAxisLengthConfidence": 1.23,
          "semiMinorAxisLengthConfidence": 1.23,
          "semiMajorAxisOrientation": 1.0
        },
        "altitude": {
          "value": 120.0,
          "confidence": 1.0
        }
      },
      "speed": {
        "value": 123.67,
        "confidence": 0.5
      },
      "heading": {
        "value": 12.3,
        "confidence": 5.0
      },
      "objectDimensionZ": {
        "value": 12.3,
        "confidence": 0.5
      },
      "objectDimensionY": {
        "value": 12.3,
        "confidence": 0.5
      },
      "objectDimensionX": {
        "value": 12.3,
        "confidence": 0.5
      },
      "objectPerceptionQuality": 5,
      "positionPredicted": [
        {
          "time": "2022-04-05T17:31:00.000Z",
          "position": {
            "latitude": 45.587878,
            "longitude": 60.458789,
            "positionConfidence": {
              "semiMajorAxisLengthConfidence": 1.23,
              "semiMinorAxisLengthConfidence": 1.23,
              "semiMajorAxisOrientation": 1.0
            },
            "altitude": {
              "value": 120.0,
              "confidence": 1.0
            }
          }
        }
      ]
    }
  ]
