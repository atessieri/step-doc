   1"""Output period resampling shared by the CAM and CPM position datasets.
   2
   3Turns irregularly-timed positions into positions at the configured output period,
   4using Hermite interpolation of the CAM gaps and cubic spline interpolation of the
   5CPM positions and of the altitude:
   6
   7    - ``GapFiller.fill`` (streaming, CAM): fills the gap between the last queued
   8      position of an actor and a new one with interpolated positions, used by
   9      ``PointDataset`` when the gap exceeds the nominal output period plus the
  10      deviation. Latitude and longitude follow a Hermite segment built on the reported
  11      speed and heading, the altitude a cubic spline on the history. A gap shorter than
  12      the nominal period minus the deviation never reaches it: ``PointDataset`` rejects
  13      the position (streaming decimation).
  14    - ``GapFiller.resample`` (batch, CPM): resamples a whole time-ordered list of
  15      positions on the output period grid, used by ``ObjectPerceivedDataset``:
  16      longer input periods are interpolated, shorter ones decimated.
  17
  18Main components:
  19    - ``GapFillerConfig``: immutable, validated resampling parameters (output
  20      period, deviation, altitude trailing run percentage).
  21    - ``GapFiller``: stateless resampler (configuration and logger only), so one
  22      instance can be shared.
  23
  24Let:
  25    - n = number of input points of one spline (CAM: queue plus new point, 2-31;
  26      CPM: measured plus predicted points).
  27    - k = number of output points generated by one call (CAM: interpolated
  28      positions; CPM: grid points kept, at most the given maximum point number).
  29    - c = number of points of one chain (fill: k + 2; resample: k).
  30
  31Thread Safety:
  32    ``GapFiller`` keeps no mutable state, so concurrent calls are safe as long as
  33    the logger is.
  34
  35Complexity:
  36    - Time: O(n + k*log(n)), dominated by GapFiller.interpolate (spline
  37      construction O(n), evaluation O(k*log(n))), used by GapFiller.fill and
  38      GapFiller.resample.
  39    - Space: O(n + k), dominated by GapFiller.fill and GapFiller.resample: the
  40      input arrays, the spline and the k output positions.
  41
  42Classes:
  43    - GapFillerConfig: Validated, immutable resampling parameters.
  44      Complexity: time O(1), space O(1).
  45    - OptimalPeriod: Output period chosen for one interpolation.
  46      Complexity: time O(1), space O(1).
  47    - InterpolatedArrays: Interpolated coordinates of one interpolation.
  48      Complexity: time O(1), space O(k).
  49    - MotionValues: Speed and heading computed from a displacement.
  50      Complexity: time O(1), space O(1).
  51    - ChainMotion: Vectorized motion arrays of one position chain.
  52      Complexity: time O(1), space O(c).
  53    - GapFiller: Stateless output period resampler. Complexity: time
  54      O(n + k*log(n)), space O(n + k).
  55"""

 401    def optimal_period(
 402        self, actor: ActorId, time_last_ms: int, time_new_ms: int
 403    ) -> OptimalPeriod:
 404        """Find the optimal output period and interval count for interpolation.
 405
 406        This method computes the best possible output period (in ms) and number of intervals
 407        between two timestamps to achieve evenly-spaced interpolated points. The algorithm
 408        attempts to match the configured nominal output period while respecting the allowed
 409        deviation constraints.
 410
 411        Algorithm Overview:
 412            #. Define the valid period range: [nominal - deviation, nominal + deviation]
 413            #. Calculate the time difference between the two input timestamps
 414            #. Determine the valid range of interval counts that satisfy period constraints:
 415               ceil(diff / period_max) <= count <= floor(diff / period_min)
 416            #. If a valid solution exists:
 417
 418                - Take as candidates the floor and the ceiling of the ideal count
 419                  (diff_time / nominal_period), each clamped to the valid range
 420                - Mark as ideal solution
 421
 422            #. If no exact solution exists (constraint conflict):
 423
 424                - Take as candidates the two boundary counts, the maximum one only when
 425                  at least one (a time difference shorter than the minimum period gives
 426                  one interval)
 427                - Mark as non-ideal solution
 428
 429            #. Choose the candidate whose period diff_time / count is closest to the
 430               nominal period (the smaller count on a tie) and calculate the period
 431               using integer division: diff_time // count
 432
 433        The chosen period and interval count are logged at DEBUG level.
 434
 435        Args:
 436            actor (ActorId): The actor identifier for logging/debugging purposes.
 437            time_last_ms (int): Timestamp of the last recorded point in milliseconds.
 438            time_new_ms (int): Timestamp of the new incoming point in milliseconds.
 439
 440        Returns:
 441            OptimalPeriod: The chosen period in milliseconds (integer division
 442                result), the number of intervals between the points, and the ideal
 443                flag (True if an exact solution within constraints was found, False if
 444                an approximation at the boundary was necessary).
 445
 446        Raises:
 447            ValueError: If ``time_new_ms`` does not follow ``time_last_ms``.
 448
 449        Example:
 450            Ideal solution, 10 Hz (nominal 100 ms, deviation 25 ms, valid period
 451            range [75, 125] ms), diff_time = 245 ms:
 452
 453                - Ideal count: 245 / 100 = 2.45.
 454                - Valid counts: ceil(245 / 125) = 2 <= n <= floor(245 / 75) = 3, so
 455                  an exact solution exists.
 456                - Candidates: floor(2.45) = 2 and ceil(2.45) = 3, both valid.
 457                - n = 2: period 245 / 2 = 122.5 ms, error abs(122.5 - 100) = 22.5 ms.
 458                - n = 3: period 245 / 3 = 81.7 ms, error abs(81.7 - 100) = 18.3 ms.
 459                - Returns OptimalPeriod(81, 3, True): n = 3 has the smaller error and
 460                  245 // 3 = 81. Rounding the ideal count, round(2.45) = 2, would have
 461                  picked the worse candidate.
 462
 463            Non-ideal solution, 1 Hz (nominal 1000 ms, deviation 50 ms, valid period
 464            range [950, 1050] ms), diff_time = 2800 ms:
 465
 466                - Ideal count: 2800 / 1000 = 2.8.
 467                - Valid counts: ceil(2800 / 1050) = 3 > floor(2800 / 950) = 2, so no
 468                  count keeps the period within the range.
 469                - Candidates: the boundary counts 3 and 2.
 470                - n = 3: period 2800 / 3 = 933.3 ms, error abs(933.3 - 1000) = 66.7 ms.
 471                - n = 2: period 2800 / 2 = 1400 ms, error abs(1400 - 1000) = 400 ms.
 472                - Returns OptimalPeriod(933, 3, False): n = 3 has the smaller error
 473                  and 2800 // 3 = 933, outside the range but the closest achievable.
 474
 475        Complexity:
 476            - Time: O(1), constant-time arithmetic over at most two candidates.
 477            - Space: O(1), a fixed number of local variables.
 478        """
 479        nominal_period = self._config.output_nominal_period_ms
 480        output_period_min = self._config.output_period_min_ms
 481        output_period_max = self._config.output_period_max_ms
 482        diff_time = time_new_ms - time_last_ms
 483        if diff_time <= 0:
 484            raise ValueError(
 485                f"{actor}: new time {time_new_ms} ms must follow last time {time_last_ms} ms"
 486            )
 487        interval_number_ideal = diff_time / nominal_period
 488        # Valid range for n: ceil(d/pt_max) <= n <= floor(d/pt_min)
 489        interval_number_min = ceil(diff_time / output_period_max)
 490        interval_number_max = floor(diff_time / output_period_min)
 491        period_ideal = interval_number_min <= interval_number_max
 492        if period_ideal:
 493            # d/n is not linear in n: rounding the ideal count can pick the worse of
 494            # its floor and ceiling, so both are compared
 495            candidates = {
 496                min(
 497                    interval_number_max,
 498                    max(interval_number_min, floor(interval_number_ideal)),
 499                ),
 500                min(
 501                    interval_number_max,
 502                    max(interval_number_min, ceil(interval_number_ideal)),
 503                ),
 504            }
 505        else:
 506            # No exact solution: one of the boundary counts, at least one interval
 507            candidates = {interval_number_min}
 508            if interval_number_max >= 1:
 509                candidates.add(interval_number_max)
 510        interval_number_optimal = min(
 511            candidates,
 512            key=lambda interval_number: (
 513                abs(diff_time / interval_number - nominal_period),
 514                interval_number,
 515            ),
 516        )
 517        period_optimal = diff_time // interval_number_optimal
 518        if self._logger.isEnabledFor(level=logging.DEBUG):
 519            self._logger.debug(
 520                msg=(
 521                    f"{actor}: period {'ideal' if period_ideal else 'optimal'}: "
 522                    f"period={period_optimal} ms, intervals={interval_number_optimal} "
 523                    f"for time diff time={diff_time} ms => range {time_last_ms} - {time_new_ms} ms, "
 524                    f"error={abs(period_optimal - nominal_period)} ms"
 525                )
 526            )
 527        return OptimalPeriod(
 528            period_ms=period_optimal,
 529            interval_number=interval_number_optimal,
 530            ideal=period_ideal,
 531        )

 533    def interpolation_timestamps(
 534        self, actor: ActorId, time_last_ms: int, time_new_ms: int
 535    ) -> np.typing.NDArray[np.int64]:
 536        """Create the interpolated timestamps between two timestamps.
 537
 538        Gets the interval count n from ``optimal_period`` and spreads the n - 1
 539        timestamps evenly over the gap d: timestamp i (1 <= i < n) is
 540        time_last_ms + floor(i * d / n). Every interval, the last one up to
 541        ``time_new_ms`` included, is then the floor or the ceiling of d / n, so the
 542        d % n remainder is spread instead of piling up on the last interval. With an
 543        ideal period (d / n within the integer bounds nominal period -/+ deviation)
 544        every interval stays within the configured deviation; with a non-ideal period
 545        the intervals are the closest achievable to the nominal period and a warning
 546        is logged. A single interval gives no timestamp.
 547
 548        Args:
 549            actor (ActorId): The identifier of the actor for which timestamps are being generated.
 550            time_last_ms (int): Timestamp of the range start in milliseconds (epoch time).
 551            time_new_ms (int): Timestamp of the range end in milliseconds (epoch time).
 552
 553        Returns:
 554            np.typing.NDArray[np.int64]: Array of n - 1 timestamps in milliseconds
 555                (epoch time) between ``time_last_ms`` and ``time_new_ms``, excluding
 556                both of them.
 557
 558        Raises:
 559            ValueError: If ``time_new_ms`` does not follow ``time_last_ms``.
 560
 561        Example:
 562            Ideal period, 10 Hz (nominal 100 ms, deviation 25 ms, intervals allowed
 563            in [75, 125] ms), range from 0 ms to 2999 ms: n = 30. Each timestamp is
 564            placed on its own proportional position, so its rounding error stays
 565            below 1 ms and never accumulates:
 566
 567                - i = 1: floor(1 * 2999 / 30) = floor(99.97) = 99, interval 99.
 568                - i = 2: floor(2 * 2999 / 30) = floor(199.93) = 199, interval
 569                  199 - 99 = 100.
 570                - ...
 571                - i = 29: floor(29 * 2999 / 30) = floor(2899.03) = 2899, interval
 572                  100; last interval up to the range end 2999 - 2899 = 100.
 573
 574            Every interval is 99 or 100 ms. Adding the rounded period
 575            2999 // 30 = 99 twenty-nine times instead would place the last timestamp
 576            at 2871 ms, leaving a last interval of 2999 - 2871 = 128 ms, above 125.
 577
 578            Non-ideal period, 1 Hz (nominal 1000 ms, deviation 25 ms, intervals
 579            allowed in [975, 1025] ms), range from 0 ms to 1900 ms: no n fits
 580            (n = 1 gives 1900, n = 2 gives 950), so ``optimal_period`` picks n = 2,
 581            the closest to the nominal period. The single timestamp is
 582            floor(1 * 1900 / 2) = 950, giving two intervals of 950 ms, 25 ms below
 583            the minimum but the closest achievable, instead of dropping it and
 584            leaving one interval of 1900 ms.
 585
 586        Complexity:
 587            - Time: O(k), k = interval count - 1 generated timestamps, for
 588              ``np.arange`` and the vectorized arithmetic.
 589            - Space: O(k), for the returned array.
 590        """
 591        optimal_period = self.optimal_period(
 592            actor=actor, time_last_ms=time_last_ms, time_new_ms=time_new_ms
 593        )
 594        diff_time_ms = time_new_ms - time_last_ms
 595        # floor(i * d / n): every interval is floor(d / n) or ceil(d / n)
 596        timestamp_ms_array = time_last_ms + (
 597            np.arange(1, optimal_period.interval_number, dtype=np.int64)
 598            * diff_time_ms
 599            // optimal_period.interval_number
 600        )
 601        if not optimal_period.ideal and self._logger.isEnabledFor(
 602            level=logging.WARNING
 603        ):
 604            self._logger.warning(
 605                msg=(
 606                    f"{actor}: no ideal period => {optimal_period.period_ms} ms over "
 607                    f"{optimal_period.interval_number} intervals, range "
 608                    f"{time_last_ms} - {time_new_ms} ms with "
 609                    f"{timestamp_ms_array.size} points without the range ends"
 610                )
 611            )
 612        return timestamp_ms_array

 614    def interpolate(  # pylint: disable=too-many-locals
 615        self,
 616        *,
 617        actor: ActorId,
 618        times_ms: np.typing.NDArray[np.int64],
 619        latitudes: np.typing.NDArray[np.float64],
 620        longitudes: np.typing.NDArray[np.float64],
 621        altitudes_m: np.typing.NDArray[np.float64],
 622        target_times_ms: np.typing.NDArray[np.int64],
 623    ) -> InterpolatedArrays:
 624        """Interpolate latitude, longitude and (if available) altitude via cubic spline.
 625
 626        Fits a vector-valued ``CubicSpline`` over (latitude, longitude[, altitude])
 627        of the input points - sharing one tridiagonal solve across columns - and
 628        evaluates it, without extrapolation, at ``target_times_ms``. The longitudes
 629        are unwrapped (``numpy.unwrap`` with period ``LONGITUDE_RANGE``) before the
 630        fit, so a trajectory crossing the antimeridian stays continuous; the
 631        interpolated longitudes may then lie outside [``LONGITUDE_MIN``,
 632        ``LONGITUDE_MIN`` + ``LONGITUDE_RANGE``). The altitude is a column of the
 633        shared spline when every point has one. Otherwise only the trailing run of
 634        consecutive points with altitude (ending at the last point) is used, by a
 635        separate spline, when its length reaches
 636        ``_required_altitude_trailing_point_number``; a target time before the run
 637        gets NaN (no extrapolation). With a shorter or empty run every altitude is
 638        NaN.
 639
 640        Args:
 641            actor (ActorId): The actor identifier, used for logging.
 642            times_ms (np.typing.NDArray[np.int64]): Input timestamps in milliseconds
 643                (epoch time), strictly increasing, at least 2.
 644            latitudes (np.typing.NDArray[np.float64]): Input latitudes in decimal
 645                degrees.
 646            longitudes (np.typing.NDArray[np.float64]): Input longitudes in decimal
 647                degrees.
 648            altitudes_m (np.typing.NDArray[np.float64]): Input altitudes in meters,
 649                NaN where missing.
 650            target_times_ms (np.typing.NDArray[np.int64]): Timestamps in milliseconds
 651                (epoch time) at which the spline is evaluated, within the input range.
 652
 653        Returns:
 654            InterpolatedArrays: ``target_times_ms`` with the interpolated latitudes,
 655                unwrapped longitudes (decimal degrees) and altitudes (meters, NaN
 656                where the altitude cannot be interpolated).
 657
 658        Raises:
 659            ValueError: If the input timestamps are fewer than 2 or not strictly
 660                increasing (raised by ``CubicSpline``).
 661
 662        Complexity:
 663            - Time: O(n + k*log(n)), O(n) longitude unwrap and spline construction (at
 664              most two splines), O(k*log(n)) evaluation of k points.
 665            - Space: O(n + k), the combined input matrix and spline coefficients plus
 666              the returned arrays.
 667        """
 668        points_number = times_ms.size
 669        altitude_trailing_count = self._altitude_trailing_point_number(
 670            altitudes_m=altitudes_m
 671        )
 672        altitude_complete = altitude_trailing_count == points_number
 673        # Lat/lon (and altitude, when every point has one) share the same x
 674        # (timestamps), so a single vector-valued CubicSpline solves one tridiagonal
 675        # system for all columns at once instead of building 2-3 independent splines.
 676        column_count = 3 if altitude_complete else 2
 677        combined_y = np.empty(shape=(points_number, column_count), dtype=np.float64)
 678        combined_y[:, 0] = latitudes
 679        # Unwrapped: a jump across the antimeridian becomes a continuous change
 680        combined_y[:, 1] = np.unwrap(longitudes, period=LONGITUDE_RANGE)
 681        if altitude_complete:
 682            combined_y[:, 2] = altitudes_m
 683        interpolator = CubicSpline(x=times_ms, y=combined_y)
 684        interpolated = interpolator(x=target_times_ms, extrapolate=False)
 685        if altitude_complete:
 686            interpolated_altitudes_m = interpolated[:, 2]
 687        elif altitude_trailing_count >= self._required_altitude_trailing_point_number(
 688            points_number=points_number
 689        ):
 690            # Altitude gap: a separate spline over the trailing run only; target
 691            # times before the run get NaN (no extrapolation)
 692            altitude_interpolator = CubicSpline(
 693                x=times_ms[-altitude_trailing_count:],
 694                y=altitudes_m[-altitude_trailing_count:],
 695            )
 696            interpolated_altitudes_m = altitude_interpolator(
 697                x=target_times_ms, extrapolate=False
 698            )
 699        else:
 700            # Trailing run too short, or empty (last point without altitude):
 701            # no altitude spline is built
 702            interpolated_altitudes_m = np.full(
 703                shape=target_times_ms.shape, fill_value=np.nan, dtype=np.float64
 704            )
 705        if self._logger.isEnabledFor(level=logging.DEBUG) and not altitude_complete:
 706            self._logger.debug(
 707                msg=(
 708                    f"{actor}: altitude gap, trailing run {altitude_trailing_count} of "
 709                    f"{points_number} points => altitude "
 710                    f"{'unavailable' if np.isnan(interpolated_altitudes_m).all() else 'interpolated'}"
 711                )
 712            )
 713        return InterpolatedArrays(
 714            times_ms=target_times_ms,
 715            latitudes=interpolated[:, 0],
 716            longitudes=interpolated[:, 1],
 717            altitudes=interpolated_altitudes_m,
 718        )

 720    def _tangent_deg_per_ms(
 721        self,
 722        position: PositionInfo,
 723        chord_tangent: tuple[float, float],
 724        chord_speed_m_s: float,
 725    ) -> tuple[float, float]:
 726        """Return the latitude and longitude rates of a position.
 727
 728        The rates come from the point reached in one second on the WGS84 ellipsoid
 729        with the speed and heading reported by the sender; the heading is the
 730        orientation of the velocity vector, so it already gives the direction of motion
 731        when driving backwards. The chord tangent is used when the speed or the heading
 732        is missing, when the speed is below ``TANGENT_SPEED_MIN_M_S`` (unreliable
 733        heading), or when it exceeds the chord speed by more than
 734        ``TANGENT_CHORD_SPEED_RATIO_MAX`` times.
 735
 736        Args:
 737            position (PositionInfo): The position with its reported motion.
 738            chord_tangent (tuple[float, float]): Latitude and longitude rates of the
 739                chord between the two positions, in decimal degrees per millisecond.
 740            chord_speed_m_s (float): Speed along the chord, in m/s.
 741
 742        Returns:
 743            tuple[float, float]: Latitude and longitude rates, in decimal degrees per
 744                millisecond.
 745
 746        Complexity:
 747            - Time: O(1), at most one forward geodesic call on scalar inputs.
 748            - Space: O(1), a tuple of two floats is returned.
 749        """
 750        speed = position.speed
 751        heading = position.heading
 752        if (
 753            (speed is None)
 754            or (heading is None)
 755            or (speed.value < self.TANGENT_SPEED_MIN_M_S)
 756            or (speed.value > self.TANGENT_CHORD_SPEED_RATIO_MAX * chord_speed_m_s)
 757        ):
 758            return chord_tangent
 759        latitude = position.position.latitude
 760        longitude = position.position.longitude
 761        origin = LatLonPoint(latitude, longitude)
 762        geocode = Geocode(point_a_par=origin, point_b_par=origin)
 763        geocode.move_point_a_to_point_b(
 764            distance=speed.value,
 765            heading=heading.value,
 766            dist_unit=DistanceUnit.METERS,
 767            angle_unit=AngleUnit.DEGREES,
 768        )
 769        moved_point = geocode.point_b
 770        # Unwrapped: a move across the antimeridian becomes a continuous change
 771        moved_longitude = np.unwrap(
 772            [longitude, moved_point.longitude], period=LONGITUDE_RANGE
 773        )[1]
 774        return (
 775            (moved_point.latitude - latitude) / ItsTime.SEC_TO_MS_FACTOR,
 776            float(moved_longitude - longitude) / ItsTime.SEC_TO_MS_FACTOR,
 777        )

 779    def _hermite_coordinates(
 780        self,
 781        *,
 782        last_record: PositionInfoRecord,
 783        new_record: PositionInfoRecord,
 784        target_times_ms: np.typing.NDArray[np.int64],
 785    ) -> np.typing.NDArray[np.float64]:
 786        """Evaluate the Hermite segment between two consecutive positions.
 787
 788        Both tangents are known when the new position arrives and the tangent of a
 789        position is the same for the segments ending and starting on it, unless the
 790        chord fallback of ``_tangent_deg_per_ms`` applies. The longitudes are unwrapped,
 791        so a segment crossing the antimeridian stays continuous.
 792
 793        Args:
 794            last_record (PositionInfoRecord): The position at the start of the segment.
 795            new_record (PositionInfoRecord): The position at the end of the segment,
 796                strictly after ``last_record``.
 797            target_times_ms (np.typing.NDArray[np.int64]): k timestamps in milliseconds
 798                (epoch time), within the segment.
 799
 800        Returns:
 801            np.typing.NDArray[np.float64]: k rows of latitude and unwrapped longitude,
 802                in decimal degrees.
 803
 804        Complexity:
 805            - Time: O(k), up to three scalar geodesic calls, constant-time construction
 806              and k evaluations on two knots.
 807            - Space: O(k), the returned array.
 808        """
 809        last_reference = last_record.position.position
 810        new_reference = new_record.position.position
 811        longitudes = np.unwrap(
 812            [last_reference.longitude, new_reference.longitude], period=LONGITUDE_RANGE
 813        )
 814        time_last_ms = last_record.time.epoch_ms
 815        time_new_ms = new_record.time.epoch_ms
 816        elapsed_ms = time_new_ms - time_last_ms
 817        chord_tangent = (
 818            (new_reference.latitude - last_reference.latitude) / elapsed_ms,
 819            float(longitudes[1] - longitudes[0]) / elapsed_ms,
 820        )
 821        chord_speed_m_s = (
 822            Geocode(
 823                point_a_par=LatLonPoint(
 824                    last_reference.latitude, last_reference.longitude
 825                ),
 826                point_b_par=LatLonPoint(
 827                    new_reference.latitude, new_reference.longitude
 828                ),
 829            ).get_distance(unit=DistanceUnit.METERS)
 830            * ItsTime.SEC_TO_MS_FACTOR
 831            / elapsed_ms
 832        )
 833        hermite = CubicHermiteSpline(
 834            x=[time_last_ms, time_new_ms],
 835            y=[
 836                [last_reference.latitude, longitudes[0]],
 837                [new_reference.latitude, longitudes[1]],
 838            ],
 839            dydx=[
 840                self._tangent_deg_per_ms(
 841                    position=last_record.position,
 842                    chord_tangent=chord_tangent,
 843                    chord_speed_m_s=chord_speed_m_s,
 844                ),
 845                self._tangent_deg_per_ms(
 846                    position=new_record.position,
 847                    chord_tangent=chord_tangent,
 848                    chord_speed_m_s=chord_speed_m_s,
 849                ),
 850            ],
 851        )
 852        coordinates: np.typing.NDArray[np.float64] = hermite(target_times_ms)
 853        return coordinates

 855    def fill(
 856        self,
 857        *,
 858        actor: ActorId,
 859        history_times_ms: np.typing.NDArray[np.int64],
 860        history_latitudes: np.typing.NDArray[np.float64],
 861        history_longitudes: np.typing.NDArray[np.float64],
 862        history_altitudes_m: np.typing.NDArray[np.float64],
 863        last_record: PositionInfoRecord,
 864        new_record: PositionInfoRecord,
 865    ) -> list[PositionInfo]:
 866        """Fill the gap between the last position of a stream and a new one.
 867
 868        Gets the interpolated timestamps (``interpolation_timestamps``), evaluates the
 869        Hermite segment between the two positions for latitude and longitude
 870        (``_hermite_coordinates``) and the spline fitted on the history for the altitude
 871        (``interpolate``), and builds the chain
 872        last position -> interpolated positions -> new position
 873        (``_build_chain_positions``): the k interpolated positions share stationInfo
 874        and objectId of ``new_record`` and are followed by ``new_record`` with
 875        speed/heading recomputed from the displacement from the last interpolated
 876        position (or from ``last_record`` when k = 0).
 877
 878        Args:
 879            actor (ActorId): The actor identifier, used for logging.
 880            history_times_ms (np.typing.NDArray[np.int64]): Timestamps in milliseconds
 881                (epoch time) of the history, ``new_record`` last, strictly increasing.
 882            history_latitudes (np.typing.NDArray[np.float64]): Latitudes of the
 883                history in decimal degrees.
 884            history_longitudes (np.typing.NDArray[np.float64]): Longitudes of the
 885                history in decimal degrees.
 886            history_altitudes_m (np.typing.NDArray[np.float64]): Altitudes of the
 887                history in meters, NaN where missing.
 888            last_record (PositionInfoRecord): The last position before the gap, the
 889                origin of the chain (not returned).
 890            new_record (PositionInfoRecord): The new position after the gap, returned
 891                last.
 892
 893        Returns:
 894            list[PositionInfo]: k interpolated positions (``POSITION_*_ESTIMATED``)
 895                followed by the real ``new_record`` position with recomputed
 896                speed/heading.
 897
 898        Raises:
 899            ValueError: If ``new_record`` does not follow ``last_record``.
 900
 901        Complexity:
 902            - Time: O(n + k*log(n)), dominated by ``interpolate``.
 903            - Space: O(n + k), the spline plus the chain arrays and the k + 1
 904              returned positions.
 905        """
 906        target_times_ms = self.interpolation_timestamps(
 907            actor=actor,
 908            time_last_ms=last_record.time.epoch_ms,
 909            time_new_ms=new_record.time.epoch_ms,
 910        )
 911        interpolated = self.interpolate(
 912            actor=actor,
 913            times_ms=history_times_ms,
 914            latitudes=history_latitudes,
 915            longitudes=history_longitudes,
 916            altitudes_m=history_altitudes_m,
 917            target_times_ms=target_times_ms,
 918        )
 919        # The history spline provides the altitude only: the horizontal path uses the
 920        # motion reported by the sender, known when the new position arrives
 921        coordinates = self._hermite_coordinates(
 922            last_record=last_record,
 923            new_record=new_record,
 924            target_times_ms=target_times_ms,
 925        )
 926        interpolated = interpolated._replace(
 927            latitudes=coordinates[:, 0], longitudes=coordinates[:, 1]
 928        )
 929        last_reference = last_record.position.position
 930        new_reference = new_record.position.position
 931        # The altitude of the real chain ends is never used: the real positions are
 932        # returned with their own altitude
 933        return self._build_chain_positions(
 934            actor=actor,
 935            template=new_record.position,
 936            times_ms=np.concatenate(
 937                (
 938                    [last_record.time.epoch_ms],
 939                    interpolated.times_ms,
 940                    [new_record.time.epoch_ms],
 941                ),
 942                dtype=np.int64,
 943            ),
 944            latitudes=np.concatenate(
 945                (
 946                    [last_reference.latitude],
 947                    interpolated.latitudes,
 948                    [new_reference.latitude],
 949                ),
 950                dtype=np.float64,
 951            ),
 952            longitudes=np.concatenate(
 953                (
 954                    [last_reference.longitude],
 955                    interpolated.longitudes,
 956                    [new_reference.longitude],
 957                ),
 958                dtype=np.float64,
 959            ),
 960            altitudes_m=np.concatenate(
 961                ([np.nan], interpolated.altitudes, [np.nan]), dtype=np.float64
 962            ),
 963            real_positions=[
 964                last_record.position,
 965                *([None] * interpolated.times_ms.size),
 966                new_record.position,
 967            ],
 968        )

 970    def _resample_grid_times(
 971        self,
 972        actor: ActorId,
 973        first_time_ms: int,
 974        last_time_ms: int,
 975        max_point_number: int,
 976    ) -> np.typing.NDArray[np.int64]:
 977        """Create the output period grid of a resampling, up to the maximum number.
 978
 979        The grid is first time + floor(i * span / n), with n chosen by
 980        ``optimal_period`` over the whole span; only the kept points are generated,
 981        so the cost does not depend on the span. A non-ideal period and a truncation
 982        are logged as warnings.
 983
 984        Args:
 985            actor (ActorId): The actor identifier, used for logging.
 986            first_time_ms (int): Time of the first position in milliseconds.
 987            last_time_ms (int): Time of the last position in milliseconds.
 988            max_point_number (int): Maximum number of grid points.
 989
 990        Returns:
 991            np.typing.NDArray[np.int64]: The first min(n + 1, ``max_point_number``)
 992                grid times in milliseconds (epoch time).
 993
 994        Raises:
 995            ValueError: If ``last_time_ms`` does not follow ``first_time_ms``.
 996
 997        Complexity:
 998            - Time: O(k), k = kept grid points, for ``np.arange`` and the vectorized
 999              arithmetic.
1000            - Space: O(k), the returned array.
1001        """
1002        optimal_period = self.optimal_period(
1003            actor=actor, time_last_ms=first_time_ms, time_new_ms=last_time_ms
1004        )
1005        interval_number = optimal_period.interval_number
1006        if not optimal_period.ideal and self._logger.isEnabledFor(
1007            level=logging.WARNING
1008        ):
1009            self._logger.warning(
1010                msg=(
1011                    f"{actor}: no ideal period => {optimal_period.period_ms} ms over "
1012                    f"{interval_number} intervals, range "
1013                    f"{first_time_ms} - {last_time_ms} ms with "
1014                    f"{interval_number - 1} points without the range ends"
1015                )
1016            )
1017        grid_point_number = interval_number + 1
1018        if grid_point_number > max_point_number and self._logger.isEnabledFor(
1019            level=logging.WARNING
1020        ):
1021            self._logger.warning(
1022                msg=(
1023                    f"{actor}: {grid_point_number} resampled positions, "
1024                    f"truncated to {max_point_number}"
1025                )
1026            )
1027        # floor(i * d / n): every interval is floor(d / n) or ceil(d / n)
1028        return first_time_ms + (
1029            np.arange(min(grid_point_number, max_point_number), dtype=np.int64)
1030            * (last_time_ms - first_time_ms)
1031            // interval_number
1032        )

1034    def resample(  # pylint: disable=too-many-locals
1035        self,
1036        *,
1037        actor: ActorId,
1038        records: Sequence[PositionInfoRecord],
1039        max_point_number: int,
1040    ) -> list[PositionInfo]:
1041        """Resample time-ordered positions on the output period grid.
1042
1043        Fewer than ``RESAMPLE_POINT_NUMBER_MIN`` positions are returned as-is.
1044        Positions whose every interval is already within [output period min, output
1045        period max] keep their times, truncated to ``max_point_number`` with a
1046        warning (``_with_recomputed_motion``). Otherwise the grid is first time +
1047        floor(i * span / n), for
1048        i in [0, n], with n chosen by ``optimal_period`` over the whole span
1049        (``_resample_grid_times``, so a non-ideal period is logged as a warning and
1050        only the first ``max_point_number`` grid times are generated, with a warning
1051        when some are left out): a longer input period is interpolated, a shorter one
1052        decimated. A grid time equal to an input time keeps that real position (an
1053        input period that divides the output one is a pure decimation); the other
1054        grid times become estimated positions from the spline fitted on every input
1055        position (``interpolate``). The first position is returned unchanged; the
1056        speed/heading of every following position, real or estimated, is recomputed
1057        from the displacement from the previous grid point
1058        (``_build_chain_positions``).
1059
1060        Args:
1061            actor (ActorId): The actor identifier, used for logging.
1062            records (Sequence[PositionInfoRecord]): Positions with their parsed time,
1063                in strictly increasing time order; the first one is the template of
1064                the estimated positions (stationInfo, objectId, position type).
1065            max_point_number (int): Maximum number of returned positions.
1066
1067        Returns:
1068            list[PositionInfo]: The positions at the output period, first and last
1069                grid times on the first and last input positions (before
1070                truncation).
1071
1072        Raises:
1073            ValueError: If the record times are not strictly increasing.
1074
1075        Complexity:
1076            - Time: O(n + k*log(n)), O(n) input arrays, O(k) grid generation
1077              (``_resample_grid_times``), O(k*log(n)) grid matching
1078              (``numpy.searchsorted``) and ``interpolate``; O(n) when no grid is
1079              needed.
1080            - Space: O(n + k), the input arrays and the spline, plus the k grid times
1081              and returned positions; O(n) when no grid is needed.
1082        """
1083        if len(records) < self.RESAMPLE_POINT_NUMBER_MIN:
1084            return self._truncate_positions(
1085                actor=actor,
1086                positions=[record.position for record in records],
1087                max_point_number=max_point_number,
1088            )
1089        times_ms = np.fromiter(
1090            (record.time.epoch_ms for record in records),
1091            dtype=np.int64,
1092            count=len(records),
1093        )
1094        diff_ms = np.diff(times_ms)
1095        if np.any(diff_ms <= 0):
1096            raise ValueError(f"{actor}: resample times must be strictly increasing")
1097        if np.all(
1098            (diff_ms >= self._config.output_period_min_ms)
1099            & (diff_ms <= self._config.output_period_max_ms)
1100        ):
1101            if self._logger.isEnabledFor(level=logging.DEBUG):
1102                self._logger.debug(
1103                    msg=f"{actor}: {len(records)} positions already at the output period"
1104                )
1105            return self._with_recomputed_motion(
1106                actor=actor,
1107                positions=self._truncate_positions(
1108                    actor=actor,
1109                    positions=[record.position for record in records],
1110                    max_point_number=max_point_number,
1111                ),
1112                times_ms=times_ms,
1113            )
1114        grid_times_ms = self._resample_grid_times(
1115            actor=actor,
1116            first_time_ms=int(times_ms[0]),
1117            last_time_ms=int(times_ms[-1]),
1118            max_point_number=max_point_number,
1119        )
1120        latitudes = np.fromiter(
1121            (record.position.position.latitude for record in records),
1122            dtype=np.float64,
1123            count=len(records),
1124        )
1125        longitudes = np.fromiter(
1126            (record.position.position.longitude for record in records),
1127            dtype=np.float64,
1128            count=len(records),
1129        )
1130        altitudes_m = np.fromiter(
1131            (
1132                record.position.position.altitude.value
1133                if record.position.position.altitude
1134                else np.nan
1135                for record in records
1136            ),
1137            dtype=np.float64,
1138            count=len(records),
1139        )
1140        # Grid time equal to an input time: the real position is kept
1141        record_indexes = np.minimum(
1142            np.searchsorted(times_ms, grid_times_ms), times_ms.size - 1
1143        )
1144        is_real = times_ms[record_indexes] == grid_times_ms
1145        is_estimated = ~is_real
1146        interpolated = self.interpolate(
1147            actor=actor,
1148            times_ms=times_ms,
1149            latitudes=latitudes,
1150            longitudes=longitudes,
1151            altitudes_m=altitudes_m,
1152            target_times_ms=grid_times_ms[is_estimated],
1153        )
1154        grid_latitudes = np.empty(shape=grid_times_ms.shape, dtype=np.float64)
1155        grid_longitudes = np.empty(shape=grid_times_ms.shape, dtype=np.float64)
1156        grid_altitudes_m = np.empty(shape=grid_times_ms.shape, dtype=np.float64)
1157        grid_latitudes[is_real] = latitudes[record_indexes[is_real]]
1158        grid_longitudes[is_real] = longitudes[record_indexes[is_real]]
1159        grid_altitudes_m[is_real] = altitudes_m[record_indexes[is_real]]
1160        grid_latitudes[is_estimated] = interpolated.latitudes
1161        grid_longitudes[is_estimated] = interpolated.longitudes
1162        grid_altitudes_m[is_estimated] = interpolated.altitudes
1163        positions = [records[0].position]
1164        positions.extend(
1165            self._build_chain_positions(
1166                actor=actor,
1167                template=records[0].position,
1168                times_ms=grid_times_ms,
1169                latitudes=grid_latitudes,
1170                longitudes=grid_longitudes,
1171                altitudes_m=grid_altitudes_m,
1172                real_positions=[
1173                    records[int(record_index)].position if real else None
1174                    for record_index, real in zip(record_indexes, is_real, strict=True)
1175                ],
1176            )
1177        )
1178        if self._logger.isEnabledFor(level=logging.DEBUG):
1179            self._logger.debug(
1180                msg=(
1181                    f"{actor}: resampled {len(records)} positions into "
1182                    f"{len(positions)} ({int(is_real.sum())} real, "
1183                    f"{int(is_estimated.sum())} estimated)"
1184                )
1185            )
1186        return positions

1189        self,
1190        position: PositionInfo,
1191        distance_m: float,
1192        heading_deg: float,
1193        time_diff_ms: int,
1194    ) -> PositionInfo:
1195        """Return ``position`` with speed/heading (re)computed from the given motion.
1196
1197        Speed and heading reported by the sender are intentionally not trusted or
1198        preserved here: they are always recomputed (``_speed_heading_from_motion``)
1199        from the geodesic displacement relative to the previous point, since the
1200        caller already has that distance/heading available (no extra ``Geocode`` call
1201        is made). The computed values are logged at DEBUG level.
1202
1203        Args:
1204            position (PositionInfo): Real (measured) position to enrich with motion data.
1205            distance_m (float): Geodesic distance to the previous point, in meters.
1206            heading_deg (float): Forward azimuth from the previous point, in degrees.
1207            time_diff_ms (int): Time elapsed since the previous point, in milliseconds.
1208
1209        Returns:
1210            PositionInfo: Shallow copy of ``position`` with recomputed speed and
1211                heading (both None when ``time_diff_ms`` is not strictly positive).
1212
1213        Complexity:
1214            - Time: O(1), a fixed amount of arithmetic and one shallow model copy.
1215            - Space: O(1), ``model_copy`` creates a shallow copy with only
1216              speed/heading replaced.
1217        """
1218        motion = self._speed_heading_from_motion(

1312    def _build_chain_positions(  # pylint: disable=too-many-locals
1313        self,
1314        *,
1315        actor: ActorId,
1316        template: PositionInfo,
1317        times_ms: np.typing.NDArray[np.int64],
1318        latitudes: np.typing.NDArray[np.float64],
1319        longitudes: np.typing.NDArray[np.float64],
1320        altitudes_m: np.typing.NDArray[np.float64],
1321        real_positions: Sequence[PositionInfo | None],
1322    ) -> list[PositionInfo]:
1323        """Build the positions of a chain after its origin.
1324
1325        First applies, once on the whole arrays, the range clamping/wrapping each
1326        validator would have applied: ``np.clip`` for latitude and altitude,
1327        ``_wrap_longitude_values`` for longitude. The geodesic/motion math is then
1328        delegated to ``_compute_chain_motion`` (a single vectorized call over the
1329        whole chain), so a spline overshoot beyond the poles or across the
1330        antimeridian never yields a NaN or a bogus speed/heading. For every chain
1331        point after the origin: a real position (``real_positions`` entry not None)
1332        is returned with speed/heading recomputed (``apply_motion``); an estimated
1333        one is built via ``model_construct`` (skipping pydantic validation, values
1334        computed internally) with stationInfo and objectId of ``template``, no
1335        confidence, no drive direction, and type ``POSITION_GNSS_ESTIMATED`` for a
1336        GNSS ``template``, ``POSITION_PERCEIVED_ESTIMATED`` otherwise. A chain holding
1337        only its origin has no position after it, so no geodesic call is made.
1338
1339        Args:
1340            actor (ActorId): The actor identifier, used for logging.
1341            template (PositionInfo): Position whose stationInfo, objectId and type
1342                the estimated positions derive from.
1343            times_ms (np.typing.NDArray[np.int64]): c chain timestamps (ms epoch),
1344                origin first.
1345            latitudes (np.typing.NDArray[np.float64]): c chain latitudes, in decimal
1346                degrees, possibly beyond [LATITUDE_MIN, LATITUDE_MAX].
1347            longitudes (np.typing.NDArray[np.float64]): c chain longitudes, in decimal
1348                degrees, possibly unwrapped.
1349            altitudes_m (np.typing.NDArray[np.float64]): c chain altitudes, in meters,
1350                NaN where unavailable (used for the estimated positions only).
1351            real_positions (Sequence[PositionInfo | None]): c entries, the real
1352                position of each chain point, None for an estimated one; the origin
1353                entry is not used.
1354
1355        Returns:
1356            list[PositionInfo]: c - 1 positions, one per chain point after the origin;
1357                empty for a chain holding only its origin.
1358
1359        Complexity:
1360            - Time: O(c), the vectorized clamping/wrapping, ``_compute_chain_motion``
1361              and O(c) object construction.
1362            - Space: O(c), the clamped arrays, the chain motion arrays and the
1363              returned positions.
1364        """
1365        if times_ms.size <= 1:
1366            return []
1367        # Validator rules applied once to the whole arrays (NaN altitudes stay NaN),
1368        # before the geodesic chain so it only sees valid coordinates
1369        latitudes = np.clip(latitudes, LATITUDE_MIN, LATITUDE_MAX)
1370        longitudes = self._wrap_longitude_values(values=longitudes)
1371        altitudes_m = np.clip(altitudes_m, ALTITUDE_VALUE_MIN, ALTITUDE_VALUE_MAX)
1372        chain_motion = self._compute_chain_motion(
1373            times_ms=times_ms, latitudes=latitudes, longitudes=longitudes
1374        )
1375        position_type = (
1376            PositionType.POSITION_GNSS_ESTIMATED
1377            if template.positionType == PositionType.POSITION_GNSS
1378            else PositionType.POSITION_PERCEIVED_ESTIMATED
1379        )
1380        time_tmp = ItsTime(its_time_ms=0)
1381        positions: list[PositionInfo] = []
1382        estimated_number = 0
1383        # Row chain_index - 1 of the chain motion is the pair into chain point chain_index
1384        for chain_index in range(1, times_ms.size):
1385            motion_index = chain_index - 1
1386            real_position = real_positions[chain_index]
1387            if real_position is not None:
1388                positions.append(
1389                    self.apply_motion(
1390                        position=real_position,
1391                        distance_m=float(
1392                            chain_motion.distance_heading["distance"][motion_index]
1393                        ),
1394                        heading_deg=float(
1395                            chain_motion.distance_heading["heading"][motion_index]
1396                        ),
1397                        time_diff_ms=int(chain_motion.time_diff_ms[motion_index]),
1398                    )
1399                )
1400                continue
1401            estimated_number += 1
1402            reference_position = ReferencePosition.model_construct(
1403                latitude=float(latitudes[chain_index]),
1404                longitude=float(longitudes[chain_index]),
1405                positionConfidence=None,
1406                altitude=(
1407                    Altitude.model_construct(
1408                        value=float(altitudes_m[chain_index]), confidence=None
1409                    )
1410                    if not np.isnan(altitudes_m[chain_index])
1411                    else None
1412                ),
1413            )
1414            time_tmp.epoch_ms = int(times_ms[chain_index])
1415            positions.append(
1416                PositionInfo.model_construct(
1417                    stationInfo=template.stationInfo,
1418                    objectId=template.objectId,
1419                    positionType=position_type,
1420                    time=str(object=time_tmp),
1421                    position=reference_position,
1422                    speed=(
1423                        Speed.model_construct(
1424                            value=float(chain_motion.speed_values[motion_index]),
1425                            confidence=None,
1426                        )
1427                        if chain_motion.has_motion[motion_index]
1428                        else None
1429                    ),
1430                    heading=(
1431                        Heading.model_construct(
1432                            value=float(chain_motion.heading_values[motion_index]),
1433                            confidence=None,
1434                        )
1435                        if chain_motion.has_motion[motion_index]
1436                        else None
1437                    ),
1438                    driveDirection=None,
1439                )
1440            )
1441        if self._logger.isEnabledFor(level=logging.DEBUG):
1442            self._logger.debug(
1443                msg=(
1444                    f"{actor}: built {estimated_number} estimated and "
1445                    f"{len(positions) - estimated_number} real positions from a single "
1446                    f"batched geodesic call over {len(positions)} pairs"
1447                )
1448            )
1449        return positions

1451    @staticmethod
1452    def _compute_chain_motion(
1453        times_ms: np.typing.NDArray[np.int64],
1454        latitudes: np.typing.NDArray[np.float64],
1455        longitudes: np.typing.NDArray[np.float64],
1456    ) -> ChainMotion:
1457        """Compute geodesic distance/heading and derived speed/heading for one chain.
1458
1459        Issues a single vectorized geodesic call over the whole chain of c points
1460        (c - 1 pairs, origin first) instead of one scalar ``Geocode`` call per pair,
1461        then derives per-pair time deltas, speeds in m/s (clamped to
1462        [``SPEED_VALUE_MIN``, ``SPEED_VALUE_MAX``]) and headings in decimal degrees
1463        (wrapped by ``_wrap_heading_values``).
1464
1465        Args:
1466            times_ms (np.typing.NDArray[np.int64]): c chain timestamps (ms epoch).
1467            latitudes (np.typing.NDArray[np.float64]): c chain latitudes, in range.
1468            longitudes (np.typing.NDArray[np.float64]): c chain longitudes, in range.
1469
1470        Returns:
1471            ChainMotion: The c-1-row distance/heading/time-diff/speed/heading arrays;
1472                row i is the pair from chain point i to chain point i + 1.
1473
1474        Complexity:
1475            - Time: O(c), one vectorized geodesic call over c - 1 pairs plus O(c)
1476              numpy arithmetic.
1477            - Space: O(c), the chain points and the five c-1-row result arrays.
1478        """
1479        pair_number = times_ms.size - 1
1480        chain = np.empty(shape=pair_number, dtype=Geocode.SPHERICAL_POINT_DTYPE)
1481        chain["latitude"] = latitudes[1:]
1482        chain["longitude"] = longitudes[1:]
1483        previous_point = np.void(
1484            (float(latitudes[0]), float(longitudes[0])),
1485            dtype=Geocode.SPHERICAL_POINT_DTYPE,
1486        )
1487        distance_heading = Geocode.get_distances_and_headings_vector_numpy(
1488            points=chain,
1489            previous_point=previous_point,
1490            dist_unit=DistanceUnit.METERS,
1491            angle_unit=AngleUnit.DEGREES,
1492        )
1493        time_diff_ms = np.diff(times_ms)
1494        has_motion = time_diff_ms > 0
1495        speed_values = np.zeros(shape=pair_number, dtype=np.float64)
1496        heading_values = np.zeros(shape=pair_number, dtype=np.float64)
1497        speed_values[has_motion] = np.clip(
1498            distance_heading["distance"][has_motion]
1499            * ItsTime.SEC_TO_MS_FACTOR
1500            / time_diff_ms[has_motion],
1501            SPEED_VALUE_MIN,
1502            SPEED_VALUE_MAX,
1503        )
1504        heading_values[has_motion] = GapFiller._wrap_heading_values(
1505            values=distance_heading["heading"][has_motion]
1506        )
1507        return ChainMotion(
1508            distance_heading=distance_heading,
1509            time_diff_ms=time_diff_ms,
1510            has_motion=has_motion,
1511            speed_values=speed_values,
1512            heading_values=heading_values,
1513        )

1521        The run is made of the consecutive points with a non-NaN altitude ending at

1571    ) -> MotionValues:
1572        """Compute speed and heading from a distance/heading pair and a time delta.
1573
1574        Pure helper used by ``apply_motion``: the callers already have a
1575        (distance, heading) pair on hand (from a coherence check or from the batched
1576        chain geodesic call) and only need the motion math applied, without any

1578
1579        Args:
1580            distance_m (float): Geodesic distance to the previous point, in meters.

1585            MotionValues: Speed and heading both None when ``time_diff_ms`` is not

1598                value=(distance_m * ItsTime.SEC_TO_MS_FACTOR) / time_diff_ms,

1604    @staticmethod
1605    def _wrap_heading_values(
1606        values: np.typing.NDArray[np.float64],
1607    ) -> np.typing.NDArray[np.float64]:
1608        """Wrap headings, mirroring the ``wrap_value`` validator of ``Heading``.
1609
1610        Values outside [``HEADING_VALUE_MIN``, ``HEADING_VALUE_MIN`` +
1611        ``HEADING_VALUE_RANGE``) are wrapped by modulo ``HEADING_VALUE_RANGE``; a
1612        wrapped value above ``HEADING_VALUE_MAX`` goes to the nearer of
1613        ``HEADING_VALUE_MIN`` and ``HEADING_VALUE_MAX`` (``HEADING_VALUE_MAX`` on a
1614        tie).
1615
1616        Args:
1617            values (np.typing.NDArray[np.float64]): Raw headings, in decimal degrees.
1618
1619        Returns:
1620            np.typing.NDArray[np.float64]: The headings wrapped into
1621                [``HEADING_VALUE_MIN``, ``HEADING_VALUE_MAX``].
1622
1623        Complexity:
1624            - Time: O(c), at most c - 1 values (the chain pairs), vectorized
1625              comparisons and modulo.
1626            - Space: O(c), the returned array and the temporary masks.
1627        """
1628        in_range = (values >= HEADING_VALUE_MIN) & (
1629            values < HEADING_VALUE_MIN + HEADING_VALUE_RANGE
1630        )
1631        wrapped = np.where(
1632            in_range,
1633            values,
1634            (values - HEADING_VALUE_MIN) % HEADING_VALUE_RANGE + HEADING_VALUE_MIN,
1635        )
1636        # Values between HEADING_VALUE_MAX and the full turn go to the nearer bound
1637        above_max = wrapped > HEADING_VALUE_MAX
1638        to_minimum = HEADING_VALUE_MIN + HEADING_VALUE_RANGE - wrapped[above_max]
1639        to_maximum = wrapped[above_max] - HEADING_VALUE_MAX
1640        wrapped[above_max] = np.where(
1641            to_minimum < to_maximum, HEADING_VALUE_MIN, HEADING_VALUE_MAX
1642        )
1643        return wrapped

1648    ) -> np.typing.NDArray[np.float64]:
1649        """Wrap longitudes, mirroring the ``wrap_longitude`` validator of ``ReferencePosition``.
1650
1651        Values outside [``LONGITUDE_MIN``, ``LONGITUDE_MIN`` + ``LONGITUDE_RANGE``)
1652        are wrapped by modulo ``LONGITUDE_RANGE``; values in range are returned
1653        unchanged.
1654
1655        Args:
1656            values (np.typing.NDArray[np.float64]): Raw longitudes, in decimal degrees.
1657
1658        Returns:
1659            np.typing.NDArray[np.float64]: The longitudes wrapped into
1660                [``LONGITUDE_MIN``, ``LONGITUDE_MIN`` + ``LONGITUDE_RANGE``).
1661
1662        Complexity:
1663            - Time: O(c), one longitude per chain point, vectorized comparisons and
1664              modulo.
1665            - Space: O(c), the returned array and the temporary mask.
1666        """
1667        in_range = (values >= LONGITUDE_MIN) & (
1668            values < LONGITUDE_MIN + LONGITUDE_RANGE
1669        )
1670        return np.where(
1671            in_range, values, (values - LONGITUDE_MIN) % LONGITUDE_RANGE + LONGITUDE_MIN
1672        )
