Source code for step_adapter.point_dataset

   1"""Position dataset management with Hermite and cubic spline interpolation.
   2
   3Processes raw, irregularly-timed position measurements (e.g. GNSS fixes from CAM
   4messages) into smooth, regularly-sampled trajectories, using Hermite interpolation
   5of latitude and longitude and cubic spline interpolation of the altitude between
   6real measurements (``GapFiller.fill``).
   7
   8Main components:
   9    - ``PointDatasetConfig``: immutable, validated processing parameters (queue
  10      size bounds, period/deviation limits, output period); the resampling ones
  11      are validated by the ``GapFillerConfig`` it builds.
  12    - ``PointDataset``: per-actor dataset manager. Checks each incoming
  13      position against the coherence rules, then either appends it directly
  14      (consecutive positions close to the nominal output period), has its
  15      ``GapFiller`` generate interpolated positions to fill the gap (larger
  16      temporal gaps), rejects it, or clears the history and restarts the
  17      trajectory from it.
  18
  19Coherence rules:
  20    ``PointDataset._COHERENCE_RULES`` binds every check of a new position to the
  21    action taken when it fails (``CoherenceRule``); the checks run in order and
  22    the first failure decides the action of ``PointDataset.add_point``, so the
  23    order is also the precedence:
  24
  25    #. Local time (REJECT): the position time must be within
  26       ``input_max_local_time_deviation_ms`` of the local clock. The reference
  27       is the clock, not the history, so the new position is wrong; being
  28       first, a stale or future-dated position never clears the history.
  29    #. Minimum period (REJECT): a position too close to, or not following, the
  30       last one is a downsampling or an out-of-order message. A last position in
  31       the future can be ahead by at most the local time deviation, so such a
  32       block ends by itself.
  33    #. Maximum period (RESTART): a gap above ``input_max_period_ms`` makes
  34       neither position wrong, but interpolating across it is not meaningful.
  35    #. Speed against a confirmed history (REJECT): with at least
  36       ``PointDataset.CONFIRMED_HISTORY_POINT_NUMBER_MIN`` positions, each one
  37       coherent in speed with the previous, the trajectory confirms itself, so a
  38       speed above ``PointDataset.SPEED_COHERENCE_THRESHOLD`` points at the new
  39       position (e.g. an isolated GNSS jump), which is discarded and never
  40       published.
  41    #. Speed against a single position (RESTART): nothing confirms the last
  42       position, so the trajectory restarts from the new one.
  43
  44    A wrong history recovers by itself: rejected positions do not update the
  45    last time, so within ``input_max_period_ms`` the maximum period rule
  46    restarts the trajectory; the worst case is an output gap of that length for
  47    the actor.
  48
  49Let:
  50    - n = ``input_max_point_number``, the input queue size (5-30).
  51    - k = number of interpolated positions generated by one insertion, bounded
  52      by ``input_max_period_ms`` / (output nominal period - output deviation).
  53
  54Thread Safety:
  55    This module is **NOT thread-safe**. Concurrent access requires external
  56    synchronization (e.g. one ``PointDataset`` per thread per actor, or a lock
  57    around a shared instance).
  58
  59Note:
  60    A restart clears the history rather than interpolating across a likely
  61    discontinuity, which may produce temporary output gaps; downstream consumers
  62    needing continuous output should buffer accordingly.
  63
  64Complexity:
  65    - Time: O(n + k*log(n)), dominated by PointDataset.add_point on the
  66      interpolation path (spline construction O(n), evaluation O(k*log(n))).
  67    - Space: O(n + k), dominated by PointDataset: history buffers of n + 1
  68      entries plus the transient interpolation buffers and output.
  69
  70Classes:
  71    - PointDatasetConfig: Validated, immutable processing parameters.
  72      Complexity: time O(1), space O(1).
  73    - InsertPointResult: Outcome of a coherence check of a new position.
  74      Complexity: time O(1), space O(1).
  75    - CoherenceAction: Action taken on a new position after its checks.
  76      Complexity: time O(1), space O(1).
  77    - CoherenceCheck: Coherence result with its action and the reusable
  78      distance/heading. Complexity: time O(1), space O(1).
  79    - CoherenceInput: Positions a coherence check works on.
  80      Complexity: time O(1), space O(1).
  81    - CoherenceRule: A coherence check bound to the action of its failure.
  82      Complexity: time O(1), space O(1).

 366class PointDataset:
 367    """Per-actor position dataset with Hermite and cubic spline interpolation.
 368
 369    Maintains a bounded history of recent position measurements for a single actor
 370    (a deque of at most n ``PositionInfoRecord`` plus four pre-allocated numpy
 371    buffers of n + 1 entries) and, on each ``add_point()`` call, either appends the
 372    new position directly (consecutive positions close to the nominal output period)
 373    or has its ``GapFiller`` fill the gap with interpolated positions (larger gaps). Every
 374    new position is checked against ``_COHERENCE_RULES`` (see the module overview):
 375    the first failed rule rejects the position or clears the history and restarts
 376    the trajectory from it. Speed and heading of the returned positions are always
 377    recomputed from the geodesic displacement.
 378
 379    Attributes:
 380        actor_par (ActorId): The actor identifier for this dataset instance.
 381        config (PointDatasetConfig): Configuration object containing dataset parameters
 382            including input_max_point_number for queue and array sizing.
 383        logger (Logger): Logger instance for recording events and debugging information.
 384
 385    Thread Safety:
 386        This class is **NOT thread-safe**. Concurrent access from multiple threads
 387        requires external synchronization (e.g. one instance per thread per actor).
 388
 389    Example:
 390        >>> config = PointDatasetConfig(
 391        ...     input_max_point_number=20,
 392        ...     input_min_altitude_trailing_point_percent=25,
 393        ...     input_max_period_ms=2000,
 394        ...     input_max_local_time_deviation_ms=5000,
 395        ...     output_nominal_period_ms=200,  # 5 Hz
 396        ...     output_max_period_deviation_ms=20,
 397        ... )
 398        >>> from datetime import UTC, datetime
 399        >>> from step_cloud_schemas import ItsTime
 400        >>> now = str(ItsTime.create_from_datetime(datetime.now(tz=UTC)))
 401        >>> position_info = PositionInfo.model_validate(
 402        ...     obj=PositionInfo.get_default().model_dump() | {"time": now}
 403        ... )
 404        >>> actor_id = ActorId(
 405        ...     station_id=position_info.stationInfo.stationId,
 406        ...     object_id=position_info.objectId,
 407        ... )
 408        >>> dataset = PointDataset(
 409        ...     actor_par=actor_id, config=config, logger=logging.getLogger(__name__)
 410        ... )
 411        >>> result = dataset.add_point(new_position=position_info)
 412        >>> result == [position_info]  # the first position is returned as-is
 413        True
 414
 415    Note:
 416        Interpolation quality depends on input point density and temporal
 417        distribution; a minimum of 2 points is required (handled automatically),
 418        and insufficient coverage may cause extrapolation artifacts (mitigated by
 419        ``extrapolate=False`` in spline evaluation).
 420
 421    Complexity:
 422        - Time: O(n + k*log(n)), driven by add_point on the interpolation path
 423          (see GapFiller.fill).
 424        - Space: O(n + k), the O(n) history buffers allocated by __init__ plus the
 425          O(n + k) transient buffers and output of the interpolation path.
 426    """

 570    def _populate_input_arrays(self, new_position: PositionInfoRecord) -> int:
 571        """Populate the pre-allocated input arrays from the queue plus ``new_position``.
 572
 573        Writes timestamps, latitudes, longitudes and altitudes of the queued points,
 574        oldest first, followed by ``new_position``; a missing altitude is stored as
 575        NaN.
 576
 577        Args:
 578            new_position (PositionInfoRecord): The new position appended after the
 579                queued points.
 580
 581        Returns:
 582            int: Number of populated points (queued points plus ``new_position``),
 583                capped at the input array size.
 584
 585        Raises:
 586            ValueError: If the input queue is empty.
 587
 588        Complexity:
 589            - Time: O(n), one pass over the n queued points.
 590            - Space: O(1), the input buffers are pre-allocated.
 591        """
 592        queue_len = len(self._input_points_queue)
 593        if queue_len == 0:
 594            raise ValueError(
 595                f"{self._actor}: insufficient points to create interpolators, the queue is empty"
 596            )
 597        np_points_len = min(self._np_input_points_timestamp_ms.size, queue_len + 1)
 598        # Single pass through queue to populate arrays directly, NaN for a missing altitude
 599        for point_index, position_info_record in enumerate(self._input_points_queue):
 600            reference_position = position_info_record.position.position
 601            self._np_input_points_timestamp_ms[point_index] = (
 602                position_info_record.time.epoch_ms
 603            )
 604            self._np_input_points_latitude[point_index] = reference_position.latitude
 605            self._np_input_points_longitude[point_index] = reference_position.longitude
 606            self._np_input_points_altitude[point_index] = (
 607                reference_position.altitude.value
 608                if reference_position.altitude
 609                else np.nan
 610            )
 611        new_reference_position = new_position.position.position
 612        self._np_input_points_timestamp_ms[np_points_len - 1] = (
 613            new_position.time.epoch_ms
 614        )
 615        self._np_input_points_latitude[np_points_len - 1] = (
 616            new_reference_position.latitude
 617        )
 618        self._np_input_points_longitude[np_points_len - 1] = (
 619            new_reference_position.longitude
 620        )
 621        self._np_input_points_altitude[np_points_len - 1] = (
 622            new_reference_position.altitude.value
 623            if new_reference_position.altitude
 624            else np.nan
 625        )
 626        return np_points_len

 628    def _create_positions_list(
 629        self,
 630        actor: ActorId,
 631        new_position: PositionInfoRecord,
 632        last_position_distance_heading: DistanceHeading | None,
 633    ) -> list[PositionInfo]:
 634        """Create the list of positions from the last queued position to the new one.
 635
 636        Two paths, chosen by the temporal gap to the last queued position:
 637
 638            #. **Fast path** (gap within the nominal output period + deviation): the new
 639               position is returned as-is with speed/heading recomputed from
 640               ``last_position_distance_heading`` - the distance/heading pair the caller's
 641               coherence check already computed for this exact pair of points, so no
 642               further ``Geocode`` call is made here.
 643            #. **Interpolation path** (gap exceeds the threshold):
 644               ``_populate_input_arrays`` fills the input buffers from the queue plus
 645               the new position, and ``GapFiller.fill`` evaluates the Hermite segment
 646               between the two positions and the altitude spline on the buffers, and
 647               returns k+1 positions (k interpolated + the real new position), using a
 648               single vectorized geodesic call over the whole chain, instead of one
 649               scalar call per point.
 650
 651        In both paths the new position record is then appended to the input queue, and
 652        the speed/heading reported by the CAM sender are not preserved on the returned
 653        position - they are always recomputed from the geodesic displacement relative
 654        to the previous point. The queued record keeps them, for the Hermite tangents.
 655
 656        Args:
 657            actor (ActorId): The actor identifier, used for logging.
 658            new_position (PositionInfoRecord): The newly arrived position record.
 659            last_position_distance_heading (DistanceHeading | None): Distance/heading
 660                from the last queued position to ``new_position``, as computed by
 661                ``_check_position_coherence``. Required (non-None) on the fast path.
 662
 663        Returns:
 664            list[PositionInfo]: Fast path: a single-element list with the real
 665                position. Interpolation path: k interpolated positions
 666                (``POSITION_*_ESTIMATED``) followed by the real position.
 667
 668        Raises:
 669            StepAdapterError: If the input queue is empty, or if
 670                ``last_position_distance_heading`` is missing on the fast path.
 671
 672        Complexity:
 673            - Time: O(1) on the fast path; O(n + k*log(n)) on the interpolation path,
 674              dominated by ``GapFiller.fill``.
 675            - Space: O(1) on the fast path; O(n + k) on the interpolation path.
 676        """
 677        if len(self._input_points_queue) == 0:
 678            raise StepAdapterError(
 679                f"{actor}: positions list error due to input queue being empty"
 680            )
 681        last_queued = self._input_points_queue[-1]
 682        diff_time_ms = new_position.time.time_difference(other_time=last_queued.time)
 683        # No interpolation needed - just return new position
 684        if (
 685            diff_time_ms
 686            <= self._config.output_nominal_period_ms
 687            + self._config.output_max_period_deviation_ms
 688        ):
 689            if last_position_distance_heading is None:
 690                raise StepAdapterError(
 691                    f"{actor}: missing precomputed distance/heading for the fast path"
 692                )
 693            new_real_position = self._gap_filler.apply_motion(
 694                position=new_position.position,
 695                distance_m=last_position_distance_heading.distance,
 696                heading_deg=last_position_distance_heading.heading,
 697                time_diff_ms=diff_time_ms,
 698            )
 699            self._input_points_queue.append(new_position)
 700            return [new_real_position]
 701        np_points_len = self._populate_input_arrays(new_position=new_position)
 702        positions = self._gap_filler.fill(
 703            actor=actor,
 704            history_times_ms=self._np_input_points_timestamp_ms[:np_points_len],
 705            history_latitudes=self._np_input_points_latitude[:np_points_len],
 706            history_longitudes=self._np_input_points_longitude[:np_points_len],
 707            history_altitudes_m=self._np_input_points_altitude[:np_points_len],
 708            last_record=last_queued,
 709            new_record=new_position,
 710        )
 711        self._input_points_queue.append(new_position)
 712        return positions

 714    def _check_local_time(
 715        self: "PointDataset", coherence_input: CoherenceInput
 716    ) -> CoherenceCheck:
 717        """Check the new position time against the local system time.
 718
 719        The position time must be within ``input_max_local_time_deviation_ms`` of
 720        the local system time, also for the first position; a failure is logged as a
 721        warning. The reference is the local clock, not the history, so a failure
 722        always means the new position is wrong.
 723
 724        Args:
 725            coherence_input (CoherenceInput): The positions to check; only the new
 726                one is used.
 727
 728        Returns:
 729            CoherenceCheck: SUCCESS when the time is within the deviation,
 730                LOCAL_TIME_NOT_COHERENT_ERROR otherwise; never a distance/heading.
 731
 732        Complexity:
 733            - Time: O(1), one clock read and two comparisons.
 734            - Space: O(1), a single ``ItsTime`` is allocated.
 735        """
 736        new_position_time = coherence_input.new_record.time
 737        now = ItsTime()
 738        result = InsertPointResult.SUCCESS
 739        if not (
 740            now.epoch_ms - self._config.input_max_local_time_deviation_ms
 741            <= new_position_time.epoch_ms
 742            <= now.epoch_ms + self._config.input_max_local_time_deviation_ms
 743        ):
 744            if self._logger.isEnabledFor(level=logging.WARNING):
 745                self._logger.warning(
 746                    msg=(
 747                        f"{self._actor}: new position time {new_position_time} "
 748                        f"is not coherent with local system time {now} "
 749                        f"due to deviation threshold of {self._config.input_max_local_time_deviation_ms} ms"
 750                    )
 751                )
 752            result = InsertPointResult.LOCAL_TIME_NOT_COHERENT_ERROR
 753        return CoherenceCheck(result=result, distance_heading=None)

 755    def _check_minimum_period(
 756        self: "PointDataset", coherence_input: CoherenceInput
 757    ) -> CoherenceCheck:
 758        """Check that the new position does not come too soon after the last one.
 759
 760        The time from the last position must not be below the nominal output period
 761        minus the deviation (which also covers a position not following the last
 762        one); a failure is logged as a warning. Without a last position there is
 763        nothing to check.
 764
 765        Args:
 766            coherence_input (CoherenceInput): The positions to check.
 767
 768        Returns:
 769            CoherenceCheck: SUCCESS when the time reaches the minimum period or there
 770                is no last position, PERIOD_TOO_SHORT_ERROR otherwise; never a
 771                distance/heading.
 772
 773        Complexity:
 774            - Time: O(1), one time difference and one comparison.
 775            - Space: O(1), a fixed number of local variables.
 776        """
 777        result = InsertPointResult.SUCCESS
 778        if coherence_input.last_record is not None:
 779            new_position_time = coherence_input.new_record.time
 780            last_position_time = coherence_input.last_record.time
 781            diff_time_ms = new_position_time.time_difference(
 782                other_time=last_position_time
 783            )
 784            minimum_period = (
 785                self._config.output_nominal_period_ms
 786                - self._config.output_max_period_deviation_ms
 787            )
 788            if diff_time_ms < minimum_period:
 789                if self._logger.isEnabledFor(level=logging.WARNING):
 790                    self._logger.warning(
 791                        msg=(
 792                            f"{self._actor}: new position time {new_position_time} "
 793                            f"is too close (min {minimum_period} ms) to last position time "
 794                            f"{last_position_time}, diff time {diff_time_ms} ms"
 795                        )
 796                    )
 797                result = InsertPointResult.PERIOD_TOO_SHORT_ERROR
 798        return CoherenceCheck(result=result, distance_heading=None)

 840    def _check_speed(self, coherence_input: CoherenceInput) -> CoherenceCheck:
 841        """Check the speed implied by the displacement from the last position.
 842
 843        Computes the geodesic distance and heading between the two positions with a
 844        single ``Geocode`` (a local, throwaway instance: there is no per-call state
 845        worth reusing) and the implied speed; a speed above
 846        ``SPEED_COHERENCE_THRESHOLD`` m/s is logged as a warning. It follows the
 847        period checks in ``_COHERENCE_RULES``, which grant a strictly positive
 848        elapsed time. Without a last position there is nothing to check.
 849
 850        Args:
 851            coherence_input (CoherenceInput): The positions to check.
 852
 853        Returns:
 854            CoherenceCheck: SUCCESS with the (distance, heading) from the last
 855                position to the new one, SUCCESS without distance/heading when there
 856                is no last position, or POSITION_ERROR without distance/heading when
 857                the speed exceeds the threshold.
 858
 859        Complexity:
 860            - Time: O(1), one geodesic distance/heading computation.
 861            - Space: O(1), a fixed number of local variables.
 862        """
 863        coherence = CoherenceCheck(
 864            result=InsertPointResult.SUCCESS, distance_heading=None
 865        )
 866        if coherence_input.last_record is not None:
 867            new_position = coherence_input.new_record.position
 868            last_position = coherence_input.last_record.position
 869            diff_time_ms = coherence_input.new_record.time.time_difference(
 870                other_time=coherence_input.last_record.time
 871            )
 872            geocode = Geocode(
 873                point_a_par=LatLonPoint(
 874                    last_position.position.latitude, last_position.position.longitude
 875                ),
 876                point_b_par=LatLonPoint(
 877                    new_position.position.latitude, new_position.position.longitude
 878                ),
 879            )
 880            distance_m = geocode.get_distance(unit=DistanceUnit.METERS)
 881            heading_deg = geocode.get_heading(unit=AngleUnit.DEGREES)
 882            speed = (distance_m * ItsTime.SEC_TO_MS_FACTOR) / diff_time_ms
 883            if speed > self.SPEED_COHERENCE_THRESHOLD:
 884                if self._logger.isEnabledFor(level=logging.WARNING):
 885                    self._logger.warning(
 886                        msg=(
 887                            f"{self._actor}: position speed {speed} m/s exceeds threshold "
 888                            f"{self.SPEED_COHERENCE_THRESHOLD} m/s"
 889                        )
 890                    )
 891                coherence = CoherenceCheck(
 892                    result=InsertPointResult.POSITION_ERROR, distance_heading=None
 893                )
 894            else:
 895                coherence = CoherenceCheck(
 896                    result=InsertPointResult.SUCCESS,
 897                    distance_heading=DistanceHeading(distance_m, heading_deg),
 898                )
 899        return coherence

 981    def _check_position_coherence(
 982        self, new_record: PositionInfoRecord, last_record: PositionInfoRecord | None
 983    ) -> CoherenceCheck:
 984        """Run the coherence rules on a new position; the first failure decides.
 985
 986        Runs the checks of ``_COHERENCE_RULES`` in order and stops at the first one
 987        that fails, returning its result with the ``failure_action`` of its rule:
 988
 989            #. Local time (``_check_local_time``, REJECT): also for the first
 990               position; being first, a stale or future-dated position is always
 991               rejected and never clears the history.
 992            #. Minimum period (``_check_minimum_period``, REJECT).
 993            #. Maximum period (``_check_maximum_period``, RESTART).
 994            #. Speed coherence against a confirmed history of at least
 995               ``CONFIRMED_HISTORY_POINT_NUMBER_MIN`` positions
 996               (``_check_speed_from_confirmed_history``, REJECT): the new position is
 997               the likely outlier.
 998            #. Speed coherence against a single, unconfirmed position
 999               (``_check_speed_from_unconfirmed_history``, RESTART).
1000
1001        Every failure is logged as a warning by its check. When every check passes,
1002        the result is SUCCESS with action ACCEPT and the distance/heading of the speed
1003        check, so callers on the fast path (see ``_create_positions_list``) can reuse
1004        it instead of issuing another ``Geocode`` call for the same pair of points.
1005
1006        Args:
1007            new_record (PositionInfoRecord): The new position and its parsed time.
1008            last_record (PositionInfoRecord | None): The last queued position and its
1009                parsed time, None for the first position.
1010
1011        Returns:
1012            CoherenceCheck: The first failure with the action of its rule, or SUCCESS
1013                with action ACCEPT and the (distance, heading) from the last position
1014                to the new one (None for the first position).
1015
1016        Complexity:
1017            - Time: O(1), a fixed number of rules: the local time comparison, the
1018              period bounds and one geodesic distance/heading computation.
1019            - Space: O(1), a fixed number of local variables.
1020        """
1021        coherence_input = CoherenceInput(new_record=new_record, last_record=last_record)
1022        coherence = CoherenceCheck(
1023            result=InsertPointResult.SUCCESS, distance_heading=None
1024        )
1025        for rule in self._COHERENCE_RULES:
1026            check = rule.check(self, coherence_input)
1027            if check.result != InsertPointResult.SUCCESS:
1028                coherence = check._replace(action=rule.failure_action)
1029                break
1030            if check.distance_heading is not None:
1031                coherence = check
1032        return coherence

1067    def add_point(self, new_position: PositionInfo) -> list[PositionInfo] | None:
1068        """Validate and add a new position to the actor trajectory.
1069
1070        Rejects positions belonging to a different actor. Otherwise runs the
1071        coherence rules (``_check_position_coherence``, ``_COHERENCE_RULES``) and
1072        takes the action they return:
1073
1074            - ACCEPT: the first position is appended as-is; subsequent positions are
1075              delegated to ``_create_positions_list``, which either appends directly
1076              or fills the gap with interpolated positions.
1077            - RESTART (a gap exceeding ``input_max_period_ms``, or an implied speed
1078              above ``SPEED_COHERENCE_THRESHOLD`` against a single, unconfirmed
1079              position): the history is cleared and the trajectory restarts from the
1080              new position.
1081            - REJECT (not coherent with the local time, checked first, arriving too
1082              soon after the last position, or an implied speed above
1083              ``SPEED_COHERENCE_THRESHOLD`` against a confirmed history): the
1084              position is discarded (``None``) and the history is kept.
1085
1086        Args:
1087            new_position (PositionInfo): Position measurement, including coordinates
1088                and an ISO 8601 timestamp.
1089
1090        Returns:
1091            list[PositionInfo] | None:
1092
1093                - ``None``: actor mismatch or REJECT.
1094                - Single-element list: first position, RESTART, or no interpolation
1095                  needed.
1096                - k+1-element list: k interpolated positions (``POSITION_*_ESTIMATED``)
1097                  followed by the real position.
1098
1099        Raises:

1101                ``_create_positions_list``).

1105            access. Debug logs are emitted for first positions/restarts, warnings for
1106            validation failures - consider log volume in high-throughput scenarios.

1122                )
1123            return None

1125        coherence = self._check_position_coherence(

1127            last_record=(

1130        )

1149                    new_position_time=new_position_record.time,
