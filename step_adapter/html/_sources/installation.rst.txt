============
Installation
============

STEP Adapter works on Windows, Linux and MacOS. Please follow the instructions below
to build and run an example in your specific environment.

------------------------------
Installing from git repository
------------------------------

The command to install the library is:

.. code-block:: bash

   $pip install git+https://gitlab.automotive.vodafone.com/vfa-init/pnrr/step_adapter.git@step_adapter_<version>#egg=step_adapter
