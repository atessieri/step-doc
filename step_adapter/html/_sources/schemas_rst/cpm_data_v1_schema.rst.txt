CPM Data V1 Schema
==================

The CPM (Collective Perception Message) Data Schema defines the structure for the objects perceived
by an ITS station in the C-ITS system. This schema captures essential data including:

    * Reference time, station id and reference position of the sender
    * Identification and type of each perceived object, with its confidence
    * Measurement time, position and kinematics (speed, heading) of each perceived object
    * Physical characteristics of each perceived object (dimensions X, Y and Z)
    * Perception quality and predicted path of each perceived object

This schema defines a JSON Schema **version 1**. For further information, please refer
to the python classes.
