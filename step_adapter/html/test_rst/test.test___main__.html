test.test___main__ module

Test suite for the step_adapter.__main__ module.

This module provides comprehensive unit tests for the main entry point and core functionality of the STEP Adapter application. The tests cover the command-line interface, configuration handling, signal processing, and the main application lifecycle.

Test Coverage:

  • ExitCode enumeration validation

  • Command-line argument parsing and validation

  • Signal handling and shutdown procedures

  • Configuration file management (schema and template files)

  • Main application lifecycle and error handling

  • Exception handling and logging

  • Redis stream operations and data processing

  • Interrupt handling and graceful shutdown

Key Test Classes:

  • TestExitCode: Validates the ExitCode enumeration values and structure

Key Test Functions:

  • test_shutdown: Validates signal-based shutdown handling

  • test_args_parse: Tests command-line argument parsing

  • test_exception_handler: Validates exception handling and logging

  • test_get_config_schema_file: Tests configuration schema file retrieval

  • test_get_config_template_file: Tests configuration template file retrieval

  • test_main: Tests the main application entry point

  • test_main_interrupt_exception: Tests interrupt handling during execution

The test suite uses pytest for test execution and pytest-mock for mocking external dependencies, ensuring isolated and reliable unit tests.
