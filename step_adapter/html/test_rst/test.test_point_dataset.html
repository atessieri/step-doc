test.test_point_dataset module

Test module for PointDataset and PointDatasetConfig classes.

This module provides comprehensive unit tests for the point_dataset module, testing both the configuration validation and core functionality of point data management.

Test Classes:

  • TestPointDatasetConfig: Tests for PointDatasetConfig class validation and initialization, ensuring proper parameter validation and error handling for invalid configurations.

  • TestInsertPointResult: Tests for InsertPointResult enum, verifying enum values and length.

  • TestPointDataset: Comprehensive test suite for the PointDataset class, covering:

    • Object initialization and configuration

    • Property access and string representations

    • Point addition with various parameter combinations

    • Vehicle dimension tracking and updates

    • Time management and last record tracking

    • History clearing functionality

    • Optimal period calculation for interpolation

    • Interpolated timestamp and position array generation

    • Position list creation with interpolation

    • Position coherence validation (temporal and spatial consistency)

The tests utilize parameterized testing to verify behavior across multiple scenarios and edge cases, ensuring robust validation of the PointDataset implementation. Mock objects are used for logger instances to isolate testing from external dependencies.
