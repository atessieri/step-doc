   1"""STEP Producer Main Module.
   2
   3This module serves as the main entry point for the STEP Producer service, which is responsible
   4for processing and managing Decentralized Environmental Notification Messages (DENM) within
   5the Intelligent Transportation Systems (ITS) ecosystem.
   6
   7Overview:
   8    The STEP Producer is a Redis-based microservice that:
   9
  10    - Listens to Redis streams for incoming collision prediction data
  11    - Processes DENM records and station collision arrays
  12    - Manages the lifecycle of DENM messages with periodic cleanup
  13    - Provides signal handling for graceful shutdown
  14    - Supports configuration via JSON files with schema validation
  15
  16Key Components:
  17
  18    - Command-line interface with argument parsing for configuration management
  19    - Asynchronous Redis stream consumer for real-time message processing
  20    - DEN (Decentralized Environmental Notification) service manager
  21    - Configurable logging and error handling
  22    - Cross-platform signal handling (Windows and Unix-like systems)
  23
  24Architecture:
  25    The service operates using an event-driven architecture with the following workflow:
  26
  27    #. Initialize configuration from command-line arguments
  28    #. Establish Redis connection pool for stream operations
  29    #. Create asynchronous task groups for concurrent processing:
  30
  31        - Stream message reception and processing
  32        - Periodic DENM message cleanup
  33
  34    #. Handle system signals for graceful shutdown
  35    #. Automatic reconnection with configurable retry intervals
  36
  37Message Types Processed:
  38
  39    - ProducerCloudEventsDenmDataV1: Individual DENM records
  40    - ProducerCloudEventsStationCollisionArrayV1: Arrays of station collision data
  41
  42Usage:
  43    The module can be executed directly with various command-line options:
  44
  45        - -v, --version: Display version information
  46        - -s, --conf_schema: Generate JSON schema file for configuration
  47        - -t, --conf_template: Generate configuration template file
  48        - -c, --config: Load configuration from specified JSON file
  49        - -i, --instance: Specify the instance name
  50
  51Note:
  52    When the module uses the `-c` or `--config` option, also the -i or --instance option
  53    must be specified to set the instance name.
  54
  55Example:
  56    >>> python -m step_producer -c config.json
  57
  58Exit Codes:
  59
  60    - 0 (OK): Successful execution
  61    - 1 (USAGE): Invalid command-line usage
  62    - 2 (ERROR): General execution error
  63    - 3 (ABORTED): Process interrupted by signal
  64
  65Complexity:
  66    - Time: dominated by the three tasks spawned by _main_async
  67      (_stream_receive_run, _periodical_cleanup_run,
  68      _redis_health_check_run), which run indefinitely; the heaviest
  69      bounded per-call operation is _stream_receive_run's
  70      O(k log k + k log N) dispatch to
  71      DenServiceManager.process_station_collisions_received, k = stations
  72      in a collision array message, N = total tracked DENM records.
  73    - Space: O(k), for the same call's returned message list; O(1)
  74      elsewhere.
  75
  76Functions:
  77    - _exception_handler: Logs uncaught asyncio event loop exceptions.
  78      Complexity: time O(1), space O(1).
  79    - _periodical_cleanup_run: Periodically cleans up expired DENM records
  80      and publishes cancellations, indefinitely. Complexity: time O(m log N)
  81      per iteration, space O(m) per iteration.
  82    - _denm_message_handler: Times and dispatches a received DENM record
  83      message to the DEN service. Complexity: time O(log N), space O(1).
  84    - _station_collision_array_message_handler: Times a station collision
  85      array message, derives DENM messages from it, and publishes each
  86      one to the client Redis stream. Complexity: time O(k log k + k
  87      log N), space O(k).
  88    - _stream_receive_run: Listens to the Redis input stream and dispatches
  89      DENM/station-collision messages, indefinitely. Complexity: time
  90      O(k log k + k log N) per station-collision message (O(log N)
  91      for a DENM record), space O(k) per station-collision message.
  92    - _redis_health_check_run: Runs a continuous Redis stream health check
  93      loop. Complexity: time O(1) per iteration, space O(1).
  94    - _redis_params_convert: Converts a RedisConnection config into
  95      StepRedisPoolParams. Complexity: time O(1), space O(1).
  96    - _wait_for_shutdown: Waits on a shutdown Event, then raises
  97      ShutdownRequestedError to unwind _main_async's TaskGroup on
  98      SIGINT/SIGTERM. Complexity: time O(1) once set, space O(1).
  99    - _main_async: Asynchronous main loop; sets up Redis and runs the four
 100      concurrent tasks above (including the shutdown watcher), reconnecting
 101      on failure. Complexity: dominated by the concurrent tasks above.
 102    - _get_config_schema_file: Writes the configuration JSON schema file.
 103      Complexity: time O(1) relative to input size, space O(1) relative
 104      to input size.
 105    - _get_config_template_file: Writes the configuration template file.
 106      Complexity: time O(1) relative to input size, space O(1) relative
 107      to input size.
 108    - _stream_ttl_seconds: Computes the Redis stream consumer TTL from a wait
 109      timeout. Complexity: time O(1), space O(1).
 110    - _signal_handler: Requests a cooperative Windows shutdown, or raises
 111      KeyboardInterrupt when no shutdown state is published (POSIX
 112      SIGINT/SIGTERM normally set the shutdown Event via
 113      loop.add_signal_handler, see _main_async). Complexity: time O(1),
 114      space O(1).
 115    - _signals_install: Registers _signal_handler for the process shutdown
 116      signals. Complexity: time O(1), space O(1).
 117    - _args_parse: Builds the command-line argument parser. Complexity: time
 118      O(1), space O(1).
 119    - _get_redis_credential: Loads Redis connection details from environment
 120      variables. Complexity: time O(1), space O(1).
 121    - main: Program entry point; parses arguments, loads configuration, and
 122      runs the event loop until interrupted. Complexity: time O(1) for
 123      setup, dominated thereafter by _main_async.
 124
 125Classes:
 126    - ExitCode: Enumeration of process exit codes. Complexity: time O(1),
 127      space O(1).

 224def _exception_handler(context: dict[Any, Any], logger: Logger) -> None:
 225    """Handle exceptions in asyncio event loop.
 226
 227    This function serves as an exception handler for the asyncio event loop,
 228    logging any uncaught exceptions that occur during loop execution.
 229
 230    Args:
 231        context (dict[Any, Any]): A dictionary containing contextual information about the exception.
 232            The optional 'exception' key, if present, is logged as the exception info.
 233        logger (Logger): Logger instance to record the error message.
 234
 235    Returns:
 236        None: The exception is logged as a side effect; nothing is returned.
 237
 238    Example:
 239        >>> loop = asyncio.get_running_loop()
 240        ... loop.set_exception_handler(lambda ctx: _exception_handler(ctx, logger))
 241
 242    Complexity:
 243        - Time: O(1), a single conditional log call.
 244        - Space: O(1), no additional storage.
 245    """
 246    if logger.isEnabledFor(level=logging.ERROR):
 247        logger.error(msg="Exception in loop", exc_info=context.get("exception"))

 258) -> None:
 259    """Periodically cleans up expired DENM records and publishes cancellation messages.
 260
 261    This asynchronous function runs in an infinite loop, invoking the DEN service manager's
 262    cleanup routine to identify expired DENM records. For each expired record, it publishes
 263    a cancellation message to the appropriate Redis stream. After processing, it waits for
 264    the configured interval before repeating the cleanup process.
 265
 266    Args:
 267        redis_pool (StepRedisPool): Redis connection pool for stream operations.
 268        instance_name (str): Name of the instance for Redis stream consumer.
 269        config (RedisStreams): Redis streams configuration.
 270        den_service (DenServiceManager): Service manager for DENM record handling.
 271        denm_check_last_update_interval_sec (int): Interval (in seconds) between cleanup runs.
 272        logger (Logger): Logger instance for debug and info messages.
 273
 274    Returns:
 275        None: Runs indefinitely, publishing cancellation messages as a side
 276        effect.
 277
 278    Complexity:
 279        - Time: O(m log N) per iteration (the loop itself runs
 280          indefinitely), m = expired records found in that iteration, N =
 281          total tracked DENM records; dominated by
 282          den_service.periodical_cleanup() plus one publish call per
 283          expired message.
 284        - Space: O(m) per iteration, for the list of expired messages.
 285    """
 286    logging_timer = LoggingTimer(
 287        logger=logger, prefix="step_producer", log_level=LogMode.INFO
 288    )
 289    async with StepClientRedisStream(
 290        pool=redis_pool,
 291        config=StepRedisStreamParams(
 292            stream_id=config.outputs.client.streamId,
 293            published_message_max_retained=config.outputs.client.maxLength,
 294            consumer_name=instance_name,
 295        ),
 296        logger=logger,
 297    ) as redis_stream:
 298        while True:
 299            with logging_timer(_periodical_cleanup_run):
 300                if logger.isEnabledFor(level=logging.DEBUG):
 301                    logger.debug(msg="Running DENM periodical cleanup")
 302                for message in den_service.periodical_cleanup():
 303                    await redis_stream.publish_denm_message(message=message)
 304            await asyncio_sleep(delay=denm_check_last_update_interval_sec)

 386async def _stream_receive_run(
 387    instance_name: str,
 388    config: RedisStreams,
 389    logger: Logger,
 390    redis_pool: StepRedisPool,
 391    den_service: DenServiceManager,
 392) -> None:
 393    """Asynchronously listens to a Redis stream for incoming messages and processes them
 394    based on their type.
 395
 396    Behavior:
 397        - Establishes a connection to the Redis stream as a consumer.
 398        - Continuously listens for new messages from the stream.
 399        - Processes messages of type ``ProducerCloudEventsDenmDataV1``
 400          by invoking ``process_denm_record_received``.
 401        - Processes messages of type ``ProducerCloudEventsStationCollisionArrayV1``
 402          by invoking ``process_station_collisions_received``.
 403        - Logs a warning for unknown message types.
 404
 405    Args:
 406        instance_name (str): The name of the instance.
 407        config (RedisStreams): Configuration object containing Redis
 408            stream and instance settings.
 409        logger (Logger): Logger instance for logging information, debug,
 410            and warning messages.
 411        redis_pool (StepRedisPool): Redis connection pool for managing
 412            Redis connections.
 413        den_service (DenServiceManager): Service manager responsible for
 414            processing DENM and station collision messages.
 415
 416    Returns:
 417        None: Runs indefinitely, publishing derived DENM messages as a side
 418        effect.
 419
 420    Complexity:
 421        - Time: per message, O(log N) for a DENM record (delegates to
 422          den_service.process_denm_record_received) or O(k log k) for a
 423          station collision array (delegates to
 424          den_service.process_station_collisions_received), where N =
 425          total tracked DENM records and k = stations in that message;
 426          the loop itself runs indefinitely.
 427        - Space: O(k) per station-collision message, for the returned list
 428          of messages to publish; O(1) otherwise.
 429    """
 430    logging_timer = LoggingTimer(
 431        logger=logger, prefix="step_producer", log_level=LogMode.INFO
 432    )
 433    async with (
 434        StepProducerRedisStream(
 435            pool=redis_pool,
 436            config=StepRedisStreamParams(
 437                stream_id=config.input.streamId,
 438                group_id=config.input.groupId,
 439                wait_timeout_ms=config.input.waitTimeout,
 440                consumer_name=instance_name,
 441                ttl_seconds=_stream_ttl_seconds(
 442                    wait_timeout_ms=config.input.waitTimeout
 443                ),
 444            ),
 445            logger=logger,
 446        ) as producer_redis_stream,
 447        StepClientRedisStream(
 448            pool=redis_pool,
 449            config=StepRedisStreamParams(
 450                stream_id=config.outputs.client.streamId,
 451                published_message_max_retained=config.outputs.client.maxLength,
 452                consumer_name=instance_name,
 453            ),
 454            logger=logger,
 455        ) as client_redis_stream,
 456    ):
 457        if logger.isEnabledFor(level=logging.INFO):
 458            logger.info(msg="Listening for messages from Redis stream")
 459        await producer_redis_stream.create_input_stream()
 460        while True:
 461            async for message in producer_redis_stream.receive_producer_message():
 462                if logger.isEnabledFor(level=logging.DEBUG):
 463                    logger.debug(msg=f"Redis message: {message}")
 464                match message.root:
 465                    case ProducerCloudEventsDenmDataV1():
 466                        _denm_message_handler(
 467                            logging_timer=logging_timer,
 468                            den_service=den_service,
 469                            message=message.root.data,
 470                        )
 471                    case ProducerCloudEventsStationCollisionArrayV1():
 472                        await _station_collision_array_message_handler(
 473                            logging_timer=logging_timer,
 474                            den_service=den_service,
 475                            client_redis_stream=client_redis_stream,
 476                            message=message.root.data,
 477                        )
 478                    case _:
 479                        if logger.isEnabledFor(level=logging.WARNING):
 480                            logger.warning(
 481                                msg=f"Unknown message type: {type(message.root)}"
 482                            )

 580async def _wait_for_shutdown(stop_event: Event, tasks: list[Task[None]]) -> None:
 581    """Wait until ``stop_event`` is set or every task in ``tasks`` finishes, whichever
 582    comes first.
 583
 584    Intended to be run as a sibling task inside ``_main_async``'s
 585    ``TaskGroup``: once a shutdown handler (a POSIX ``SIGINT``/``SIGTERM`` handler
 586    registered via ``loop.add_signal_handler``, or the Windows ``SIGBREAK`` handler,
 587    see ``_main_async``) sets ``stop_event``,
 588    this task raises ``ShutdownRequestedError``, which causes the
 589    ``TaskGroup`` to cancel its other sibling tasks and unwind the
 590    surrounding ``async with`` blocks - giving ``StepRedisPool``
 591    a chance to disconnect cleanly before ``_main_async`` returns. If instead
 592    every task in ``tasks`` finishes on its own first, this returns
 593    normally, letting the ``TaskGroup`` complete without a shutdown signal.
 594
 595    Args:
 596        stop_event (Event): Event set by the signal handler to request
 597            shutdown.
 598        tasks (list[asyncio.Task[None]]): The stream receive, periodical cleanup and
 599            Redis health check tasks to wait on; once all of them are done, this returns.
 600
 601    Returns:
 602        None: Returns normally once every task in ``tasks`` has
 603            finished, if that happens before ``stop_event`` is set.
 604
 605    Raises:
 606        ShutdownRequestedError: Raised if ``stop_event`` is set before every
 607            task in ``tasks`` finishes.
 608
 609    Complexity:
 610        - Time: O(1) once either race side resolves; unbounded wait before
 611          that.
 612        - Space: O(1), aside from the already-held ``tasks`` list.
 613    """
 614    stop_task = create_task(stop_event.wait())
 615    all_done_task = create_task(wait(tasks))
 616    try:
 617        await wait({stop_task, all_done_task}, return_when=asyncio.FIRST_COMPLETED)
 618    finally:
 619        for pending_task in (stop_task, all_done_task):
 620            if not pending_task.done():
 621                pending_task.cancel()
 622        await gather(stop_task, all_done_task, return_exceptions=True)
 623    if stop_task.done() and not stop_task.cancelled():
 624        raise ShutdownRequestedError

 627async def _main_async(  # noqa: C901, PLR0912
 628    instance_name: str,
 629    config: StepProducerConfig,
 630    redis_credential: RedisCredential,
 631    logger: Logger,
 632) -> ExitCode:
 633    """Asynchronous main entry point for the STEP Producer application.
 634
 635    This function initializes the event loop's exception handler, logs the program start,
 636    and enters a loop to manage the main application lifecycle. Within the loop, it:
 637
 638        - Establishes a Redis connection pool using StepRedisPool.
 639        - Initializes the DenServiceManager for DENM message handling.
 640        - Creates asynchronous tasks for:
 641
 642            - Receiving and processing stream data.
 643            - Periodically cleaning up DENM messages.
 644            - Running the Redis connection health check.
 645            - Watching for a shutdown request.
 646
 647    If an exception occurs, it logs the error, waits for a configured interval, and retries
 648    the connection.
 649
 650    Args:
 651        instance_name (str): The name of the instance being run.
 652        config (StepProducerConfig): Configuration object containing application settings.
 653        redis_credential (RedisCredential): Redis credential object for connecting to the Redis server.
 654        logger (Logger): Logger instance for logging messages.
 655
 656    Returns:
 657        ExitCode: Exit code indicating program result status:
 658
 659            - ExitCode.OK (0): Success
 660            - ExitCode.USAGE (1): Improper usage
 661            - ExitCode.ERROR (2): An unhandled exception occurred
 662            - ExitCode.ABORTED (3): Program was interrupted
 663
 664    Note:
 665        The function runs until a connection drop (retried after the interval specified in
 666        config) or until a POSIX SIGINT/SIGTERM is received, registered here via
 667        ``loop.add_signal_handler`` rather than a raw ``signal.signal()`` handler that raises
 668        ``KeyboardInterrupt`` directly: the latter injects the exception at whatever point in
 669        the event loop happens to be executing when the signal arrives, which can land inside
 670        one of this TaskGroup's child tasks and get wrapped in a ``BaseExceptionGroup`` that a
 671        plain ``except KeyboardInterrupt`` would not catch. ``add_signal_handler`` instead
 672        schedules ``stop_event.set()`` cooperatively via the loop itself; ``_wait_for_shutdown``
 673        turns that into a plain ``ShutdownRequestedError`` raised from a normal TaskGroup
 674        sibling task, giving deterministic, catchable unwinding of the ``async with`` above (so
 675        the Redis pool still disconnects cleanly) before this function returns normally.
 676        Windows has no ``add_signal_handler`` support at all, so its ``SIGBREAK`` handling in
 677        ``main()`` is unaffected and still raises ``KeyboardInterrupt`` directly.
 678
 679    Complexity:
 680        - Time: dominated by the three concurrently spawned tasks
 681          (_stream_receive_run, _periodical_cleanup_run,
 682          _redis_health_check_run), each of which runs indefinitely; the
 683          per-reconnect setup/teardown overhead of this function itself is
 684          O(1).
 685        - Space: O(1) additional beyond the concurrent tasks' own state.
 686    """
 687    exit_code = ExitCode.OK
 688    get_running_loop().set_exception_handler(
 689        handler=lambda _, context: _exception_handler(context=context, logger=logger)
 690    )
 691    stop_event = Event()
 692    loop = get_running_loop()
 693    if IS_WINDOWS:
 694        WindowsOsShutdownState().publish(loop=loop, stop_event=stop_event)
 695    else:
 696        for shutdown_signal in (signal.SIGINT, signal.SIGTERM):
 697            loop.add_signal_handler(shutdown_signal, stop_event.set)
 698    try:
 699        if logger.isEnabledFor(level=logging.INFO):
 700            logger.info(msg="Program started")
 701        while True:
 702            try:
 703                den_service = DenServiceManager(
 704                    station_id=config.stationId,
 705                    time_after_collision_sec=config.timeAfterCollision,
 706                    denm_last_update_max_delay_ms=config.denmLastUpdateMaxDelay,
 707                    logger=logger,
 708                )
 709                async with (
 710                    StepRedisPool(
 711                        params=_redis_params_convert(
 712                            config=config.redis.connection,
 713                            redis_credential=redis_credential,
 714                            max_connections=MAX_CONNECTIONS,
 715                        ),
 716                        logger=logger,
 717                    ) as redis_pool,
 718                    TaskGroup() as group,
 719                ):
 720                    # Create stream receive thread
 721                    tasks = [
 722                        group.create_task(
 723                            coro=_stream_receive_run(
 724                                instance_name=instance_name,
 725                                config=config.redis.streams,
 726                                logger=logger,
 727                                redis_pool=redis_pool,
 728                                den_service=den_service,
 729                            )
 730                        )
 731                    ]
 732                    # Create DENM check thread
 733                    tasks.append(
 734                        group.create_task(
 735                            coro=_periodical_cleanup_run(
 736                                redis_pool=redis_pool,
 737                                instance_name=instance_name,
 738                                config=config.redis.streams,
 739                                den_service=den_service,
 740                                denm_check_last_update_interval_sec=config.denmCheckLastUpdateInterval,
 741                                logger=logger,
 742                            )
 743                        )
 744                    )
 745                    # Create health check thread. It will check the health of the Redis connection
 746                    tasks.append(
 747                        group.create_task(
 748                            coro=_redis_health_check_run(
 749                                instance_name=instance_name,
 750                                config=config.redis.streams,
 751                                pool=redis_pool,
 752                                logger=logger,
 753                            )
 754                        )
 755                    )
 756                    # Create shutdown watcher. Unwinds the group on SIGINT/SIGTERM/SIGBREAK
 757                    group.create_task(
 758                        coro=_wait_for_shutdown(stop_event=stop_event, tasks=tasks)
 759                    )
 760            except* ShutdownRequestedError:
 761                if logger.isEnabledFor(level=logging.INFO):
 762                    logger.info(msg="Program interrupted")
 763                exit_code = ExitCode.ABORTED
 764            except* Exception:
 765                if logger.isEnabledFor(level=logging.ERROR):
 766                    logger.exception(msg="Exception unmanaged")
 767                await asyncio_sleep(delay=config.reconnectInterval)
 768                if logger.isEnabledFor(level=logging.INFO):
 769                    logger.info(
 770                        msg=f"Connection retry after {config.reconnectInterval}"
 771                    )
 772            if exit_code == ExitCode.ABORTED:
 773                break
 774    finally:
 775        if IS_WINDOWS:
 776            WindowsOsShutdownState().clear()
 777    return exit_code

 897def _signal_handler(_signum: int, _frame: Any) -> None:
 898    """Handles the shutdown signals registered by ``_signals_install``.
 899
 900    On Windows, while ``_main_async`` is running, ``WindowsOsShutdownState().request_shutdown()``
 901    schedules ``stop_event.set()`` on the published loop, routing the shutdown through the
 902    cooperative ``_wait_for_shutdown``/``ShutdownRequestedError`` path. Otherwise (always on
 903    POSIX, where ``_main_async`` uses ``loop.add_signal_handler`` instead, and on Windows when
 904    ``_main_async`` is not running) no shutdown state is published and a ``KeyboardInterrupt``
 905    is raised, caught by ``main()``.
 906
 907    Args:
 908        _signum (int): The signal number received.
 909        _frame (Any): The current stack frame (unused).
 910
 911    Returns:
 912        None: Either schedules the shutdown callback or raises, per the Raises
 913        section below.
 914
 915    Raises:
 916        KeyboardInterrupt: Raised when no shutdown state is published.
 917
 918    Complexity:
 919        - Time: O(1), either a single scheduled callback or a single raised
 920          exception.
 921        - Space: O(1), no additional storage.
 922    """
 923    if not WindowsOsShutdownState().request_shutdown():
 924        raise KeyboardInterrupt

 927def _get_redis_credential(logger: Logger) -> RedisCredential:
 928    """Load Redis connection details from environment variables.
 929
 930    This function reads the Redis URL, port, username, and password from the environment
 931    (loading a ``.env`` file first via ``load_dotenv``), using the
 932    ``REDIS_URL_VAR_NAME``, ``REDIS_PORT_VAR_NAME``, ``REDIS_USERNAME_VAR_NAME``,
 933    and ``REDIS_PASSWORD_VAR_NAME`` variable names. The username and password
 934    are optional; the URL and port are required.
 935
 936    Args:
 937        logger (Logger): Logger instance used to record the loaded settings at
 938            INFO level.
 939
 940    Returns:
 941        RedisCredential: The Redis connection details assembled from the
 942            environment variables.
 943
 944    Raises:
 945        ValueError: If the ``REDIS_URL`` or ``REDIS_PORT`` environment variable
 946            is not set.
 947
 948    Complexity:
 949        - Time: O(1), a fixed number of environment variables is read.
 950        - Space: O(1), a single fixed-size frozen dataclass is allocated.
 951    """
 952    load_dotenv()
 953    redis_url = os.getenv(REDIS_URL_VAR_NAME)
 954    if redis_url is None:
 955        raise ValueError(f"Environment variable {REDIS_URL_VAR_NAME} is not set.")
 956    redis_port = os.getenv(REDIS_PORT_VAR_NAME)
 957    if redis_port is None:
 958        raise ValueError(f"Environment variable {REDIS_PORT_VAR_NAME} is not set.")
 959    redis_username = os.getenv(REDIS_USERNAME_VAR_NAME)
 960    redis_password = os.getenv(REDIS_PASSWORD_VAR_NAME)
 961    if logger.isEnabledFor(level=logging.INFO):
 962        logger.info(
 963            msg="Creating RedisCredential with the following settings: "
 964            f"redis_host={redis_url}, redis_port={redis_port}, redis_user={redis_username}"
 965        )
 966    return RedisCredential(
 967        redis_url=redis_url,
 968        redis_port=int(redis_port),
 969        redis_username=redis_username,
 970        redis_password=redis_password,
 971    )

 974def _signals_install() -> None:
 975    """Register ``_signal_handler`` for the process shutdown signals.
 976
 977    On Windows only ``SIGBREAK`` (CTRL_BREAK_EVENT) is registered. On POSIX
 978    ``SIGINT`` and ``SIGTERM`` are registered. ``main`` calls this before the event
 979    loop starts and again once ``_main_async`` has returned:
 980    ``asyncio.Runner`` replaces these handlers with its own
 981    (``loop.add_signal_handler``) while the loop is open and, on ``loop.close()``,
 982    resets them to ``default_int_handler`` (``SIGINT``) and ``SIG_DFL``
 983    (``SIGTERM``) rather than restoring the previous ones. Registering again
 984    keeps a late signal routed through ``_signal_handler`` (exit code ``ABORTED``)
 985    instead of being ignored or killing the process.
 986
 987    Returns:
 988        None: The handlers are registered in place.
 989
 990    Complexity:
 991        - Time: O(1), at most two ``signal.signal`` calls.
 992        - Space: O(1), no additional data structures are allocated.
 993    """
 994    if IS_WINDOWS:
 995        # Windows: Handle CTRL_BREAK_EVENT
 996        sigbreak = getattr(signal, "SIGBREAK", None)
 997        if sigbreak is not None:
 998            signal.signal(signalnum=sigbreak, handler=_signal_handler)
 999    else:
1000        # Linux/Unix: Handle SIGINT (in case default behavior is overridden)
1001        signal.signal(signal.SIGINT, _signal_handler)
1002        # Linux/Unix: Handle SIGTERM (sent by container runtimes on stop)
1003        signal.signal(signal.SIGTERM, _signal_handler)
