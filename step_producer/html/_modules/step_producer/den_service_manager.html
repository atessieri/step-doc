  1"""DENM Service Manager Module.
  2
  3This module provides management functionality for DENM (Decentralized Environmental Notification Message)
  4services in ITS (Intelligent Transportation Systems) environments.
  5
  6Overview:
  7    Implements DENM lifecycle management: creation, processing, termination, and cleanup of DENM messages.
  8    Serves as the main interface for managing collision-related notifications between ITS stations.
  9
 10Key Components:
 11    - DenServiceManager: Main service class orchestrating DENM operations
 12    - Station Collision Processing: Handles collision data and generates DENM messages
 13    - Message Termination: Processes DENM negations and cancellations
 14    - Periodic Cleanup: Manages expired DENM records
 15
 16Core Functionality:
 17    #. Collision Event Processing: Converts station collision arrays into DENM messages
 18    #. Message Lifecycle Management: Tracks active DENM records
 19    #. Termination Handling: Processes negation messages and removes records
 20    #. Automatic Cleanup: Cancels expired DENM messages
 21
 22Dependencies:
 23    - step_cloud_schemas: DENM data structures and schemas
 24    - step_producer: DENM service data management
 25    - logging: Operation logging
 26
 27Usage:
 28    Instantiate with station configuration and use to process collision data and manage DENM message lifecycle.
 29
 30Example:
 31    >>> manager = DenServiceManager(
 32    ...     station_id=12345,
 33    ...     time_after_collision_sec=5,
 34    ...     denm_last_update_max_delay_ms=1000,
 35    ...     logger=logger,
 36    ... )
 37    >>> denm_list = manager.process_station_collisions_received(collision_data)
 38    >>> manager.process_denm_record_received(denm_message)
 39    >>> expired_denm_list = manager.periodical_cleanup()
 40
 41Thread Safety:
 42    Designed for single-threaded operation. Do not share instances between concurrent tasks.
 43
 44Performance:
 45    - Uses slots for memory efficiency
 46    - Periodic cleanup prevents memory leaks
 47
 48Complexity:
 49    - Time: O(k log k + k log N), dominated by
 50      DenServiceManager.process_station_collisions_received (via
 51      DenServiceDataManager.insert_station_collision_array's station sort and
 52      per-station SortedList insert/remove), k = number of stations in the
 53      collision array, N = total tracked DENM records.
 54    - Space: O(k), dominated by the same method's returned DENM message list.
 55
 56Classes:
 57    - DenServiceManager: Orchestrates DENM message creation, termination, and periodic
 58      cleanup for a single station. Complexity: time O(k log k + k log N), space
 59      O(k), k = number of stations in a processed collision array, N = total
 60      tracked DENM records (worst case, in
 61      process_station_collisions_received).
 62"""

 75class DenServiceManager:
 76    """DENM Service Manager for ITS Environments.
 77
 78    The DenServiceManager class manages the lifecycle of DENM (Decentralized Environmental Notification Message)
 79    messages for Intelligent Transportation Systems (ITS). It processes station collision data, manages DENM records,
 80    handles terminations and cancellations, and performs periodic cleanup of expired records.
 81
 82    Responsibilities:
 83        - Process station collision arrays and generate DENM messages
 84        - Handle incoming DENM records and process terminations (negations/cancellations)
 85        - Create cancellation messages for expired DENM events
 86        - Periodically clean up expired DENM records
 87
 88    Attributes:
 89        station_id (int): Unique identifier for the station.
 90        time_after_collision_sec (int): Time duration after collision event in seconds.
 91        denm_last_update_max_delay_ms (int): Maximum delay in milliseconds for DENM last update.
 92        logger (Logger): Logger instance for logging events and debugging.
 93
 94    Example:
 95        >>> manager = DenServiceManager(
 96        ...     station_id=12345,
 97        ...     time_after_collision_sec=5,
 98        ...     denm_last_update_max_delay_ms=1000,
 99        ...     logger=logger,
100        ... )
101        >>> denm_list = manager.process_station_collisions_received(collision_data)
102        >>> manager.process_denm_record_received(denm_message)
103        >>> expired_denm_list = manager.periodical_cleanup()
104
105    Complexity:
106        - Time: O(k log k + k log N), dominated by
107          process_station_collisions_received, k = number of stations in a
108          processed collision array, N = total tracked DENM records (see
109          module-level Complexity note).
110        - Space: O(k), dominated by the same method's returned DENM message list.
111    """

171    def process_denm_record_received(self, denm: DenmDataV1) -> None:
172        """Processes a received DENM (Decentralized Environmental Notification Message)
173        record.
174
175        If the DENM record's management container indicates a termination with a negation,
176        logs the receipt of the negation and removes the corresponding DENM record from
177        the service data.
178
179        Args:
180            denm (DenmDataV1): The DENM data object containing management information.
181
182        Returns:
183            None: The service data's internal record is removed in place when a
184            negation is received; otherwise nothing happens.
185
186        Complexity:
187            - Time: O(log N), delegates to DenServiceDataManager.remove_denm_record,
188              N = number of currently tracked DENM records (dict removal is O(1),
189              the SortedList removal is O(log N)).
190            - Space: O(1), no additional storage.
191        """
192        if denm.managementContainer.termination == Termination.NEGATION:
193            if self._logger.isEnabledFor(level=logging.INFO):
194                self._logger.info(
195                    msg=f"Received DENM negation for actionId: {denm.managementContainer.actionId}"
196                )
197            self._denm_service_data.remove_denm_record(
198                denm_action_id=denm.managementContainer.actionId
199            )

201    def _denm_create_cancellation(self, denm: DenmDataV1) -> DenmDataV1:
202        """Creates a new ``DenmDataV1`` instance representing the cancellation of a DENM
203        event.
204
205        This method copies all relevant fields from the provided ``denm`` object, but sets
206        the ``termination`` field in the management container to ``Termination.CANCELLATION``.
207        All other fields are preserved from the original DENM message.
208
209        Args:
210            denm (DenmDataV1): The original DENM data object to be cancelled.
211
212        Returns:
213            DenmDataV1: A new DENM data object with the cancellation termination.
214
215        Complexity:
216            - Time: O(1), two Pydantic model_copy calls over fixed-size models.
217            - Space: O(1), aside from the newly copied model.
218        """
219        return denm.model_copy(
220            update={
221                "managementContainer": denm.managementContainer.model_copy(
222                    update={"termination": Termination.CANCELLATION}
223                )
224            }
225        )

227    def periodical_cleanup(self) -> list[DenmDataV1]:
228        """Performs a single cleanup operation to retrieve expired DENM records.
229
230        This method checks for DENM records whose reference times have expired and returns
231        a list of those records for further processing, such as cancellation or removal.
232
233        Returns:
234            list[DenmDataV1]: List of expired DENM records.
235
236        Complexity:
237            - Time: O(m log N), m = number of expired records found, N = total
238              tracked DENM records; dominated by
239              DenServiceDataManager.get_denm_records_clean_reference_expired's
240              SortedList scan/removal, plus one model_copy per expired record.
241            - Space: O(m), for the returned cancellation list.
242        """
243        return [
244            self._denm_create_cancellation(denm=denm)
