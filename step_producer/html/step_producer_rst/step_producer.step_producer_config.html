step_producer.step_producer_config module

STEP Producer configuration module.

This module provides configuration classes and utilities for the STEP Producer component. It leverages Pydantic for configuration validation, serialization, and schema generation.

The configuration covers several key aspects:

  • Redis connection settings and stream configurations

  • Logging configuration with various handlers (stream, file, null)

  • Producer instance settings including station ID and timing parameters

The module is structured with a hierarchical configuration model:

  • StepProducerConfig: Top-level configuration class

  • RedisClientConfig: Configuration for Redis client connections

  • RedisStreams: Configuration for Redis streams (input/output)

The logging section uses LogConfig, imported from step_cloud_schemas, and the Redis connection section uses RedisConnection, imported from step_redis. The Redis host, port and credentials are not part of the configuration: RedisCredential (step_redis) holds them once read from the environment.

The pydantic configuration models provide:

  • Strong typing and validation via Pydantic

  • Default configuration instances via get_default() methods

  • JSON schema generation capabilities

  • Immutable (frozen) instances to prevent accidental modifications

Example

>>> config = StepProducerConfig.get_default()
>>> StepProducerConfig.print_config_schema(path=Path("./config"))
Complexity:

  • - Time – O(1) relative to input size, dominated by StepProducerConfig.print_config_schema/print_config_example, whose cost is set by the underlying pydantic schema generation, JSON serialization, and file I/O over the fixed set of configuration fields.

  • - Space – O(1) relative to input size, for the same reason.

Classes:

  • StepConfigVersion: Enumeration of the STEP configuration version. Complexity: time O(1), space O(1).

  • RedisStreamOutput: Configuration for a single Redis stream output. Complexity: time O(1), space O(1).

  • RedisStreamOutputs: Collection of configured Redis stream outputs. Complexity: time O(1), space O(1).

  • RedisStreamInput: Configuration for a Redis stream input (consumer group). Complexity: time O(1), space O(1).

  • RedisStreams: Combined input/output Redis stream configuration. Complexity: time O(1), space O(1).

  • RedisClientConfig: Combined Redis connection and stream configuration. Complexity: time O(1), space O(1).

  • _ConfigGenerateJsonSchema: Adds a custom $id/$schema to the generated JSON schema. Complexity: time O(1), space O(1) (relative to input size).

  • StepProducerConfig: Top-level STEP Producer configuration, including Redis and logging settings. Complexity: time O(1), space O(1) (relative to input size; print_config_schema/print_config_example drive the worst case).

class step_producer.step_producer_config.RedisClientConfig(*, connection: RedisConnection, streams: RedisStreams)

Bases: BaseModel

Configuration class for Redis client settings.

This class defines the configuration schema for the Redis client, including connection parameters and stream settings. It uses Pydantic for validation and schema definition.

connection

step_redis connection settings (database, timeouts, keepalive, SSL, and pool); the host, port and credentials come from the environment (RedisCredential).

Type:

RedisConnection

streams

Configuration for Redis streams used by the client. This includes stream names, group names, and consumer settings.

Type:

RedisStreams

Note

connection.socketTimeout must exceed streams.input.waitTimeout by at least READ_TIMEOUT_MARGIN_MS: the blocking XREADGROUP read is bounded by the socket timeout, and a read that times out first drops the connection and loses any message the server delivered in that instant (the input stream is read with noack).

Complexity:

  • - Time – O(1), dominated by get_default(), which delegates to RedisConnection.get_default() and RedisStreams.get_default().

  • - Space – O(1), two nested configuration fields.

class step_producer.step_producer_config.RedisStreamInput(*, streamId: Annotated[str, MinLen(min_length=1)], groupId: Annotated[str, MinLen(min_length=1)], waitTimeout: Annotated[int, Ge(ge=10000)])

Bases: BaseModel

Redis Stream Input Configuration model.

This model defines configuration parameters for Redis stream inputs including stream ID, group ID, and wait timeout settings. It enforces validation rules on all fields.

streamId

Key of the Redis stream the producer messages are read from. Must be at least 1 character long.

Type:

str

groupId

Consumer group the instance reads the input stream with. Must be at least 1 character long.

Type:

str

waitTimeout

The timeout in milliseconds for the stream receive operation. Must be at least 10000 (10 seconds).

Type:

int

Note

The model configuration enforces strict validation with no extra fields allowed and the object is immutable (frozen).

Complexity:

  • - Time – O(1), dominated by get_default(), a fixed-field construction.

  • - Space – O(1), three scalar fields.
