step_producer.ordered_list_record module

OrderedListRecord Module.

This module provides the OrderedListRecord class, a lightweight and memory-efficient container for time-ordered operations in ITS DENM management.

Features:

  • Encapsulates a reference time and a unique record key for fast lookup, sorting, and deduplication.

  • Optimized for high-frequency, time-ordered operations (insert, search, delete) in sorted lists and hash tables.

  • Uses __slots__ and hash caching for minimal memory and fast dictionary/set operations.

  • Implements rich comparison operators for chronological ordering and deduplication.

  • Designed for use in ITS DENM management and related modules handling event life cycles.

Example

>>> record = OrderedListRecord(reference_time, record_key)
... record_key = record.record_key
... sorted_records = sorted([record1, record2])
Complexity:

  • - Time – O(1), every operation on RecordKey and OrderedListRecord (construction, comparison, hashing) is constant time.

  • - Space – O(1), both classes hold only fixed-size fields (no collection grows with input size).

Classes:
RecordKey: Frozen dataclass holding the unique reference/involved actor pair

for a DENM record. Complexity: time O(1), space O(1).

OrderedListRecord: Lightweight, memory-efficient record supporting sorting and

deduplication by reference time and record key. Complexity: time O(1), space O(1).
