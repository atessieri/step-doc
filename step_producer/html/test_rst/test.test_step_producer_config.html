test.test_step_producer_config module

Test module for step_producer configuration components.

This module contains comprehensive unit tests for the step_producer configuration system, specifically testing the Redis connection/stream configuration classes, the private JSON schema generator, and the main StepProducerConfig class. The tests ensure proper functionality, default value settings, and schema/example file generation capabilities.

Note

Logging configuration classes (LogConfig, LogHandlerType, and friends) now live in the external step_cloud_schemas package and are no longer defined in step_producer. They are out of scope for this module’s tests and are only imported here where needed to construct real StepProducerConfig instances.

Key Testing Features:

  • Default configuration validation for all Redis configuration classes

  • Parameterized testing for enumeration value conversions

  • File comparison testing for schema and template generation

  • Temporary directory usage to avoid filesystem pollution
