test.file_compare.schemas package

Schemas package for file comparison testing.

This module serves as the package initializer for schema-related test utilities used in file comparison testing within the step_producer test suite. It provides a namespace for organizing schema validation and comparison test components.

The schemas in this package are used to:

  • Validate file structure and content during testing

  • Compare expected vs actual file outputs

  • Ensure data integrity in file processing operations

  • Support automated testing of file-based operations

This package is part of the step_producer testing framework and should only be used in test environments.
