test.test___main__ module

Test module for step_producer.__main__ module functionality.

This comprehensive test suite validates the core functionality of the STEP Producer main module, including application startup, configuration management, signal handling, and stream processing capabilities.

Test Coverage:

  • ExitCode enumeration validation and member values

  • Signal handling and shutdown procedures for cross-platform compatibility

  • OS signal configuration for both Windows and Unix-like systems

  • Command line argument parsing for various configuration options

  • Exception handling in asyncio event loops

  • Redis stream processing with different message types (DENM, collision arrays)

  • Asynchronous main execution flow with retry logic and error handling

  • Configuration schema and template file generation

  • Application lifecycle management including startup and graceful shutdown

The test suite ensures robust error handling, proper resource management, and correct behavior across different operating systems and execution scenarios. It validates both successful execution paths and error conditions to ensure the application behaves predictably under various circumstances.

Regression tests for the max(1, ceil(...)) guard used when computing ttl_seconds for the producer input stream’s StepRedisStreamParams.

test_ttl_seconds_guard_never_floors_to_zero(wait_timeout_ms: int, expected_ttl_seconds: int) → None[source]

Test that the ttl_seconds guard never produces a value of 0, even for wait_timeout_ms values well below the config schema’s own minimum (bypassed here by constructing StepRedisStreamParams directly).

This test verifies that:

  1. The guarded formula max(1, ceil(wait_timeout_ms * 2 / 1000)) always produces the expected, strictly positive ttl_seconds.

  2. Constructing StepRedisStreamParams with that ttl_seconds never raises, unlike the naive floor-division formula (wait_timeout_ms * 2) // 1000, which would floor to 0 for wait_timeout_ms values below 500 and be rejected by StepRedisStreamParams.

Parameters:

  • expected_ttl_seconds (int) – The expected ttl_seconds produced by the guarded formula.
