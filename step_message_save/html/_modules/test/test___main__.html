180async def _mock_its_messages(message_list: list[Any]) -> AsyncGenerator[Any]:
181    """Asynchronously yields mock messages from a provided list.
182
183    This function is designed for testing purposes to simulate an asynchronous
184    iterator of ITS messages. It takes a list of mock objects and yields them one by
185    one in an async generator pattern.
186
187    Args:
188        message_list (list[Any]): A list of mock objects representing messages to be
189            yielded asynchronously.
190
191    Yields:
192        Any: Individual mock message objects from the input list.
193
194    Returns:
195        AsyncGenerator[Any, None]: An async generator that yields mock objects and
196            returns None when exhausted.
197
198    Complexity:
199        - Time: O(n), where n is the number of messages in ``message_list``, since
200          each item is yielded exactly once.
201        - Space: O(1) auxiliary, beyond the already-allocated input list; no
202          additional collection is built.
203    """
204    for message in message_list:
205        yield message

757    ``sys.argv`` set so that ``main()`` takes its fast, side-effect-free usage path.

762    Returns:

766        - Time: O(1), the module is re-executed once via ``runpy.run_module`` and a

774    )
