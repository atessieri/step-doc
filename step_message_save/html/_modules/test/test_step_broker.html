 90        external dependencies and validates that:

 93            - An ``ssl.SSLContext`` is built, with the minimum TLS version pinned,

108            ssl_ca_certs_file (str | None): CA certificates file path, or None to omit
109                it; only meaningful when ``ssl_enable`` is True.
110            ssl_client_cert_file (str | None): Client certificate file path, or None
111                to omit it (and its associated key); only meaningful when
112                ``ssl_enable`` is True.
113            logger_enabled (bool): Flag to enable or disable logging in the test.
114
115        Returns:
116            None
117        """

122            username="username",
123            password="password",
124            sslEnable=ssl_enable,

126                "/path/to/client.key" if ssl_client_cert_file is not None else None
127            ),

130            ),

140        )
