test.test_step_message_save_config module

Test module for step_message_save configuration components.

This module contains comprehensive unit tests for the step_message_save configuration system, specifically testing the MQTT client/protocol configuration models, message type and QoS enumerations, and the main StepMessageSaveConfig class. The tests ensure proper functionality, default value settings, and schema/example file generation capabilities.

Key Testing Features:

  • Default configuration validation for all configuration model classes

  • Parameterized testing for enumeration value conversions

  • File comparison testing for schema and template generation

  • Error handling testing for invalid input values

  • Temporary directory usage to avoid filesystem pollution
