test.test_step_broker module

Unit tests for the StepBroker MQTT gateway component.

This module contains unit tests for the StepBroker class, which serves as a gateway between the STEP MQTT broker and the local filesystem. The tests cover initialization (with SSL/TLS enabled and disabled), asynchronous context manager behavior, and MQTT topic subscription handling.

Testing Approach:

All tests employ extensive mocking to isolate the unit under test and eliminate external dependencies such as MQTT broker connections, SSL certificate validation, and network I/O.

test_init(mocker: MockerFixture, *, ssl_enable: bool) → None[source]

Test StepBroker initialization with SSL enabled and disabled configurations.

This test verifies that the StepBroker is properly initialized. It mocks all external dependencies and validates that:

  • The broker stores the given config and logger

  • TLSParameters are configured only when SSL is enabled, with the correct certificates and settings

  • AsyncComManagerParams are created with all necessary MQTT and SSL parameters

  • The parent AsyncComManager is properly initialized

Parameters:

  • mocker (MockerFixture) – pytest-mock fixture for creating mock objects.

  • ssl_enable (bool) – Whether SSL is enabled in the MQTT client configuration.

Returns:

None

Complexity:

  • - Time – O(1), the broker is constructed once from a fixed-size configuration and a constant number of mocked calls are asserted.

  • - Space – O(1), only the fixed-size configuration and mocked objects are held.
