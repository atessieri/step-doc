test.test_step_broker module

Unit tests for step_message_save.step_broker.

This module contains unit tests for the StepBroker class, which serves as a gateway between the STEP MQTT broker and the local filesystem. The tests cover initialization (with SSL/TLS enabled and disabled), asynchronous context manager behavior, and MQTT topic subscription handling.

The parent AsyncComManager is patched in every test, so no MQTT broker connection, SSL certificate, or network I/O is involved.

Test that subscribe_execution subscribes to every configured topic with the configured SubscribeOptions, accepts granted QoS levels (plain ints or ReasonCode) up to the configured maximum, raises StepMessageSaveError for a result above it or a result count mismatch, and skips subscribing when no topics are configured, logging that at INFO.

  • subscription_topics (list[SubscriptionTopicParams] | None) – The configured subscription topics.

  • results (list[Any] | None) – The results returned by the patched subscribe.

  • error (str | None) – The expected StepMessageSaveError message pattern, or None when no error is expected.

  • expected_info_calls (int) – The number of INFO records expected when the logger is enabled (“Subscribed to” per topic, or the single “No subscription topics configured” record).

  • logger_enabled (bool) – Return value of the mock logger’s isEnabledFor.
