test.test___main__ module

Test module for __main__ module functionality.

This test suite validates the core functionality of the STEP Message Save main module, including application startup, configuration management, signal handling, message receiving/writing, and the main execution loop with reconnection logic.

Test Coverage:

  • ExitCode enumeration validation and member values

  • Command line argument parsing for various configuration options

  • Exception handling in asyncio event loops

  • Signal handling for cross-platform shutdown

  • Receiving ITS messages from the STEP gateway and queuing them for writing

  • Writing queued messages to the output file

  • Asynchronous main execution flow with retry logic and error handling

  • Configuration schema and template file generation

  • Application lifecycle management including startup and graceful shutdown

test.test___main__.test_dunder_main_guard(mocker: MockerFixture) → None[source]

Test that running the module as a script exits with main()’s return code.

The if __name__ == "__main__": guard at the bottom of the module is only reached when the module is executed directly (e.g. via python -m step_message_save), which cannot be exercised by calling main() or any other importable symbol directly. This test re-executes the module with runpy.run_module and run_name="__main__" to reach that guard, with sys.argv set so that main() takes its fast, side-effect-free usage path.

Parameters:

mocker (MockerFixture) – pytest-mock fixture for creating mock objects.

Returns:

None

Complexity:

  • - Time – O(1), the module is re-executed once via runpy.run_module and a single SystemExit is inspected.

  • - Space – O(1), only the cached module reference and exception info are held.

test.test___main__.test_main_interrupt_exception(mocker: MockerFixture, *, is_windows: bool, has_sigbreak: bool, logger_enabled: bool) → None[source]

Test that main handles KeyboardInterrupt correctly.

This test verifies that when a KeyboardInterrupt is raised during argument parsing, the main function:

  • Returns the ABORTED exit code

  • Installs the SIGBREAK handler on Windows only when signal.SIGBREAK is available, and the SIGINT/SIGTERM handlers on non-Windows platforms

  • Logs the interruption only when the logger is enabled for INFO

Parameters:

  • mocker (MockerFixture) – pytest-mock fixture for creating mock objects.

  • is_windows (bool) – Value used to patch IS_WINDOWS to select the signal handling branch under test.

  • has_sigbreak (bool) – Whether the mocked signal module exposes SIGBREAK, relevant only when is_windows is True.

  • logger_enabled (bool) – Flag to enable or disable logging in the test.

Returns:

None

Complexity:

  • - Time – O(1), at most two signal handlers are registered per scenario.

  • - Space – O(1), only the fixed set of mocked signal objects is held.
