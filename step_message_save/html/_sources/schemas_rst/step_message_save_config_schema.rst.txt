STEP Message Save Config V1 Schema
==================================

The STEP Message Save Config Version 1 Schema defines a comprehensive configuration structure
for the STEP Message Save subsystem. This JSON Schema is automatically generated from Pydantic
models and provides strong typing, validation rules, and documentation.

Overview
--------

The STEP Message Save Configuration is organized hierarchically with the main ``StepMessageSaveConfig``
class containing several nested configuration components for different aspects of the system:

  * **Base Configuration**

      * ``templateVersion``: The version of the template (currently "1")
      * ``outputFile``: Output file path for saving STEP messages
      * ``stepReceiverNumber``: Number of concurrent STEP receiver tasks (1-50)
      * ``maxFileWriterQueueRooms``: Maximum size of the queue used to pass messages
        from the STEP receiver tasks to the file writer task (1-10000)
      * ``reconnectInterval``: Time between reconnection attempts, in seconds (0-60)

  * **STEP Broker Configuration** (``stepBroker``)

      * **MQTT Client Configuration**: Connection parameters (host, port),
        authentication (username, password), and SSL/TLS security settings
        (certificates, keys)
      * **MQTT Protocol Configuration**: Session management (expiry, keepalive,
        timeout), message handling (queue sizes, in-flight messages), subscription
        topic management, and QoS settings
      * ``cacheDir``: Optional cache directory path

  * **Logging Configuration** (``log``)

      * Log handlers
      * Log levels
      * Formatting options

Features and Benefits
---------------------

* **Type Validation**: Strong typing and constraints via Pydantic fields
* **Immutable Design**: Configuration is frozen after loading to prevent runtime errors
* **Comprehensive Documentation**: Detailed field descriptions and examples
* **Default Values**: Sensible defaults provided for all configuration options
* **Strict Validation**: Prevents configuration errors before they cause runtime issues
