CPM Data V1 Schema
==================

The CPM (Cooperative Perception Message) Data Schema defines the structure for reporting objects
perceived by an originating ITS station's sensors, used in C-ITS system. The schema consists of:

    * **Station ID**: Identification of the originating station
    * **Reference Time and Position**: Common reference time and position used to resolve the
      absolute time and position of each perceived object
    * **Perceived Objects**: The list of objects detected by the station's sensors, each
      including:
        
        * Object identifier and measurement time
        * Position with confidence ellipse
        * Speed and heading with confidence levels
        * Object dimensions (length, width, height) with confidence levels
        * Overall perception quality
        * Predicted future path points

This schema defines a JSON Schema **version 1**. For further information, please refer 
to the python classes.
