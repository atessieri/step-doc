The STEP Message Save package provides a robust interface for communicating with the STEP (Safer Transport for Europe Platform) ecosystem.
It serves as a client that subscribes to the STEP MQTT broker and appends the received
Intelligent Transport Systems (ITS) messages such as CAM (Cooperative Awareness Messages), CPM (Cooperative
Perception Messages) and DENM (Decentralized Environmental Notification Messages), as JSON lines, to a local
output file.

Goal
----

The goal of the STEP Message Save project is to provide a reliable, secure bridge between the
STEP MQTT broker and the local filesystem, so that CAM, CPM, and DENM messages received from
the broker can be persisted to a JSON-lines file without managing MQTT connectivity, security,
or protocol details directly.

Key Features
------------

* Secure MQTT communication with SSL/TLS support
* Concurrent STEP receiver tasks feeding a single JSON-lines output file writer
* Asynchronous operation with non-blocking I/O
* Configurable connection parameters
* Comprehensive error handling and logging
* Quality of Service (QoS) controls for reliable message delivery
* Automatic reconnection with a configurable retry interval

Purpose
-------

The primary purpose of the STEP Message Save client is to enable straightforward capture of ITS
traffic by:

* Subscribing to configured topics on the STEP broker
* Running multiple concurrent receiver tasks for higher message throughput
* Serializing received messages to JSON and appending them to a single output file
* Providing a standardized approach to ITS message persistence for offline analysis

Getting Started
---------------

To begin using the STEP Message Save client, refer to the :doc:`installation<installation>`
