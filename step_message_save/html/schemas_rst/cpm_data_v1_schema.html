CPM Data V1 Schema

The CPM (Cooperative Perception Message) Data Schema defines the structure for reporting objects perceived by an originating ITS station’s sensors, used in C-ITS system. The schema consists of:

  • Station ID: Identification of the originating station

  • Reference Time and Position: Common reference time and position used to resolve the absolute time and position of each perceived object

  • Perceived Objects: The list of objects detected by the station’s sensors, each including:

    • Object identifier and measurement time

    • Position with confidence ellipse

    • Speed and heading with confidence levels

    • Object dimensions (length, width, height) with confidence levels

    • Overall perception quality

    • Predicted future path points

This schema defines a JSON Schema version 1. For further information, please refer to the python classes.

Example of the message:

{
  "type": "CPM",
  "referenceTime": "2022-04-05T17:31:00.000Z",
  "stationId": 25648,
  "referencePosition": {
    "latitude": 45.587878,
    "longitude": 60.458789,
    "positionConfidence": {
      "semiMajorAxisLengthConfidence": 1.23,
      "semiMinorAxisLengthConfidence": 1.23,
      "semiMajorAxisOrientation": 1.0
    },
    "altitude": {
      "value": 120.0,
      "confidence": 1.0
    }
  },
  "perceivedObjects": [
    {
      "objectId": 123,
      "objectType": "passengerCar",
      "objectTypeConfidence": 90,
      "measurementTime": "2022-04-05T17:31:00.000Z",
      "position": {
        "latitude": 45.587878,
        "longitude": 60.458789,
        "positionConfidence": {
          "semiMajorAxisLengthConfidence": 1.23,
          "semiMinorAxisLengthConfidence": 1.23,
          "semiMajorAxisOrientation": 1.0
        },
        "altitude": {
          "value": 120.0,
          "confidence": 1.0
        }
      },
      "speed": {
        "value": 123.67,
        "confidence": 0.5
      },
      "heading": {
        "value": 12.3,
        "confidence": 5.0
      },
      "objectDimensionZ": {
        "value": 12.3,
        "confidence": 0.5
      },
      "objectDimensionY": {
        "value": 12.3,
        "confidence": 0.5
      },
      "objectDimensionX": {
        "value": 12.3,
        "confidence": 0.5
      },
      "objectPerceptionQuality": 5,
      "positionPredicted": [
        {
          "time": "2022-04-05T17:31:00.000Z",
          "position": {
            "latitude": 45.587878,
            "longitude": 60.458789,
