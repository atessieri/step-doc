Changelog

All notable changes to step_client are documented in this file.

1.4.6 - 2026-11-05

1.4.6 - Added

  • pyrefly>=1.4.1 type checker: [tool.pyrefly] configuration, run by tox -e lint, README and docs badge and command descriptions updated.

  • Documentation: changelog page (doc/source/changelog.rst, rendered from CHANGELOG.md through myst_parser).

  • CI: TOX_UV_PYTHON_PREFERENCE=system, so tests use the Python of the Docker image instead of downloading another one.

1.4.6 - Changed

  • Requires pydantic>=2.14.3,<3.0, step_cloud_schemas>=3.4.3,<4.0 and step_lib>=3.1.4,<4.0; coverage>=7.17.2, mypy>=2.4.1, pytest>=9.2.0, ruff>=0.17.3 (ruff required-version>=0.17.3), tox>=4.67.11, tox-uv>=1.37.5, types-docutils>=0.23.0.20261030 and uv >=0.13.7; uv.lock refreshed accordingly.

  • step_broker: subscribe results are typed as Sequence[int | ReasonCode] instead of narrowing with cast.

  • step_client: RELEASE_DATE and __version__ moved after __all__.

1.4.0 - 2026-10-17

1.4.0 - Changed

  • Requires step_lib>=3.0.0,<4.0 and step_cloud_schemas>=3.0.0,<4.0 (TAI timestamps and new wire format: every station must be upgraded together).

  • step_broker.StepBroker (and the step_publisher example) configures TLS through step_lib.TLSParameters instead of a hand-built ssl.SSLContext, which step_lib 3.0.0 no longer accepts: CA file, client certificate/key and key password map to ca_certs, certfile, keyfile, keyfile_password, and sslVerifyServerCert=false to cert_reqs=ssl.CERT_NONE (hostname check included). The minimum TLS version is Python’s default (TLS 1.2).

  • The workload moved from __main__ to the new step_client_app.StepClientApp, an AbstractApp run by step_cloud_schemas.AppRunner (signal handling and shutdown); __main__.main only parses the arguments, loads the configuration and runs it. The public ShutdownRequestedError was removed.

  • __main__.main (and the doc/examples) again pass a Windows SelectorEventLoop loop_factory, reverting the 1.3.6 removal: the default ProactorEventLoop has no add_reader/add_writer, which aiomqtt needs to detect the CONNACK, so the MQTT connection hung until its timeout.

  • StepBroker.sender_station_id is now int (the configuration always provides stationId); MAC_ID_DEFAULT was removed.

  • StepBroker.client_publish_its_message returns bool: False, without the “Published” log, when step_lib skips the message because no publish topic is configured for its type.

  • RedisStreamOutput.maxLength must be at least 1 (ge=1), as step_redis requires: a 0 used to pass validation and then fail on every reconnect.

  • The root package re-exports StepBroker, StepClientApp, ExitCode, MqttRedisCredential, StepClientError and StepCliError.

  • CLI: -s/-t are documented as directories (<schema dir>/<template dir>).

  • CI: lint, test and coverage also run on merge requests and branch pushes; coverage must be 100% (fail_under = 100).

1.4.0 - Fixed
