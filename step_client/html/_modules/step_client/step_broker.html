  1"""STEP broker module for MQTT communication with the STEP broker.
  2
  3This module provides the ``StepBroker`` MQTT client used to talk to the STEP broker
  4within the STEP ecosystem. The bridging to Redis streams is performed by the caller
  5(``step_client.step_client_app.StepClientApp``), not by this module.
  6
  7The module implements a client that supports:
  8
  9    - Secure TLS/SSL MQTT communications with configurable parameters
 10    - Asynchronous operation with async context management for resource handling
 11    - Quality of Service (QoS) controls for topic subscriptions and publishing
 12    - Publishing ITS facility messages (CAM, CPM, DENM) with the configured sender location
 13    - Logging of subscriptions (published messages are logged by step_lib)
 14
 15The STEP Broker class leverages async/await patterns throughout to ensure non-blocking
 16operations.
 17
 18Complexity:
 19    - Time: O(t), where t is the number of configured MQTT topics; subscribing to and
 20      converting the publish-topic configuration scales with t, while publishing or
 21      receiving an individual ITS message is O(1).
 22    - Space: O(t), for the subscription and publish-topic configuration retained by the
 23      broker client.
 24

 28      to the STEP broker. Complexity: time O(t), space O(t), t = number of
 29      configured subscription/publish topics.

 58class StepBroker(AsyncComManager):
 59    """STEP broker client implementing AsyncComManager.
 60
 61    This class provides a high-level client for connecting to the STEP broker
 62    using MQTT protocol. It handles secure connections, topic subscriptions
 63    and message management according to the provided configuration.
 64
 65    The class manages:
 66
 67        - TLS/SSL connections with certificate validation
 68        - MQTT connection parameters (host, port, auth, timeouts, etc.)
 69        - Topic subscriptions with configurable QoS levels
 70        - Publishing ITS facility messages with a fixed sender position, stamped
 71          with the current time on every publish
 72
 73    It implements the AsyncComManager interface and supports asynchronous
 74    context manager protocol for safe resource management.
 75
 76    Attributes:
 77        instance_name (str): The name identifier for this broker instance.
 78        sender_station_id (int): Station ID of the transmitter, used as the
 79            GeoNetworking address MAC id and as the AsyncComManager echo-filter
 80            station id: received messages carrying it are dropped as echoes.
 81            A published DENM whose stationId differs (e.g. the producer's) is
 82            logged at WARNING by step_lib and its echo is not filtered, so with a
 83            DENM subscription it is forwarded back to the producer stream.
 84        sender_latitude (float): Latitude in degrees of the fixed transmitter
 85            position attached to every published message.
 86        sender_longitude (float): Longitude in degrees of the fixed transmitter
 87            position attached to every published message.
 88        config (StepBrokerConfig): Configuration object containing STEP broker settings
 89            including MQTT client parameters, protocol settings, and SSL configuration.
 90        mqtt_credential (MqttRedisCredential): MQTT and Redis connection credentials;
 91            only the MQTT host, port, username and password are used. A missing
 92            username connects anonymously (a password without a username is
 93            ignored, with a warning).
 94        logger (Logger): Logger instance for recording broker operations and events.
 95
 96    Example:
 97        >>> async with StepBroker(
 98        ...     instance_name="client1",
 99        ...     sender_station_id=12345,
100        ...     sender_latitude=50.1,
101        ...     sender_longitude=8.1,
102        ...     config=step_broker_config,
103        ...     mqtt_credential=mqtt_credential,
104        ...     logger=logger,
105        ... ) as broker:
106        ...     # Use the STEP broker
107        ...     pass
108
109    Complexity:
110        - Time: O(t), where t is the number of configured subscription/publish topics;
111          construction and subscription scale with t, while publishing a single ITS message
112          is O(1).
113        - Space: O(t), for the topic subscription and publish-topic configuration held by
114          the instance.

269    async def subscribe_execution(self) -> None:
270        """Subscribe to a list of topics with specified MQTT options.
271
272        This method subscribes to a list of topics specified in the configuration
273        with the following MQTT options:
274
275            - QoS: ``maxSubscriptionQos`` for every topic (``SubscriptionTopicParams``
276              has no per-topic QoS)
277            - Local messages delivered (noLocal=False)
278            - Do not retain as published (retainAsPublished=False)
279            - Do not send retained messages (retainHandling=RETAIN_DO_NOT_SEND)
280
281        Nothing is subscribed when ``subscriptionTopics`` is None.
282
283        Returns:
284            None: Subscriptions are established as a side effect; nothing is returned.
285
286        Raises:
287            StepClientError: If the number of subscription results differs from the number
288                of configured topics, or a granted QoS exceeds ``maxSubscriptionQos``.
289
290        Complexity:
291            - Time: O(t), where t is the number of configured subscription topics; each topic
292              is subscribed and validated in O(1) time.
293            - Space: O(t), for the list of topic/options tuples and the returned subscription
294              results.
295        """
296        if self._config.mqttProtocol.subscriptionTopics is not None:
297            sub_results = await self.subscribe(
298                topic=[
299                    (
300                        topic_params.topic,
301                        SubscribeOptions(
302                            qos=self._config.mqttProtocol.maxSubscriptionQos,
303                            noLocal=False,
304                            retainAsPublished=False,
305                            retainHandling=SubscribeOptions.RETAIN_DO_NOT_SEND,
306                        ),
307                    )
308                    for topic_params in self._config.mqttProtocol.subscriptionTopics
309                ]
310            )
311            if len(sub_results) != len(self._config.mqttProtocol.subscriptionTopics):
312                raise StepClientError(
313                    f"Subscription results {len(sub_results)} do not match the number "
314                    f"of topics {len(self._config.mqttProtocol.subscriptionTopics)}."
315                )
316            for topic, result in zip(
317                self._config.mqttProtocol.subscriptionTopics, sub_results, strict=True
318            ):
319                result_value = (
320                    result.value
321                    if isinstance(result, ReasonCode)
322                    else cast("int", result)
323                )
324                if result_value > self._config.mqttProtocol.maxSubscriptionQos:
325                    raise StepClientError(f"Failed to subscribe to {topic}: {result}")
326                if self._logger.isEnabledFor(level=logging.INFO):
327                    self._logger.info(msg=f"Subscribed to {topic}: {result}")

375        Complexity:
376            - Time: O(1), publishes a single message with the fixed sender location.
377            - Space: O(1), only the fixed-size sender position is allocated.
378        """
379        return await self.publish_its_message(

381            address=self._geo_network_address,
382            current_position=self._current_position(),
