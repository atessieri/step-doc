Installation with uv

STEP Client works on Windows, Linux and MacOS. Please follow the instructions below to build and run an example in your specific environment.

The installation process is performed using uv program.

Configure authentication

Before installing the library, you need to configure authentication to access the private git repository using a personal access token (PAT). You can use the following command to set up authentication:

$uv auth login gitlab.automotive.vodafone.com --token <your-personal-access-token>

To check the token is correctly configured, you can use the following command:

$uv auth token gitlab.automotive.vodafone.com

To remove the token, you can use the following command:

$uv auth logout gitlab.automotive.vodafone.com

To know the directory where the token is stored, you can use the following command:

$uv auth dir

URL Registry configuration

In order to access the private git repository, you need to configure the URL registry. The configuration is in the file uv.toml located:

$HOME\AppData\Roaming\uv\

$HOME/.config/uv/

The file should contain the following configuration:

# UV Configuration File

# Index resolution strategy - searches all indexes for best version match
index-strategy = "unsafe-best-match"

# main registry
[[index]]
name = "pypi"
url = "https://pypi.org/simple"
default = true

# step_client
[[index]]
url = "https://gitlab.automotive.vodafone.com/api/v4/projects/961/packages/pypi/simple"

If you have other indexes configured, make sure to include the above configuration in the file.

Installing from registry

The command to install the library is:

$uv pip install --upgrade step_client
