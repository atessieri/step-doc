API Documentation Coverage Summary
==================================

This page reports which modules, classes, functions, and methods are
missing docstrings. 

STEP Client coverage
--------------------

It checks the coverage of API documentation of the STEP Client, not test
coverage — for unit test line and branch coverage, see
:doc:`coverage_report`.

.. report:doc-coverage::
   :reportid: step_client

Test coverage
-------------

It checks the coverage of API documentation of the test suite.
