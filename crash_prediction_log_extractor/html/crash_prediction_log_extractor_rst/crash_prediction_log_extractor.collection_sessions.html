crash_prediction_log_extractor.collection_sessions module

Data models for crash-prediction collection sessions.

This module defines immutable, strict Pydantic models representing the collection-sessions payload exchanged by crash-prediction pipeline components. The models span the full hierarchy, from single geo-temporal points to the versioned root document, and include helpers to export both example payloads and JSON Schema artifacts.

The field validators normalize out-of-range coordinate and heading values (clamping latitude and wrapping longitude/heading) before final validation, and the field serializers round coordinates to COORDINATE_PRECISION (7) decimals and speed/heading to 2 decimals.

Data hierarchy:

CollectionSessions
`-- sessions                                (list[Session])
    `-- Session                             (one per time window)
        |-- actorsSession                   (list[ActorSession])
        |   `-- ActorSession                (one per actor)
        |       |-- actorId                 (ActorIdModel)
        |       `-- data                    (SessionData)
        |           |-- realPositions       (list[Position])
        |           `-- forecastedPositions (list[Position])
        |-- crashesInfo                     (list[CrashInfo])
        |   `-- CrashInfo                   (one per crash event)
        |       `-- actorsInvolved          (list[ActorIdModel])
        `-- checkpoints                     (list[CheckpointDataModel])
Complexity:

  • - Time – O(n), dominated by CollectionSessions.print_to_file, n = total number of serialized elements (sessions, actors, positions, crashes, checkpoints).

  • - Space – O(n), the JSON text built by CollectionSessions.print_to_file.

Classes:

  • CollectionSessionsDataModelVersion: Supported schema versions. Complexity: time O(1), space O(1).

  • ActorKey: Named tuple identifying an actor by station/object ID. Complexity: time O(1), space O(1).

  • ActorIdModel: Actor identifier with type and type confidence. Complexity: time O(1), space O(1).

  • Position: Timestamped geographic point with optional speed/heading. Complexity: time O(1), space O(1).

  • CrashInfo: Estimated crash event with risk and involved actors. Complexity: time O(1), space O(1).

  • DataType: String enum of scenario data types. Complexity: time O(1), space O(1).

  • SessionData: Real and forecasted positions of one actor in one session. Complexity: time O(1), space O(1).

  • ActorSession: One actor’s identifier paired with its session data. Complexity: time O(1), space O(1).

  • Session: All actors, crashes, and checkpoints of one time window. Complexity: time O(1), space O(1).

  • CollectionSessions: Versioned root payload with JSON/schema/example writers. Complexity: time O(n), space O(n).

Typical usage:

from crash_prediction_log_extractor.collection_sessions import (
    CollectionSessions,
)
from pathlib import Path

# Generate a default payload example
payload = CollectionSessions.get_default()
payload.print_to_file(Path("output.json"), indentation=2)

# Write the JSON Schema
CollectionSessions.print_schema(Path("schemas/"))
