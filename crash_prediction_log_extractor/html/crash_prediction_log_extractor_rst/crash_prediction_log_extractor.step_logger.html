crash_prediction_log_extractor.step_logger module

Logging utilities for the crash_prediction_log_extractor package.

This module provides a lightweight logging system with UTC timestamp formatting and support for both console and file-based logging. It offers a simple configuration interface through the get_logger function that creates a pre-configured logger with consistent UTC timezone handling across all handlers.

Key Features:

  • UTC timestamp formatting for consistent time handling across timezones

  • Stream handler for console output (stdout)

  • File handler for optional file-based logging with enhanced formatting

  • Configurable logging levels via the LogMode enumeration

  • Force-write capability for critical messages that must be logged regardless of the current logging level

  • File operations use UTF-8 encoding

crash_prediction_log_extractor.step_logger.get_logger(file_log: Path | None, log_level: LogMode | None) → Logger[source]

Create and configure a logger with console and optional file handlers.

Sets up a logger with UTC formatting that writes to stdout and optionally to a file. All handlers use the UtcFormatter for consistent timezone handling. If a file path is provided, a file handler is added with enhanced formatting that includes thread and function information.

Parameters:

  • file_log (Optional[Path]) – Path to log file. If None, only console logging is configured. If provided, creates a file handler that writes to this location in write mode (overwrites existing content).

  • log_level (Optional[LogMode]) – Logging level applied to the root logger and the file handler. If None, defaults to ERROR level. The console (stdout) handler is always set to ERROR level regardless of this parameter.

Returns:

Configured logger instance with handlers and UTC formatting applied.

Return type:

Logger

crash_prediction_log_extractor.step_logger.logger_force_write(logger: Logger, msg: str) → None[source]

Force the logger to write a message at INFO level, overriding handler levels.

Temporarily elevates the logger and all its handlers to INFO level to ensure the message is logged, regardless of their original levels. Original levels are restored after the message is written. Useful for critical messages that must be logged even when the logger is set to WARNING or higher levels.

Parameters:

  • logger (Logger) – The logger instance to use for writing the message.

  • msg (str) – The message to log at INFO level.

Returns:

None

Note

This function modifies handler levels during execution and restores them afterward, so it is thread-safe for the duration of the operation.
