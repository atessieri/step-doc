crash_prediction_log_extractor.log_extractor module

Log extractor for crash prediction scenario data.

This module parses structured log files produced by the step_crash_prediction service and assembles the extracted data into CollectionsPoints payloads.

Log file format

Each line in the log file follows the standard Python logging layout:

YYYY-MM-DD HH:MM:SS.mmm [LEVEL][pid=...][thread=...][module=...][function=...]: <marker>

The extractor ignores regular log output and only reacts to marker lines embedded in the log. The markers delimit scenarios, section types (normalized / anomalous, real / forecasted), crash events, and individual data points.

Marker reference

  • Scenario boundary:

    --Scenario start--
--Scenario end--

  • Section data boundaries (cartesian product of normalized|anomaly and real|forecasted):

    --Section normalized real start--
--Section normalized real end--
--Section normalized forecasted start--
--Section normalized forecasted end--
--Section anomaly real start--
--Section anomaly real end--
--Section anomaly forecasted start--
--Section anomaly forecasted end--

  • Actor identifier (inside a section data block):

    --Id: sid <station_id>, oid <object_id|None>--

Example: --Id: sid 37, oid None--
         --Id: sid 36, oid 5--

  • Position data point (following an actor identifier):

    --t: <ISO8601>, p: (<lat>, <lon>), s: <speed|None>, h: <heading|None>--

Example (real):      --t: 2026-02-24T05:25:51.339Z, p: (45.610087, 8.863476), s: 0.00, h: 21.10--
Example (forecast):  --t: 2026-02-24T05:26:06.379Z, p: (45.609514, 8.863836), s: None, h: None--

  • Crash section boundaries:

    --Section crash start--
--Section crash end--

  • Individual crash record (inside a crash section):

    --Crash start--
--Time: <ISO8601>, pos: (<lat>, <lon>), risk: <0.000-1.000>--
--Id: sid <station_id>, oid <object_id|None>--
... (one --Id:-- line per actor involved)
--Crash end--

Log example::

    --Crash start--
    --Time: 2026-02-24T05:25:51.339Z, pos: (45.610087, 8.863476), risk: 0.850--
    --Id: sid 36, oid None--
    --Id: sid 37, oid None--
    --Crash end--

... [INFO]...: --Section normalized real start--
... [INFO]...: --Section normalized real end--
... [INFO]...: --Section normalized forecasted start--

class crash_prediction_log_extractor.log_extractor.LogExtractor(input_file: Path, logger: Logger)[source]

Bases: object

Parses a step_crash_prediction log file and builds a CollectionsPoints payload.

The extractor reads the log file line by line and drives a hierarchy of finite-state machines to recognize structured marker lines embedded in the standard Python logging output. A full scenario block looks like:

--Scenario start--
  --Section normalized real start--
  --Id: sid 37, oid None--
  --t: 2026-02-24T05:25:51.339Z, p: (45.610087, 8.863476), s: 0.00, h: 21.10--
  --Section normalized real end--
  --Section normalized forecasted start--
  --t: 2026-02-24T05:26:00.379Z, p: (45.609514, 8.863836), s: None, h: None--
  --Section normalized forecasted end--
  --Section anomaly real start--
  --Section anomaly real end--
  --Section anomaly forecasted start--
  --Section anomaly forecasted end--
  --Section crash start--
  --Crash start--
  --Time: 2026-02-24T05:25:51.339Z, pos: (45.610087, 8.863476), risk: 0.850--
  --Id: sid 36, oid None--
  --Id: sid 37, oid None--
  --Crash end--
  --Section crash end--
--Scenario end--

Multiple scenarios may appear in one log file; each is processed independently and the results are merged into a single CollectionsPoints object available through the collections property after extract() has been called.

Compiled regex that matches --Scenario (start|end)--.

Type:

Pattern[str]

SECTION_DATA_PATTERN

Compiled regex that matches a section data boundary, e.g. --Section anomaly real start--.

Type:

Pattern[str]

SECTION_CRASH_PATTERN

Compiled regex that matches --Section crash (start|end)--.

Type:

Pattern[str]

CRASH_PATTERN

Compiled regex that matches --Crash (start|end)--.

Type:

Pattern[str]

CRASH_RISK_PATTERN

Compiled regex that matches --Time: <ISO8601>, pos: (<lat>, <lon>), risk: <0.000-1.000>-- and captures the time, position, and risk float string.

Type:

Pattern[str]

ACTOR_ID_PATTERN

Compiled regex that matches --Id: sid <station_id>, oid <object_id|None>-- and captures both groups.

Type:

Pattern[str]

POINT_PATTERN

Compiled regex that matches a position data line and captures time, latitude, longitude, speed and heading.

Type:

Pattern[str]

clear_table() → None[source]

Reset all in-memory session data buffers for the current scenario.

Clears the four position dictionaries (normalized/anomaly x real/forecasted) and the crash info list so that a new scenario can be parsed from a clean state. Called automatically by _extract_section() at the start of each scenario.

Returns:

None

property collections: CollectionsPoints | None

Return the parsed collections payload.

Returns:

The assembled CollectionsPoints object containing all actor sessions extracted from the log file, or None if extract() has not been called yet.

Return type:

Optional[CollectionsPoints]

extract() → None[source]

Parse the entire log file and populate collections.

Opens _input_file in read mode and iteratively calls _extract_section() until the end of the file is reached or a ValueError is raised by a sub-parser (which is caught and logged, allowing partial results to be returned).

After this method returns, collections contains a CollectionsPoints payload with one CollectionSections entry per actor, each holding all SessionData instances extracted across every parsed scenario.

The result is always a valid CollectionsPoints object (possibly with an empty collections list) even when parsing errors occur.

Returns:

None

Example usage:

from pathlib import Path
import logging

extractor = LogExtractor(
    input_file=Path("step_crash_prediction.txt"),
    logger=logging.getLogger(__name__),
)
extractor.extract()
payload = extractor.collections
if payload:
    payload.print_to_file(Path("output.json"))

--Crash start--
--Time: 2026-02-24T05:25:51.339Z, pos: (45.610087, 8.863476), risk: 0.850--

--Id: sid 37, oid None--
--Crash end--

str

str
