   2
   3This module defines ``DataRetriever``, which derives the secondary payloads
   4from a ``CollectionSessions`` document produced by ``LogExtractor``:
   5
   6- ``CollectionActors``: sessions regrouped per actor, each session carrying
   7  only the crashes that involve that actor.
   8- ``CollectionSequences``: for each actor, a deduplicated chronological
   9  sequence of real positions, each paired with the positions previously
  10  forecasted for that instant by earlier sessions (matched within a time

 117class DataRetriever:
 118    """Derives actors, sequences, and checkpoints payloads from sessions.
 119
 120    ``get_collection_actors`` regroups a ``CollectionSessions`` document per
 121    actor; ``get_collection_sequences`` then merges, for each actor, the real
 122    positions of its sessions into one chronological list (skipping positions
 123    at or before the last already-appended timestamp) and pairs each real
 124    position with the matching forecasted positions of earlier sessions;
 125    ``get_collection_checkpoints`` extracts per-session checkpoints. ISO 8601
 126    to epoch-millisecond conversions are memoized in an internal cache that
 127    lives as long as the instance. Not thread-safe: the shared ``ItsTime``
 128    and ``Geocode`` helpers are mutated on every conversion/distance call.

 140          forecasted positions inside one matching window.

 173    def _get_epoch_ms(self, time_str: str) -> int:
 174        """Return the epoch milliseconds corresponding to an ISO 8601 time string.
 175
 176        Uses an internal cache to avoid redundant conversions of the same
 177        time string; on a miss the shared ``ItsTime`` helper performs the
 178        conversion and the result is cached for the instance lifetime.
 179
 180        Args:
 181            time_str (str): ISO 8601 formatted time string to convert.
 182
 183        Returns:
 184            int: Epoch milliseconds equivalent of ``time_str``.
 185
 186        Complexity:
 187            - Time: O(1) amortized, one dict lookup; a miss adds one
 188              fixed-length timestamp parse.
 189            - Space: O(1) per call; the cache grows by one entry per distinct
 190              time string.
 191        """
 192        cached = self._epoch_cache.get(time_str)
 193        if cached is not None:
 194            return cached
 195        self._time.iso_format = time_str
 196        result = self._time.epoch_ms
 197        self._epoch_cache[time_str] = result
 198        return result

 217        self,
 218        real_position: Position,

 220        session_time: str,

 223        """Build a ForecastedPosition with its distance and heading errors.
 224
 225        The distance error is computed by the shared ``Geocode`` helper in
 226        meters; the heading error is ``forecasted.heading - real.heading``
 227        (values outside [-180, 180] are wrapped by ``ForecastedPosition``

 231            real_position (Position): Real observed position used as the

 234                produced the forecasted position.

 236                produced the forecasted position.

 239

 241            ForecastedPosition: Object containing the forecasted position, the
 242                geodesic distance error in meters between the two coordinates,
 243                and the heading error in degrees (``None`` when either heading
 244                is unavailable).
 245
 246        Complexity:
 247            - Time: O(1), one distance computation and one model build.
 248            - Space: O(1), one ForecastedPosition.
 249        """
 250        self._geocode.point_a = LatLonPoint(
 251            latitude=real_position.latitude, longitude=real_position.longitude
 252        )
 253        self._geocode.point_b = LatLonPoint(
 254            latitude=forecasted_position.latitude,
 255            longitude=forecasted_position.longitude,
 256        )
 257        heading_error = (
 258            forecasted_position.heading - real_position.heading
 259            if (forecasted_position.heading is not None)
 260            and (real_position.heading is not None)
 261            else None
 262        )
 263        distance = self._geocode.get_distance(unit=DistanceUnit.METERS)
 264        if self._logger.isEnabledFor(level=logging.DEBUG):
 265            heading_error_str = (
 266                f"{heading_error:.2f}" if heading_error is not None else "None"
 267            )
 268            self._logger.debug(
 269                msg=(
 270                    f"Real position time {real_position.time}, forecasted position time {forecasted_position.time}: "
 271                    f"distance: {distance:.2f} meters, "
 272                    f"heading error: {heading_error_str} degrees"
 273                )
 274            )
 275        return ForecastedPosition(
 276            sessionIndex=session_index,
 277            sessionTime=session_time,
 278            position=forecasted_position,
 279            distanceError=distance,
 280            headingError=heading_error,
 281        )

 283    def _get_forecasted_position(
 284        self,
 285        session_index: int,
 286        session_time: str,
 287        forecasted_point_list: list[Position],
 288        real_position: Position,
 289        real_position_time_ms: int,
 290    ) -> tuple[int, ForecastedPosition | None]:
 291        """Find a forecasted position matching a real position time.
 292
 293        Converts every timestamp of ``forecasted_point_list`` to epoch
 294        milliseconds, then scans the list in order:
 295
 296        - The first point whose absolute time difference from
 297          ``real_position_time_ms`` is within ``max_tolerance_time_ms`` is
 298          returned as ``(its index, ForecastedPosition)``; it is the first
 299          in-tolerance point, not necessarily the closest one.
 300        - If, before any in-tolerance point, the difference stops decreasing
 301          (current difference >= previous one), the closest point has been
 302          passed and ``(index of the previous point, None)`` is returned.
 303        - If the whole list is scanned without either condition,
 304          ``(-1, None)`` is returned.
 305
 306        Args:
 307            session_index (int): Zero-based index of the session that
 308                produced the forecasted points.
 309            session_time (str): ISO 8601 timestamp of the session that
 310                produced the forecasted points.
 311            forecasted_point_list (list[Position]): Time-ordered slice of
 312                forecasted positions to search.
 313            real_position (Position): Real observed position used to compute
 314                the distance/heading errors of the match.
 315            real_position_time_ms (int): Pre-computed epoch milliseconds of
 316                ``real_position.time``, used as the search key.
 317
 318        Returns:
 319            tuple[int, ForecastedPosition | None]: A pair
 320                ``(consumed_index, result)`` where ``consumed_index`` is the
 321                index within the provided slice of the last point consumed
 322                (``-1`` when the whole list was scanned without a match or a
 323                divergence), and ``result`` is the matched
 324                ``ForecastedPosition`` or ``None`` if no match was found.
 325
 326        Complexity:
 327            - Time: O(m), m = len(forecasted_point_list); all timestamps are
 328              converted up front even when the scan stops early.
 329            - Space: O(m), the list of converted timestamps.
 330        """
 331        times_ms = [self._get_epoch_ms(time_str=p.time) for p in forecasted_point_list]
 332        last_difference_ms: int | None = None
 333        for idx_forecasted_point, (
 334            forecasted_point,
 335            forecasted_point_time_ms,
 336        ) in enumerate(iterable=zip(forecasted_point_list, times_ms, strict=True)):
 337            diff_time_ms = abs(forecasted_point_time_ms - real_position_time_ms)
 338            if diff_time_ms <= self._max_tolerance_time_ms:
 339                if self._logger.isEnabledFor(level=logging.DEBUG):
 340                    self._logger.debug(
 341                        msg=(
 342                            f"Found forecasted position {idx_forecasted_point} time "
 343                            f"{forecasted_point.time} in session time {session_time}, real position time "
 344                            f"{self._get_iso_time(epoch_ms=real_position_time_ms)}: "
 345                            f"difference: {diff_time_ms} ms)"
 346                        )
 347                    )
 348                return (
 349                    idx_forecasted_point,
 350                    self._create_forecasted_position(
 351                        session_index=session_index,
 352                        session_time=session_time,
 353                        real_position=real_position,
 354                        forecasted_position=forecasted_point,
 355                    ),
 356                )
 357            if last_difference_ms is None:
 358                last_difference_ms = diff_time_ms
 359            elif diff_time_ms >= last_difference_ms:
 360                return (idx_forecasted_point - 1, None)
 361            else:
 362                last_difference_ms = diff_time_ms
 363        return (-1, None)

 365    def _get_forecasted_position_list(
 366        self,
 367        forecasted_points_list: list[ForecastedPoints],
 368        real_position: Position,
 369        real_position_time_ms: int,
 370        cursors: list[int],
 371    ) -> list[ForecastedPosition | None]:
 372        """Collect the matching forecasted position of each prior session.
 373
 374        For each ``ForecastedPoints`` entry whose cursor is not exhausted,
 375        searches ``positions[cursor:]`` with ``_get_forecasted_position`` and
 376        advances the cursor past the consumed element (or to the end of the
 377        list when the search returned ``-1``); exhausted entries yield
 378        ``None`` directly.
 379
 380        Args:
 381            forecasted_points_list (list[ForecastedPoints]): Per-prior-session
 382                containers of forecasted positions, ordered from most-recent
 383                to oldest prior session.
 384            real_position (Position): Real observed position used as the
 385                search key.
 386            real_position_time_ms (int): Pre-computed epoch milliseconds of
 387                ``real_position.time``.
 388            cursors (list[int]): Mutable per-session cursor positions tracking
 389                how far into each session's position list has already been
 390                consumed; same length as ``forecasted_points_list``. Modified
 391                in place.
 392
 393        Returns:
 394            list[ForecastedPosition | None]: One entry per element of
 395                ``forecasted_points_list``, each being a matched
 396                ``ForecastedPosition`` or ``None`` when no within-tolerance
 397                match was found for that session.
 398
 399        Complexity:
 400            - Time: O(F), F = total remaining (uncursored) positions across
 401              all entries, each slice being copied and fully converted.
 402            - Space: O(F), the temporary slices, plus O(k) for the result,
 403              k = len(forecasted_points_list).
 404        """
 405        forecasted_position_list: list[ForecastedPosition | None] = []
 406        for idx, forecasted_points in enumerate(iterable=forecasted_points_list):
 407            if cursors[idx] < len(forecasted_points.positions):
 408                idx_tmp, forecasted_position_tmp = self._get_forecasted_position(
 409                    session_index=forecasted_points.session_index,
 410                    session_time=forecasted_points.session_time,
 411                    forecasted_point_list=forecasted_points.positions[cursors[idx] :],
 412                    real_position=real_position,
 413                    real_position_time_ms=real_position_time_ms,
 414                )
 415                cursors[idx] = (
 416                    len(forecasted_points.positions)
 417                    if idx_tmp < 0
 418                    else cursors[idx] + idx_tmp + 1
 419                )
 420                forecasted_position_list.append(forecasted_position_tmp)
 421            else:
 422                forecasted_position_list.append(None)
 423        return forecasted_position_list

 479    def _get_forecasted_points_list(
 480        self,
 481        sessions: list[ActorSessionData],
 482        idx_current_session: int,
 483        min_time_ms: int,
 484        max_time_ms: int,
 485    ) -> list[ForecastedPoints]:
 486        """Collect forecasted positions of prior sessions inside a time window.
 487
 488        Walks backwards from the session immediately before
 489        ``idx_current_session``; for each session, converts all forecasted
 490        timestamps and selects via binary search
 491        (``bisect_left(min)``/``bisect_right(max)``) the positions whose
 492        timestamps lie in the closed interval ``[min_time_ms, max_time_ms]``,
 493        so that points exactly at the tolerance bounds are kept (as
 494        ``_get_forecasted_position`` accepts them), and wraps each non-empty
 495        subset in a ``ForecastedPoints``. Equal bounds select the positions
 496        at that single instant. Stops at the
 497        first session that has no forecasted positions or whose forecasted
 498        positions have no overlap with the requested range. Assumes each
 499        session's forecasted positions are sorted by time.
 500
 501        Args:
 502            sessions (list[ActorSessionData]): All sessions for the actor,
 503                ordered chronologically.
 504            idx_current_session (int): Index of the session being processed;
 505                prior sessions are those at indices strictly below this value.
 506            min_time_ms (int): Inclusive lower bound of the search window in
 507                epoch milliseconds.
 508            max_time_ms (int): Inclusive upper bound of the search window in
 509                epoch milliseconds; must be >= ``min_time_ms``.
 510
 511        Returns:
 512            list[ForecastedPoints]: Ordered list (most-recent prior session
 513                first) of forecasted position containers, one per qualifying
 514                prior session.
 515
 516        Raises:
 517            ValueError: If ``min_time_ms`` > ``max_time_ms``.
 518
 519        Complexity:
 520            - Time: O(Q), Q = total forecasted positions of the visited prior
 521              sessions; each is converted once, plus O(log f) bisection per
 522              session.
 523            - Space: O(Q), the per-session timestamp lists and the selected
 524              slices.
 525        """
 526        if min_time_ms > max_time_ms:
 527            raise ValueError(f"Expected a <= b, got a={min_time_ms}, b={max_time_ms}")
 528        forecasted_points_list: list[ForecastedPoints] = []
 529        idx_current_session -= 1
 530        while idx_current_session >= 0:
 531            forecasted_points = sessions[idx_current_session].forecastedPositions
 532            if len(forecasted_points) == 0:
 533                break
 534            forecasted_times_ms = [
 535                self._get_epoch_ms(time_str=p.time) for p in forecasted_points
 536            ]
 537            # First index where time[i] >= min_time_ms
 538            left = bisect_left(a=forecasted_times_ms, x=min_time_ms)
 539            # First index where time[i] > max_time_ms
 540            right = bisect_right(a=forecasted_times_ms, x=max_time_ms)
 541            if self._logger.isEnabledFor(level=logging.DEBUG):
 542                self._logger.debug(
 543                    msg=(
 544                        f"Session {idx_current_session} forecasted positions time range: "
 545                        f"{forecasted_points[left].time if left < len(forecasted_points) else None} - "
 546                        f"{forecasted_points[right - 1].time if right > 0 else None}, "
 547                        f"indices: {left if left < len(forecasted_points) else None} - "
 548                        f"{right - 1 if right > 0 else None}"
 549                    )
 550                )
 551            if left >= len(forecasted_points):
 552                break
 553            positions = forecasted_points[left:right]
 554            if len(positions) == 0:
 555                break
 556            forecasted_points_list.append(
 557                ForecastedPoints(
 558                    session_index=idx_current_session,
 559                    session_time=sessions[idx_current_session].sessionTime,
 560                    positions=positions,
 561                )
 562            )
 563            idx_current_session -= 1
 564        return forecasted_points_list

 571        Uses binary search (``bisect_right`` on epoch milliseconds) to skip
 572        positions at or before ``last_sequence_time``, i.e. those already
 573        appended to the sequence, avoiding duplicate entries. Assumes
 574        ``session.realPositions`` is sorted by time.
 575
 576        Args:
 577            session (ActorSessionData): Actor session whose ``realPositions``
 578                list is searched.
 579            last_sequence_time (str): ISO 8601 timestamp of the last real
 580                position already added to the sequence.
 581
 582        Returns:
 583            int: Index into ``session.realPositions`` of the first position
 584                strictly after ``last_sequence_time``, or
 585                ``len(session.realPositions)`` if all positions are already
 586                covered.
 587
 588        Complexity:
 589            - Time: O(log p), p = len(session.realPositions); each probe is an
 590              amortized O(1) cached conversion.
 591            - Space: O(1), no allocation beyond cache entries.
 592        """
 593        return bisect_right(
 594            a=session.realPositions,
 595            x=self._get_epoch_ms(time_str=last_sequence_time),
 596            key=lambda position: self._get_epoch_ms(time_str=position.time),
 597        )

 599    def _compute_forecasted_search_range(
 600        self, session: ActorSessionData, start_real_index: int
 601    ) -> tuple[int, int]:
 602        """Compute the time window in which forecasted positions are relevant.
 603
 604        The window extends from the timestamp of the first real position to
 605        include (minus the tolerance) to the timestamp of the last real
 606        position (plus the tolerance), ensuring that forecasted positions
 607        slightly outside the real-position range are still considered for
 608        matching.
 609
 610        Args:
 611            session (ActorSessionData): Actor session providing the
 612                ``realPositions`` used to derive the window boundaries.
 613            start_real_index (int): Index of the first real position to
 614                include; the lower bound of the window is derived from this
 615                position's timestamp.
 616
 617        Returns:
 618            tuple[int, int]: A pair ``(start_time_ms, end_time_ms)`` in epoch
 619                milliseconds, used by ``_get_forecasted_points_list`` as the
 620                inclusive bounds of the forecasted search window. The two are
 621                equal when the tolerance is 0 and only the last real position
 622                is included (a single-instant window).
 623
 624        Complexity:
 625            - Time: O(1), two cached conversions.
 626            - Space: O(1), two integers.
 627        """
 628        start_time_ms = (
 629            self._get_epoch_ms(time_str=session.realPositions[start_real_index].time)
 630            - self._max_tolerance_time_ms
 631        )
 632        end_time_ms = (
 633            self._get_epoch_ms(time_str=session.realPositions[-1].time)
 634            + self._max_tolerance_time_ms
 635        )
 636        return start_time_ms, end_time_ms

 638    def _process_first_session(
 639        self,
 640        idx_session: int,
 641        session: ActorSessionData,
 642        sequence: list[SequenceElement],
 643    ) -> None:
 644        """Populate the sequence with all real positions from the first actor session.
 645
 646        Since no prior sessions exist, each ``SequenceElement`` is created
 647        with an empty ``forecastedPositions`` list.
 648
 649        Args:
 650            idx_session (int): Zero-based index of the first session (always
 651                ``0`` when called from ``_process_actor_session``).
 652            session (ActorSessionData): First session data containing the
 653                real positions to append.
 654            sequence (list[SequenceElement]): Running list of sequence
 655                elements modified in place.
 656
 657        Returns:
 658            None: ``sequence`` is extended in place.
 659
 660        Complexity:
 661            - Time: O(p), p = len(session.realPositions).
 662            - Space: O(p), one appended element per real position.
 663        """
 664        sequence.extend(
 665            SequenceElement(
 666                sessionIndex=idx_session,
 667                sessionTime=session.sessionTime,
 668                realPosition=position,
 669                forecastedPositions=[],
 670            )
 671            for position in session.realPositions
 672        )

 674    def _process_subsequent_session(
 675        self,
 676        collection: CollectionActor,
 677        idx_session: int,
 678        session: ActorSessionData,
 679        sequence: list[SequenceElement],
 680    ) -> None:
 681        """Merge a later session's new real positions into the sequence.
 682
 683        Determines the insertion start index by skipping real positions
 684        already covered by the sequence tail, computes the forecasted search
 685        window, retrieves matching forecasted positions from prior sessions,
 686        and delegates element insertion to ``_insert_elements_in_sequence``.
 687        Logs at INFO level and returns early if all real positions in the
 688        session are already covered by the sequence.
 689
 690        Args:
 691            collection (CollectionActor): Full actor collection providing all
 692                sessions for forecasted-position lookup.
 693            idx_session (int): Zero-based index of the current session within
 694                the actor's session list; must be >= 1.
 695            session (ActorSessionData): Current session data containing the
 696                real positions to process.
 697            sequence (list[SequenceElement]): Running list of sequence
 698                elements modified in place; must be non-empty.
 699
 700        Returns:
 701            None: ``sequence`` is extended in place (possibly unchanged).
 702
 703        Complexity:
 704            - Time: O(log p + Q + r * F), p = real positions of the session,
 705              Q = forecasted positions of the visited prior sessions, r = new
 706              real positions, F = forecasted positions inside the window.
 707            - Space: O(r * k + Q), see _insert_elements_in_sequence and
 708              _get_forecasted_points_list.
 709        """
 710        start_real_index = self._find_session_real_start_index(
 711            session=session, last_sequence_time=sequence[-1].realPosition.time
 712        )
 713        if start_real_index >= len(session.realPositions):
 714            if self._logger.isEnabledFor(level=logging.INFO):
 715                self._logger.info(
 716                    f"Actor {collection.actorId}, session {idx_session}, "
 717                    f"last real time {session.realPositions[-1].time}: "
 718                    f"insertion time {sequence[-1].realPosition.time} is out of bounds"
 719                )
 720            return
 721        start_time_ms, end_time_ms = self._compute_forecasted_search_range(
 722            session=session, start_real_index=start_real_index
 723        )
 724        if self._logger.isEnabledFor(level=logging.INFO):
 725            self._logger.info(
 726                msg=(
 727                    f"Session {idx_session} time forecasted search range: "
 728                    f"{self._get_iso_time(epoch_ms=start_time_ms)} "
 729                    f"({start_real_index}) - "
 730                    f"{self._get_iso_time(epoch_ms=end_time_ms)} "
 731                    f"({len(session.realPositions) - 1})"
 732                )
 733            )
 734        forecasted_points_list = self._get_forecasted_points_list(
 735            sessions=collection.sessions,
 736            idx_current_session=idx_session,
 737            min_time_ms=start_time_ms,
 738            max_time_ms=end_time_ms,
 739        )
 740        if self._logger.isEnabledFor(level=logging.DEBUG):
 741            for forecasted_points in forecasted_points_list:
 742                self._logger.debug(
 743                    msg=(
 744                        f"Forecasted positions: session {forecasted_points.session_index}, "
 745                        f"session time {forecasted_points.session_time}, "
 746                        f"time range: {forecasted_points.positions[0].time} - {forecasted_points.positions[-1].time}, "
 747                        f"count: {len(forecasted_points.positions)}"
 748                    )
 749                )
 750        self._insert_elements_in_sequence(
 751            session_index=idx_session,
 752            session_time=session.sessionTime,
 753            sequence=sequence,
 754            real_positions=session.realPositions[start_real_index:],
 755            forecasted_points_list=forecasted_points_list,
 756        )

 759        self,
 760        collection: CollectionActor,
 761        idx_session: int,
 762        session: ActorSessionData,
 763        sequence: list[SequenceElement],
 764    ) -> None:
 765        """Dispatch session processing to the appropriate handler based on the session index.
 766
 767        Delegates to ``_process_first_session`` when ``idx_session`` is
 768        ``0``, and to ``_process_subsequent_session`` for all later sessions.
 769
 770        Args:
 771            collection (CollectionActor): Full actor collection providing all
 772                sessions for forecasted-position lookup.
 773            idx_session (int): Zero-based index of the current session within
 774                the actor's session list.
 775            session (ActorSessionData): Current session data to process.
 776            sequence (list[SequenceElement]): Running list of sequence
 777                elements modified in place.
 778
 779        Returns:
 780            None: ``sequence`` is extended in place.
 781
 782        Complexity:
 783            - Time: O(log p + Q + r * F), dominated by
 784              _process_subsequent_session (O(p) for the first session).
 785            - Space: O(r * k + Q), dominated by _process_subsequent_session.
 786        """
 787        if idx_session == 0:

 791        else:

 799    def _build_actor_sequence(self, collection: CollectionActor) -> ActorSequence:
 800        """Build an ActorSequence by iterating over all sessions of a single actor.
 801
 802        Processes sessions in list order, merging real positions and matching
 803        forecasted positions from prior sessions into a flat
 804        ``SequenceElement`` list.
 805
 806        Args:
 807            collection (CollectionActor): Actor data containing all sessions
 808                to process.
 809
 810        Returns:
 811            ActorSequence: Ordered sequence of ``SequenceElement`` entries
 812                covering all sessions of the actor, identified by
 813                ``collection.actorId``.
 814
 815        Complexity:
 816            - Time: O(s * Q + P * F), s = sessions, Q = forecasted positions
 817              of the actor, P = real positions appended, F = forecasted
 818              positions inside one matching window.
 819            - Space: O(P * k + Q), the sequence plus temporary forecast
 820              slices; k = prior sessions matched per real position.
 821        """
 822        if self._logger.isEnabledFor(level=logging.INFO):
 823            self._logger.info(
 824                msg=f"Collection sequence for Actor: {collection.actorId}"
 825            )
 826        sequence: list[SequenceElement] = []
 827        for idx_session, session in enumerate(iterable=collection.sessions):
 828            if self._logger.isEnabledFor(level=logging.INFO):
 829                self._logger.info(
 830                    msg=f"Processing session {idx_session} time {session.sessionTime}"
 831                )
 832            self._process_actor_session(
 833                collection=collection,
 834                idx_session=idx_session,
 835                session=session,
 836                sequence=sequence,
 837            )
 838        return ActorSequence(actorId=collection.actorId, sequence=sequence)

 869        self, actor_id: ActorIdModel, crash_list: list[CrashInfo]
 870    ) -> list[CrashInfo]:
 871        """Return the subset of crash records in which a given actor was involved.

 874        differences in ``actorType`` or ``actorTypeConfidence`` are ignored.

 891            crash

 896    def _get_actors_session_data(
 897        self, session_index: int, session: Session
 898    ) -> dict[ActorIdModel, ActorSessionData]:
 899        """Extract and aggregate per-actor session data from a single session.
 900
 901        For each actor session within ``session``, builds an
 902        ``ActorSessionData`` instance that includes the session metadata, real
 903        and forecasted positions, and the subset of crash records involving
 904        that actor. Keys are full ``ActorIdModel`` values (all fields), so a
 905        later actor session with an identical ID overwrites an earlier one.
 906
 907        Args:
 908            session_index (int): Zero-based index of the session within the
 909                collection.
 910            session (Session): Session record containing actor sessions and
 911                crash information.
 912
 913        Returns:
 914            dict[ActorIdModel, ActorSessionData]: Mapping from each actor
 915                identifier to its aggregated session data for the given
 916                session, in actor-session order.
 917
 918        Complexity:
 919            - Time: O(A * (p + c * a)), A = actor sessions, p = positions per
 920              actor session (re-validated lists), c = crashes, a = actors per
 921              crash.
 922            - Space: O(A * (p + c)), the built ActorSessionData entries.
 923        """
 924        session_time = session.sessionTime
 925        crashes_info = session.crashesInfo
 926        actors_session_data: dict[ActorIdModel, ActorSessionData] = {}
 927        for actor_session in session.actorsSession:
 928            actor_id = actor_session.actorId
 929            actors_session_data[actor_id] = ActorSessionData(
 930                sessionIndex=session_index,
 931                sessionTime=session_time,
 932                dataType=actor_session.data.dataType,
 933                realPositions=actor_session.data.realPositions,
 934                forecastedPositions=actor_session.data.forecastedPositions,
 935                crashInfo=self._get_crashes_actor_ids(
 936                    actor_id=actor_id, crash_list=crashes_info
 937                ),
 938            )
 939        return actors_session_data

 941    def get_collection_actors(
 942        self, collection_sessions: CollectionSessions
 943    ) -> CollectionActors:
 944        """Group per-session actor data into a ``CollectionActors`` keyed by actor ID.
 945
 946        Iterates over all sessions in ``collection_sessions``, extracts per-actor session data from
 947        each via ``_get_actors_session_data``, and groups the results by ``actor_key``
 948        (``stationId``, ``objectId``). When the same actor appears with a different
 949        ``actorType`` or ``actorTypeConfidence``, the first-seen ``ActorIdModel`` is kept.
 950
 951        Args:
 952            collection_sessions (CollectionSessions): Collection of sessions
 953                containing actor session data to aggregate.
 954
 955        Returns:
 956            CollectionActors: Versioned document containing one
 957                ``CollectionActor`` entry per actor (in first-seen order),
 958                each holding all its sessions in session order.
 959
 960        Complexity:
 961            - Time: O(N + sum over sessions of A_s * c_s * a), N = total
 962              positions, A_s = actors of session s, c_s = crashes of session
 963              s, a = actors per crash.
 964            - Space: O(N + sum over sessions of A_s * c_s), the regrouped
 965              session data.
 966        """
 967        actors_dict: dict[ActorKey, tuple[ActorIdModel, list[ActorSessionData]]] = {}
 968        for idx_session, session in enumerate(collection_sessions.sessions):
 969            actors_session_data = self._get_actors_session_data(
 970                session_index=idx_session, session=session
 971            )
 972            for actor_id, session_data in actors_session_data.items():
 973                actors_dict.setdefault(actor_id.actor_key, (actor_id, []))[1].append(
 974                    session_data
 975                )
 976        return CollectionActors(
 977            formatVersion=CollectionActorsDataModelVersion.V1,
 978            collections=[
 979                CollectionActor(actorId=actor_id, sessions=sessions_data)
 980                for actor_id, sessions_data in actors_dict.values()
 981            ],
 982        )
