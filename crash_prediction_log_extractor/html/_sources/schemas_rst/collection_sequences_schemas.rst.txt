Collection Sequences V1 Schema
==============================

The Collection Sequences Version 1 schema stores, for every actor, the
time-ordered real positions and, for each of them, the positions previously
forecasted for that instant by earlier sessions, together with their distance
and heading errors. It is written as ``<stem>_sequences.json`` by
``DataRetriever.get_collection_sequences`` and feeds the distance/heading
dashboard. The JSON Schema is generated from the Pydantic models of the
``collection_sequences`` module.

Overview
--------

Data hierarchy::

    CollectionSequences
    `-- actorsSequence                         (list[ActorSequence])
        `-- ActorSequence                      (one per actor)
            |-- actorId                        (ActorIdModel)
            `-- sequence                       (list[SequenceElement])
                `-- SequenceElement            (one per time step)
                    |-- realPosition           (Position)
                    `-- forecastedPositions    (list[ForecastedPosition | None])
                        `-- ForecastedPosition (one per forecast step)
                            `-- position       (Position)

The root object ``CollectionSequences`` contains:

* ``formatVersion``: fixed to ``1``
* ``actorsSequence``: ``ActorSequence`` entries, one per actor, 0 to 10 000 entries

Each ``ActorSequence`` contains:

* ``actorId``: actor identifier (``ActorIdModel``)
* ``sequence``: ``SequenceElement`` entries, 0 to 1 000 000 entries

Each ``SequenceElement`` contains:

* ``sessionIndex``: index of the session that recorded the real position
  (uint32 range)
* ``sessionTime``: ISO-8601 session timestamp
* ``realPosition``: the real (ground-truth) ``Position``
* ``forecastedPositions``: one entry per forecast index, ``null`` when no
  forecast is available for that index; 0 to 10 000 entries

Each ``ForecastedPosition`` contains:

* ``sessionIndex``: index of the session that produced the forecast
* ``sessionTime``: ISO-8601 timestamp of that session
* ``position``: the forecasted ``Position``
* ``distanceError``: distance in meters between real and forecasted position,
  from ``0`` to ``20 037 509``
* ``headingError``: heading difference in degrees, from ``-180`` to ``180``,
  or ``null``

``ActorIdModel`` and ``Position`` are shared with the
:ref:`Collection Sessions schema <collection_sessions_schema>`.

Validation Notes
----------------

* Models are strict (no type coercion), frozen, and forbid unknown fields.
* ``distanceError`` and ``headingError`` are rounded to 2 decimals on
  serialization; a ``headingError`` outside ``[-180, 180]`` is wrapped into
  range before validation.
* Real positions are deduplicated: a position at or before the last appended
  timestamp of the actor is skipped.
* Forecasts are matched to a real position within ``maxToleranceTime``
  milliseconds (see the
  :ref:`configuration schema <crash_prediction_log_extractor_config_schema>`).
