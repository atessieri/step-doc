Package Script

This section describes how to use the script inside the project. The script is different for Windows and Linux.

Note

The scripts use uv program. If it is not installed, it is necessary to install it first using pip install uv

Create environment

The script creates a virtual environment in the project folder. The virtual environment is created in the folder .venv and the script will install all the dependencies in this folder.

$.\create_env.bat <python version>

$source create_env.sh <python version>

After the environment is created, it is necessary to activate it. The activation is done with the command:

$.venv\Script\activate

$source .venv\bin\activate

Development with Tox

The project uses tox for comprehensive automation of development tasks. All commands can be executed with UV for optimal performance and automatic Python version management.

Available Environments

List all available tox environments:

# List all tox environments
uv run tox list

Testing Environments

Run tests across multiple Python versions:

# Run all test environments in parallel (recommended)
uv run tox -p auto

# Run tests for specific Python versions
uv run tox -e py313
uv run tox -e py314

Generate coverage reports and badges:

# Combine coverage data and generate reports
uv run tox -e report

Code Quality Commands

Format code according to project standards:

# Auto-format code using multiple formatters
uv run tox -e format

Run linting and static analysis:

# Run all linting checks (ruff, mypy, pylint)
uv run tox -e lint

Documentation Commands

Generate API documentation:

# Generate sphinx API documentation
uv run tox -e apidoc

Build project documentation:

# Build HTML documentation
uv run tox -e docs-html

# Build LaTeX documentation
uv run tox -e docs-latex

Package Management

Upload package to registry:

# Build and upload package
uv run tox -e upload

Cleanup Commands

Clean build artifacts:

# Remove build artifacts and generated files
uv run tox -e clean

# Clean all tox environments
uv run tox -e cleanenv

PDF conversion

In order to create the pdf documentation, following the steps:

  1. Change the folder to the build folder:

    $cd build/latex

  2. Create the documentation in pdf format:

    $build/latex/make
