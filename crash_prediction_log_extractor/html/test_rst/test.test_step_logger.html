test.test_step_logger module

Unit tests for crash_prediction_log_extractor.step_logger.

This module validates the logging helpers used by the crash prediction log extractor package.

Covered behavior:

  • LogMode enum values and conversion to stdlib logging levels.

  • UtcFormatter.converter timestamp conversion via gmtime.

  • get_logger configuration for stdout and optional file logging, including handler levels and log directory creation.

  • logger_force_write temporary INFO-level override for logger and handlers, followed by restoration of original levels.

test.test_step_logger.test_get_logger(mocker: MockerFixture, file_log: Path | None, log_level: LogMode | None) → None[source]

Assert get_logger wires up stream and optional file handlers correctly.

Verifies that get_logger:

  • Calls getLogger() once with no arguments and clears existing handlers.

  • Sets the logger level to log_level (defaults to ERROR when None).

  • Creates a StreamHandler on sys.stdout fixed at ERROR level.

  • When file_log is given, creates the parent directory (parents=True, exist_ok=True) and attaches a FileHandler at the resolved log level.

  • Returns the configured logger instance.

Parameters:

  • mocker – pytest-mock fixture for patching dependencies.

  • file_log – Path to the log file, or None for stream-only logging.

  • log_level – Desired log level, or None to use the default (ERROR).

Returns:

None
