Position Data V1 Schema
=======================

The Position Data Schema defines the structure of a single GNSS position fix reported by
a station. This schema captures:

    * The message type (``position``)
    * The time of the fix, in Unix epoch milliseconds
    * Latitude and longitude in decimal degrees
    * Optional altitude, speed, bearing and horizontal accuracy

Latitude and altitude are clamped, and longitude and bearing are wrapped, into their valid
ranges; speed and accuracy must only be non-negative. Non-finite numbers are rejected.

This schema defines a JSON Schema **version 1**. For further information, please refer
to the python classes.
