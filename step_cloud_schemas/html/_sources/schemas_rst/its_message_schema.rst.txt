ITS Message Schema
==================

The ITS Message Schema defines the root envelope that wraps the ITS messages supported by the
STEP Cloud platform into a single discriminated union model. The ``type`` field of the
wrapped message (the discriminator) selects the concrete message model, so an invalid message
is validated against, and reported for, that model only. The type can be one of:

    * **CAM**: Cooperative Awareness Message, see :doc:`cam_message`
    * **CPM**: Cooperative Perception Message, see :doc:`cpm_message`
    * **DENM**: Decentralized Environmental Notification Message, see :doc:`denm_message`

This schema defines a JSON Schema **version 1**. For further information, please refer
to the python classes.
