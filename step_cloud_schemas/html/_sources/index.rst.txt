STEP is a distributed system that predicts vehicle collisions from V2X messages,
made up of independently deployed components (Broker, Adapter, Client, Producer,
Trajectory Forecasting, Monitoring, Machine Learning). The STEP Cloud Schemas
project is the shared contract layer between those components: it provides a
standardized way to define and validate the data structures exchanged between
them in cloud-based STEP implementations.

Key Features
------------

* JSON Schema and Pydantic model definitions for ITS (CAM, DENM, CPM) and
  CloudEvents data structures
* Validation tools for ensuring data compliance across components
* Easy integration with cloud services and APIs

Purpose
-------

This project aims to:

    * Standardize the data exchanged between the STEP Broker, Adapter, Client,
      Producer, and Machine Learning components
    * Enable interoperability between different STEP-compatible services
    * Provide a robust validation framework for STEP data
    * Simplify the integration of STEP data in modern cloud architectures

Getting Started
---------------

To begin using the STEP Cloud Schemas, refer to the :doc:`installation<installation>` 
section and :doc:`usage<usage>` section.
