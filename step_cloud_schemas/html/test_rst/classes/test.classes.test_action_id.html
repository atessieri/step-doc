TestActionId class is responsible for testing the ActionId class functionality.

This test suite verifies the creation, validation, and conversion of ActionId instances, ensuring they meet the specified requirements for STEP-Cloud communications. Test cases include:

  • Valid action ID creation with normal and boundary values

  • Default action ID instance creation

  • Invalid value handling and validation

  • Instance immutability and extra-field rejection

The ActionId class requires:

  • originatingStationId: Integer between 0 and 4294967295

  • sequenceNumber: Integer between 0 and 65535
