   1"""Geographic coordinate handling and calculations module.
   2
   3This module provides functionality for working with geographic coordinates and
   4performing various geodesic calculations. All geodesic distances and bearings
   5use the WGS84 ellipsoid via ``pyproj``'s ``Geod`` class, which solves the
   6forward and inverse geodesic problems (distance and azimuth are computed
   7together in a single call, whether scalar or vectorized over numpy arrays).
   8
   9Key Features:
  10    - Geodesic distance calculations between two geographic points.
  11    - Forward-azimuth (heading/bearing) calculations between points.
  12    - Forward geodesic moves: project a new point from an origin given a
  13      distance and heading (``move_point_a_to_point_b``).
  14    - Batch distance/heading calculations relative to a predecessor point or a
  15      fixed broadcast origin (``get_distances_and_headings_vector`` and its
  16      numpy counterpart), and between two independent, index-aligned point
  17      arrays (``get_distances_and_headings_pairs_vector`` and its numpy
  18      counterpart).
  19    - Batch forward geodesic moves: project a destination point for each
  20      origin/distance/heading triple (``get_destination_points_vector`` and
  21      its numpy counterpart).
  22    - Spherical-to-Cartesian coordinate conversion: map (lat, lon) pairs to
  23      local East-North (x, y) displacements relative to per-point origins.
  24    - Cartesian-to-Spherical coordinate conversion: recover (lat, lon) from
  25      East-North (x, y) displacements relative to per-point origins.
  26    - Both conversion directions are available in three forms:
  27        - Scalar via the ``Geocode`` instance (single pair).
  28        - Vectorized list API (list of tuples in, list of tuples out).
  29        - Vectorized numpy API (NDArray in, NDArray out) for high-throughput
  30          processing of millions of points.
  31    - Lat/lon-aligned bounding-box calculation around an anchor point and
  32      radius (``anchor_radius_to_bounding_box``).
  33    - Support for distance units (kilometers, meters) and angle units
  34      (degrees, radians).
  35

  37    - DistanceUnit: Enumeration of distance measurement units.
  38    - AngleUnit: Enumeration of angular measurement units.
  39    - LatLonPoint: A geographic point as (latitude, longitude).
  40    - CartesianPoint: A local East-North (x, y) point relative to some origin.
  41    - DistanceHeading: A (distance, heading) pair between two points.
  42    - DistanceAzimuthArray: Vectorized (distance, azimuth) arrays, one entry
  43      per input point pair.
  44    - BoundingBox: A lat/lon-aligned rectangle expressed as decimal-degree bounds.
  45    - Geocode: Main class for geographic calculations and coordinate handling.
  46

  48    - Time: O(1) for scalar operations performed through a ``Geocode`` instance
  49      (``get_distance``, ``get_heading``, ``get_mutual_cartesian_coordinates``,
  50      ``get_cartesian_coordinate``, ``move_point_a_to_point_b``) or its scalar

 238    Earth. This class provides functionality for working with geographic coordinates
 239    (latitude, longitude) and performing various calculations such as distance, bearing,

 241
 242    Format of the point is (latitude, longitude).
 243
 244    Attributes:

 450

 479        distance: float,
 480        heading: float,
 481        dist_unit: DistanceUnit,
 482        angle_unit: AngleUnit,
 483    ) -> None:
 484        """Move point_b to the position reached from point_a by distance and heading.
 485
 486        Solves the forward geodesic problem on the WGS84 ellipsoid, starting at
 487        point_a and traveling ``distance`` along ``heading`` (clockwise from
 488        north), then stores the resulting coordinates in point_b.
 489
 490        Args:
 491            distance (float): Distance to travel from point_a, in ``dist_unit``.
 492            heading (float): Direction to travel in, in ``angle_unit``, measured

 495            angle_unit (AngleUnit): Unit of ``heading``.
 496

 498            None
 499

 501            point_a is left unchanged. The inverse-geodesic cache is refreshed
 502            directly from the inputs, since the forward azimuth from point_a to
 503            the new point_b is exactly the (normalized) heading used here,
 504            avoiding a redundant inverse-geodesic solve.
 505
 506        Complexity:
 507            - Time: O(1). A single ``Geod.fwd`` call on scalar inputs.
 508            - Space: O(1). No additional memory is allocated.
 509        """
 510        distance_m = dist_unit.to_meters(distance)
 511        heading_deg = heading if angle_unit == AngleUnit.DEGREES else degrees(heading)
 512        lon_b, lat_b, _ = self._geod.fwd(
 513            self._point_a[1], self._point_a[0], heading_deg, distance_m
 514        )
 515        self._point_b = LatLonPoint(lat_b, lon_b)
 516        self._inverse_cache = DistanceHeading(float(distance_m), heading_deg % 360.0)

 595    @staticmethod
 596    def _inverse_vector(
 597        from_arr: SphericalPointsArray, to_arr: SphericalPointsArray
 598    ) -> DistanceAzimuthArray:
 599        """Solve the inverse geodesic problem for each point pair, vectorized.
 600
 601        Args:
 602            from_arr (SphericalPointsArray): Shape (n,) structured array with fields
 603                ("latitude", "longitude"). Origin points, in decimal degrees.
 604            to_arr (SphericalPointsArray): Shape (n,) structured array with fields
 605                ("latitude", "longitude"). Destination points, in decimal degrees.
 606
 607        Returns:
 608            DistanceAzimuthArray: (distance_m, azimuth_deg), each shape (n,).
 609                azimuth_deg is in the range (-180, 180].
 610
 611        Complexity:
 612            - Time: O(n), where n is the number of points in ``from_arr``/
 613              ``to_arr``. A single vectorized ``Geod.inv`` call; distance and
 614              forward azimuth are solved together, not separately.
 615            - Space: O(n). Two length-n float64 arrays are returned.
 616        """
 617        azimuth_deg, _, distance_m = Geocode._geod.inv(
 618            lons1=from_arr["longitude"],
 619            lats1=from_arr["latitude"],
 620            lons2=to_arr["longitude"],
 621            lats2=to_arr["latitude"],
 622        )
 623        return DistanceAzimuthArray(
 624            np.asarray(distance_m, dtype=np.float64),
 625            np.asarray(azimuth_deg, dtype=np.float64),
 626        )

 633
 634        For each index i, returns the bearing from from_arr[i] to to_arr[i] in
 635        radians, measured clockwise from north. The result range is (-π, π].

 637        Args:
 638            from_arr (SphericalPointsArray): Shape (n,) structured array with fields
 639                ("latitude", "longitude"). Origin points, in decimal degrees.
 640            to_arr (SphericalPointsArray): Shape (n,) structured array with fields
 641                ("latitude", "longitude"). Destination points, in decimal degrees.
 642
 643        Returns:

 648            - Time: O(n), where n is the number of points in ``from_arr``/

 651              ``Geod.inv`` is discarded.
 652        """
 653        _, azimuth_deg = Geocode._inverse_vector(from_arr=from_arr, to_arr=to_arr)

 656    @staticmethod
 657    def get_distances_and_headings_vector_numpy(
 658        points: SphericalPointsArray,
 659        previous_point: SphericalPoint | None,
 660        dist_unit: DistanceUnit,
 661        angle_unit: AngleUnit,
 662        broadcast: bool = False,
 663    ) -> DistanceHeadingArray:
 664        """Calculate distance and heading for each point relative to a predecessor.
 665
 666        Uses vectorized numpy operations for efficiency.
 667
 668        Sequential mode (broadcast=False, default):
 669            The predecessor of points[0] is previous_point (if given); the
 670            predecessor of points[i] is points[i-1].
 671
 672        Broadcast mode (broadcast=True):
 673            previous_point is used as a fixed origin for every point in the list:
 674            each result[i] holds (dist(previous_point, points[i]), heading(previous_point→points[i])).
 675            This covers fan-out patterns such as "distance from a reference to many targets."
 676            When previous_point is None in broadcast mode, every result row is NaN.
 677
 678        Args:
 679            points (SphericalPointsArray): Shape (n,) structured array with fields
 680                ("latitude", "longitude"), in decimal degrees.
 681            previous_point (SphericalPoint | None): 0D structured scalar with
 682                fields ("latitude", "longitude"). Fixed origin (broadcast mode)
 683                or predecessor of points[0] (sequential mode). When None in sequential
 684                mode the first result row is NaN.
 685            dist_unit (DistanceUnit): Unit for returned distances.
 686            angle_unit (AngleUnit): Unit for returned headings.
 687            broadcast (bool): When True, treat previous_point as a fixed origin and
 688                compute dist/heading from previous_point to each point independently.
 689                Defaults to False (sequential / consecutive-pair mode).
 690
 691        Returns:
 692            DistanceHeadingArray: Shape (n,) structured array with fields
 693            ("distance", "heading"), dtype float64. Rows where no predecessor is
 694            available (first point in sequential mode without previous_point, or all
 695            rows in broadcast mode without previous_point) are filled with NaN.
 696
 697        Raises:
 698            ValueError: If ``points`` is not a non-empty 1D structured array with
 699                fields ("latitude", "longitude"), or if ``previous_point`` is not
 700                None and is not a 0D structured scalar with the same fields.
 701
 702        Complexity:
 703            - Time: O(n), where n = len(points). Array construction and the
 704              single vectorized ``Geod.inv`` call (solving distance and forward
 705              azimuth together) are each O(n). This is asymptotically optimal
 706              since every pair must be visited.
 707            - Space: O(n). In sequential mode a single working array of shape
 708              (n+1,) or (n,) is allocated and from_arr/to_arr are zero-copy
 709              views into it. In broadcast mode from_arr is an explicit (n,)
 710              repeat of previous_point. Two O(n) arrays hold the distance and
 711              azimuth returned by ``Geod.inv``.
 712        """
 713        Geocode.validate_points_shape(
 714            points=points, name="points", dtype=Geocode.SPHERICAL_POINT_DTYPE
 715        )
 716        if previous_point is not None:
 717            Geocode.validate_single_point(point=previous_point, name="previous_point")
 718        points_size = int(points.shape[0])
 719        if broadcast:
 720            if previous_point is None:
 721                return np.full(
 722                    shape=points_size,
 723                    fill_value=np.nan,
 724                    dtype=Geocode.DISTANCE_HEADING_DTYPE,
 725                )
 726            from_arr = np.repeat(a=np.atleast_1d(previous_point), repeats=points_size)
 727            to_arr = points
 728            n_nan = 0
 729        elif previous_point is not None:
 730            # Single allocation; from_arr/to_arr are zero-copy views
 731            all_arr = np.concatenate([np.atleast_1d(previous_point), points])
 732            from_arr = all_arr[:-1]
 733            to_arr = all_arr[1:]
 734            n_nan = 0
 735        else:
 736            # Sequential without previous_point: first row is NaN
 737            from_arr = points[:-1]
 738            to_arr = points[1:]
 739            n_nan = 1
 740        n_pairs = int(from_arr.shape[0])
 741        out = np.empty(shape=n_nan + n_pairs, dtype=Geocode.DISTANCE_HEADING_DTYPE)
 742        if n_nan:
 743            out[0] = np.nan
 744        # Distance and forward azimuth are solved together by a single geodesic
 745        # inverse call, so both are always computed.
 746        distance_m, azimuth_deg = Geocode._inverse_vector(
 747            from_arr=from_arr, to_arr=to_arr
 748        )
 749        out["distance"][n_nan:] = dist_unit.from_meters(distance_m)
 750        out["heading"][n_nan:] = (
 751            azimuth_deg % 360.0
 752            if angle_unit == AngleUnit.DEGREES
 753            else np.deg2rad(azimuth_deg)
 754        )
 755        return out

 933    def get_destination_points_vector_numpy(

 940        """Solve the forward geodesic problem for each origin/distance/heading triple.
 941

 943        ``distances[i]`` from ``origins[i]`` along ``headings[i]`` (clockwise
 944        from north). Vectorized counterpart of ``move_point_a_to_point_b``.
 945
 946        Args:
 947            origins (SphericalPointsArray): Shape (n,) structured array with fields
 948                ("latitude", "longitude"). Starting point of each triple, in
 949                decimal degrees.
 950            distances (npt.NDArray[np.float64]): Shape (n,). Distance to travel
 951                from each origin, in ``dist_unit``.
 952            headings (npt.NDArray[np.float64]): Shape (n,). Direction to travel
 953                in, in ``angle_unit``, measured clockwise from north.
 954            dist_unit (DistanceUnit): Unit of ``distances``.
 955            angle_unit (AngleUnit): Unit of ``headings``.
 956
 957        Returns:
 958            SphericalPointsArray: Shape (n,) structured array with fields
 959            ("latitude", "longitude"), dtype float64, one destination point
 960            per input triple.
 961
 962        Raises:
 963            ValueError: If ``origins`` is not a non-empty 1D structured array
 964                with fields ("latitude", "longitude"), or if ``distances`` or
 965                ``headings`` is not 1D with the same length as ``origins``.
 966
 967        Complexity:
 968            - Time: O(n), where n = len(origins). A single vectorized
 969              ``Geod.fwd`` call.
 970            - Space: O(n). The structured output array plus a handful of O(n)
 971              intermediate arrays for the unit conversions.
 972        """
 973        Geocode.validate_points_shape(
 974            points=origins, name="origins", dtype=Geocode.SPHERICAL_POINT_DTYPE
 975        )

 977            raise ValueError(f"distances must be a 1D array, got {distances.ndim}D")
 978        if distances.shape[0] != origins.shape[0]:
 979            raise ValueError(
 980                "distances and origins must have the same length, got "
 981                f"{distances.shape[0]} and {origins.shape[0]}"
 982            )

 984            raise ValueError(f"headings must be a 1D array, got {headings.ndim}D")
 985        if headings.shape[0] != origins.shape[0]:
 986            raise ValueError(
 987                "headings and origins must have the same length, got "
 988                f"{headings.shape[0]} and {origins.shape[0]}"
 989            )

 991        headings_deg = (
 992            headings if angle_unit == AngleUnit.DEGREES else np.degrees(headings)
 993        )
 994        longitudes, latitudes, _ = Geocode._geod.fwd(
 995            origins["longitude"], origins["latitude"], headings_deg, distances_m
 996        )
 997        out = np.empty(shape=origins.shape[0], dtype=Geocode.SPHERICAL_POINT_DTYPE)
 998        out["latitude"] = latitudes
 999        out["longitude"] = longitudes
1000        return out

1056        point.
1057
1058        This function takes cartesian coordinates (x,y) and converts them to geographical
1059        coordinates using a reference point as origin. The conversion solves the forward
1060        geodesic problem on the WGS84 ellipsoid.
1061
1062        Args:
1063            reference (LatLonPoint): Reference point as (latitude, longitude)
1064            cartesian_coordinates (CartesianPoint): Cartesian coordinates as (x, y)
1065            unit (DistanceUnit): Unit of measurement for the cartesian coordinates
1066
1067        Returns:
1068            Geocode: A Geocode object containing the reference point (point_a) and
1069            the calculated destination point (point_b)
1070
1071        Example:
1072            >>> ref = LatLonPoint(40.7128, -74.0060)  # New York City
1073            >>> coords = CartesianPoint(1000, 2000)  # meters from reference
1074            >>> geocode = get_geocode_from_cartesian_coordinates(
1075            ...     ref, coords, DistanceUnit.METERS
1076            ... )
1077
1078        Complexity:
1079            - Time: O(1). A fixed number of scalar operations plus a single
1080              ``Geod.fwd`` call on scalar inputs.
1081            - Space: O(1). No additional memory is allocated.
1082        """
1083        distance = hypot(cartesian_coordinates[0], cartesian_coordinates[1])
1084        bearing_deg = degrees(atan2(cartesian_coordinates[0], cartesian_coordinates[1]))
1085        distance_m = unit.to_meters(distance)
1086        lon_b, lat_b, _ = Geocode._geod.fwd(
1087            reference[1], reference[0], bearing_deg, distance_m
1088        )
1089        return Geocode(point_a_par=reference, point_b_par=LatLonPoint(lat_b, lon_b))

1128

1163                f"{references.shape[0]} and {points.shape[0]}"

1240            - y-axis pointing North (positive = north)
1241

1243            references (SphericalPointsArray): Shape (n,) structured array with fields
1244                ("latitude", "longitude"). Origin points, in decimal degrees.
1245            points (CartesianPointsArray): Shape (n,) structured array with fields
1246                ("x", "y"). Cartesian displacements, in ``dist_unit``.
1247            dist_unit (DistanceUnit): Unit of the x and y displacement values.
1248

1250            SphericalPointsArray: Shape (n,) structured array with fields
1251                ("latitude", "longitude"), dtype float64.
1252                latitude in decimal degrees  [-90,  90].
1253                longitude in decimal degrees [-180, 180].

1256            ValueError: If ``references`` is not a non-empty 1D structured array
1257                with fields ("latitude", "longitude"), if ``points`` is not a
1258                non-empty 1D structured array with fields ("x", "y"), or if they
1259                do not have the same length.
1260
1261        Complexity:
1262            - Time: O(n), where n is the number of points in ``references``/
1263              ``points``. A single vectorized ``Geod.fwd`` call plus O(n) numpy
1264              trigonometry.
1265            - Space: O(n). A handful of O(n) arrays hold the distance, azimuth,
1266              and ``Geod.fwd`` results.
1267        """
1268        Geocode.validate_points_shape(
1269            points=references, name="references", dtype=Geocode.SPHERICAL_POINT_DTYPE
1270        )
1271        Geocode.validate_points_shape(
1272            points=points, name="points", dtype=Geocode.CARTESIAN_POINT_DTYPE
1273        )
1274        if references.shape[0] != points.shape[0]:
1275            raise ValueError(
1276                "references and points must have the same length, got "
1277                f"{references.shape[0]} and {points.shape[0]}"
1278            )
1279        n = int(points.shape[0])
1280        x = points["x"]
1281        y = points["y"]

1283        distance_m = dist_unit.to_meters(distance)

1289        out["latitude"] = latitudes
