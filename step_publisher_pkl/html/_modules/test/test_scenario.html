   1"""Test module for step_publisher_pkl scenario functionality.
   2
   3This module contains unit tests for the ``Scenario`` class and the ``TimeReference``
   4NamedTuple defined in ``step_publisher_pkl.scenario``. It validates loader dispatch
   5(grouping loaders by extension, falling back to every loader for an unknown
   6extension), message storage (blacklist filtering, station queue creation/append),
   7scenario-to-real time conversion for CAM, CPM, and DENM messages, and the
   8generator-based vehicle/message iteration API.
   9
  10File-format-specific parsing (JSONL, pickle actor, pickle camera) now lives in
  11``step_publisher_pkl.loaders`` and is covered by its own test modules
  12(``test_loaders_jsonl_loader.py``, ``test_loaders_pickle_actor_loader.py``,
  13``test_loaders_pickle_camera_loader.py``); this module only exercises ``Scenario``
  14itself, using real ``FileLoader`` instances for the ``load_data`` integration tests.
  15
  16Key test areas:
  17    - TimeReference: Validates the NamedTuple's fields and immutability.
  18    - Scenario: Loader-by-suffix grouping, message storage (blacklist/queue
  19      handling), scenario-to-real time conversion for every supported message type,
  20      and the public load_data/get_vehicle_ids/pop_message API.
  21
  22The tests use real temporary JSONL and pickle files (via pytest's ``tmp_path``
  23fixture) for the load_data integration tests, and real Pydantic model instances
  24(via each schema class's ``get_default()``) for time-conversion logic, keeping the
  25suite close to the actual runtime behavior instead of over-mocking.

  62def _expected_real_iso(original_iso: str, time_reference: TimeReference) -> str:
  63    """Compute the expected real-world ISO time for a scenario ISO time.
  64
  65    This helper independently reproduces the scenario-to-real time conversion using
  66    only ``ItsTime`` primitives, so tests that exercise ``Scenario``'s private
  67    ``_update_time_*`` helpers do not depend on ``Scenario._scenario_time_to_real``
  68    itself for their expected values.
  69
  70    Args:
  71        original_iso (str): The scenario-relative ISO-8601 time string to convert.
  72        time_reference (TimeReference): The time reference mapping used for
  73            conversion.
  74
  75    Returns:
  76        str: The expected real-world ISO-8601 time string.
  77    """
  78    original_time = ItsTime.create_from_iso_time(time_str=original_iso)
  79    delta_ms = original_time.time_difference(
  80        other_time=time_reference.start_scenario_time
  81    )
  82    return str(object=time_reference.start_real_time + delta_ms)
