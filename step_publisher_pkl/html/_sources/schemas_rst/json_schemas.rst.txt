JSON Schemas
============

The STEP Publisher Pickle uses JSON schemas to define the structure of messages and configurations. 
This ensures that the data exchanged with the STEP broker and configuration files adheres to a specific format, 
facilitating interoperability and validation.

ITS Message Schema
------------------

The messages published by STEP Publisher Pickle are as follows:

   * **CAM**: Defines the structure for Cooperative Awareness Messages (CAM) used in the ITS system. 
     The publisher converts CARLA simulator trajectory data from pickle files into CAM messages that 
     comply with ETSI TS 103 900 standards for V2X communication.

Configuration Schema
--------------------

The schema defines the structure for configuration of STEP Publisher Pickle subsystem, including:

   * **MQTT Client Configuration**: Connection parameters, keepalive settings, and message queue limits
   * **MQTT Protocol Configuration**: Protocol version, transport type, and subscription options
   * **Broker Configuration**: Host, port, credentials, and TLS/SSL security settings
   * **Logging Configuration**: Verbosity levels, handlers, and log file management
   * **Pickle Folder Path**: Location of CARLA-generated pickle files containing vehicle trajectory data
