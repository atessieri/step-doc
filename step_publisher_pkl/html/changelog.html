Changelog

All notable changes to step_publisher_pkl are documented in this file.

1.4.8 - 2026-11-05

1.4.8 - Added

  • pyrefly>=1.4.1,<2.0 was added as a static type checker: [tool.pyrefly] configuration in pyproject.toml, a pyrefly check step in tox -e lint, and a badge and mentions in the README and documentation.

  • The changelog is now part of the Sphinx documentation (doc/source/changelog.rst, included in the index.rst toctree, with the myst_parser extension enabled).

  • TOX_UV_PYTHON_PREFERENCE lets the tox environments choose the uv Python preference (default only-managed); the CI sets it to system, so tests run on the Python of the Docker image.

1.4.8 - Changed

  • Requires pydantic>=2.14.3,<3.0, step_cloud_schemas>=3.4.3,<4.0 and step_lib>=3.1.4,<4.0.

  • Tooling floors were raised: coverage>=7.17.2, mypy>=2.4.1, pytest>=9.2.0, ruff>=0.17.3, tox>=4.67.11, tox-uv>=1.37.5, types-docutils>=0.23.0.20261030, uv >=0.13.7 and ruff required-version >=0.17.3.

  • tox.ini: the runner, package and uv Python settings moved from [tox] to [testenv]; basepython and recreate were removed, along with the PYTHONPATH setting; skip_install = True was replaced by package = skip.

  • doc/source/conf.py no longer imports the test package and locates the test directory by path for the docstring coverage report.

  • Unit tests: _FakeLoader.get_extension in test_scenario.py is marked with @override, and a redundant None check was removed from test_release_date.

1.4.7 - 2026-10-26

1.4.7 - Changed

  • Requires step_cloud_schemas>=3.4.2,<4.0 and step_lib>=3.1.3,<4.0.

  • Tooling floors were raised: coverage>=7.17.0, pytest-asyncio>=1.4.1, ruff>=0.17.2, sphinx-jsonschema>=1.20.1, uv >=0.13.5 and ruff required-version >=0.17.0.

  • The MessageType and MqttQoSConfig JSON schema title and description are now set with the json_schema_text decorator of step_cloud_schemas instead of a custom __get_pydantic_json_schema__.

  • The configuration JSON schema is generated with make_schema_generator of step_cloud_schemas; the private _ConfigGenerateJsonSchema was removed.

  • MessageType.orm_to_enum ends with assert_never instead of raising ValueError for an unknown member.

  • The package root now re-exports every public class (loaders, Scenario, TimeReference, StepBroker, StepPublisherApp, ExitCode, exceptions) in __all__.

  • Unit tests of the package __init__ and the configuration were updated.

1.4.6 - 2026-10-21

1.4.6 - Changed

  • Requires step_cloud_schemas>=3.4.0,<4.0 and step_lib>=3.1.2,<4.0.

  • Build and tooling floors were raised: setuptools>=84.2.1, sphinx>=9.2.0,<10.0 and uv >=0.13.4.

  • Config field bounds now use the shared constants exported by step_cloud_schemas (STRING_MIN_LENGTH/STRING_MAX_LENGTH, UINT16_*, UINT32_*, TIMEOUT_S_*, QUEUE_SIZE_*, MQTT_PACKET_SIZE_*, TOPICS_*_LENGTH, …), so previously unbounded string, list and numeric fields now have upper limits.

  • The JSON schema of the configuration was regenerated to reflect the new bounds.

  • CI: the .tox/.python/ uv-managed interpreters path was removed from the cache.

  • Unit tests of FileLoader, the GPX/JSONL/pickle loaders, Scenario, the package __init__ and the configuration were refreshed.

1.4.5 - 2026-10-20

1.4.5 - Changed

  • Requires step_cloud_schemas>=3.3.3,<4.0 and step_lib>=3.1.1,<4.0.

  • Build and tooling floors were raised: setuptools>=84.2.0, sphinx>=9.1.1,<10.0 and uv >=0.13.3.

  • The GitLab pipeline is created only for tags (workflow:rules) and the per-job only: tags rules were removed.

  • CI: shallow fetch (GIT_DEPTH: 10, GIT_STRATEGY: fetch), stable uv cache key per Python version, uv-managed interpreters cached, default-jre-headless instead of openjdk-*-jre-headless.

  • CI: doc deploy runs in the step_doc resource group and retries git pull --rebase && git push up to 3 times.

  • tox.ini passes UV_CACHE_DIR through to the test environments.

  • CI: the test report of each Python version is saved and published as test_report_py*.xml.

1.4.4 - 2026-10-19

1.4.4 - Changed

  • The MQTT credential is now read with step_lib MqttCredential.from_env; the local MqttCredential dataclass and the StepPublisherApp environment parsing helpers were removed, and python-dotenv is no longer a direct dependency.

  • Raised the minimum versions of step_cloud_schemas (3.3.1), step_lib (3.1.0), pytest-mock, tox and sphinx-jsonschema.

  • The -s/--conf_schema and -t/--conf_template options now document a target directory instead of a file.

  • Coverage now fails below 100% ([tool.coverage.report] fail_under); the JUnit report of each tox test environment is named after the environment, and the lint environment runs the source doctests.

  • Reworked the README and the Sphinx documentation (architecture, commands, usage, input files, .env.example) and refreshed source docstrings.

  • Updated the unit tests for the removed credential code.

1.4.4 - Fixed

  • Scenario drops a station whose messages all have an unsupported type instead of keeping it empty.

  • The pkl_change_station_id and remove_heading_speed examples map argparse’s own exit (help, version, usage error) to an ExitCode instead of letting SystemExit escape, and return the integer exit code.

1.4.3 - 2026-10-16

1.4.3 - Changed

  • Renamed “gateway” to “broker” / “broker client” in the step_broker module docstrings and in the package docstring.

  • MQTT_USERNAME and MQTT_PASSWORD are now optional environment variables where an empty value counts as unset.

  • The MQTT credential INFO log no longer prints the username; it reports only whether authentication is configured (auth=True|False).

  • A non-integer MQTT_PORT now raises a ValueError naming the environment variable.

  • Added unit tests for the new environment parsing helpers.

1.4.2 - 2026-10-16

1.4.2 - Changed

  • MqttProtocolConfig.sessionExpiry is now bounded to 0-4294967295 (the MQTT 5 four-byte property); the field description documents that 0 ends the session on disconnection.

  • MqttProtocolConfig.keepalive is now bounded to 0-65535 (the MQTT two-byte field); the field description documents that 0 disables the keepalive.

  • MqttProtocolConfig.timeout now requires a value of at least 1 (was 0).

  • Regenerated the v1 JSON schema and updated the config tests accordingly.

1.4.1 - 2026-10-16

1.4.1 - Fixed

  • StepPublisherApp._get_mqtt_credential now loads the .env file via load_dotenv(find_dotenv(usecwd=True)), so it is searched from the current working directory (or an ancestor) instead of the installed module’s directory in site-packages.

1.4.1 - Changed

  • Dependency constraints bumped: step_lib>=3.0.6, ruff>=0.17.1, tox>=4.66.0; uv.lock refreshed.

  • Documentation (architecture.rst, usage.rst, package docstring) and the .env loading unit test updated accordingly.

1.4.0 - 2026-10-14

1.4.0 - Added

  • step_publisher_app module with StepPublisherApp, the AbstractApp workload run by step_cloud_schemas.AppRunner: reads the MQTT credential, connects to the STEP broker, loads the scenario and runs one publisher task per vehicle. ExitCode moved here from __main__.

  • MessageType.POSITION_DATA ("position_data") publish topic type, mapped to GenericMessageType.POSITION_DATA by the new MessageType.orm_to_enum(); the example config.json gains a TRIP_SIMULATOR position data topic.

  • FileLoader.EXTENSION class attribute, validated by __init_subclass__; get_extension is no longer abstract and returns it.

  • .gitattributes normalizing text files to LF in the repository, and the files_equal_as_text test helper comparing reference files regardless of line endings.

  • pytest-timeout dev dependency (300 s per test) and myst-parser doc dependency.

1.4.0 - Changed

  • Requires step_lib>=3.0.5,<4.0 and step_cloud_schemas>=3.2.1,<4.0 (TAI timestamps and new wire format: every station must be upgraded together).

  • __main__ only parses the CLI and loads the configuration, then hands a StepPublisherApp to AppRunner, which owns the event loop, signal handling and cooperative shutdown (_main_async, _publisher_run, _wait_for_shutdown, _signal_handler, _signals_install, _exception_handler and _get_mqtt_credential removed from __main__).

  • build_cam_data() moved into FileLoader as the _build_cam_data() method (its dt argument renamed to timestamp).

  • JsonlLoader skips blank lines.

  • The loaders package no longer re-exports the loader classes: import them from their own submodules.

  • StepBroker no longer logs every published message at INFO level.

  • Docs: CAM example include renamed to cam_data_v1_schema_example.json; tox badge links to tox.wiki.

  • CI moves every per-Python-version coverage file (parallel coverage data).

  • Dependency and tool minimum versions bumped (setuptools 84.0.0, uv 0.13.1, tox 4.65.5, tox-uv 1.37.0, numpy, pydantic, mypy, pylint, ruff, …).

  • step_broker.StepBroker configures TLS through step_lib.TLSParameters instead of a hand-built ssl.SSLContext, which step_lib 3.0.0 no longer accepts: CA file, client certificate/key and key password map to ca_certs, certfile, keyfile, keyfile_password, and sslVerifyServerCert=false to cert_reqs=ssl.CERT_NONE (hostname check included). The minimum TLS version is Python’s default (TLS 1.2).

1.4.0 - Fixed

  • PickleActorLoader and PickleCameraLoader raise LoaderError instead of EOFError on an empty/truncated pickle file.

1.4.0 - Removed

  • ShutdownRequestedError from step_exception (shutdown is handled by AppRunner).

1.3.4 - 2026-09-22

1.3.4 - Changed

  • main() no longer forces a SelectorEventLoop on Windows when constructing the asyncio.Runner; it now uses the default loop factory on all platforms.

  • Dependency step_lib updated to >=2.0.9,<3.0.

1.3.3 - 2026-09-20

1.3.3 - Added

  • _signals_install() in __main__ registers the shutdown signal handlers before the event loop starts and again after _main_async returns, so a late signal is still routed through _signal_handler.

  • Tests for the signal handler installation in test___main__.py.

1.3.3 - Changed

  • Module documentation now lists the four supported input formats (JSONL, pickle actor, pickle camera, GPX) and the pluggable loaders package.

  • Complexity annotations updated to O(s log s) for the sorted-collection based scenario.

  • _wait_for_shutdown() parameter publisher_tasks renamed to tasks.

  • Docstrings of JsonlLoader, Scenario and step_broker aligned with the current behaviour.

  • Dependencies updated: gpx>=2026.4.0, ruff>=0.16.8, tox>=4.63.0, types-docutils>=0.23.0.20260917, uv>=0.12.17.

1.3.2 - 2026-09-16

1.3.2 - Added

  • Scenario.load_data() now logs a WARNING when a file could not be loaded by any available loader, and a second WARNING when a loader accepts a file but produces zero messages (e.g. an empty JSONL file), instead of silently skipping it.

1.3.2 - Changed

  • JsonlLoader no longer takes a logger and no longer skips individual invalid/ unsupported lines with a warning; any validation failure from the first line onward now raises LoaderError for the whole file (pydantic.ValidationError is caught as the ValueError subclass it is).

  • PickleActorLoader and PickleCameraLoader no longer pre-validate their unpickled data with dedicated _validate_pickle_actor_data()/_validate_pickle_camera_data() helpers; malformed structures now surface as TypeError/KeyError/ValueError/ValidationError raised naturally during conversion, still wrapped into LoaderError.

  • StepBroker.__init__ now pins the TLS minimum_version to ssl.TLSVersion.TLSv1_2 instead of ssl.TLSVersion.MAXIMUM_SUPPORTED.

  • GpxLoader.__call__ now only wraps GPX parsing (not point-to-message conversion) in its try/except.

1.3.1 - 2026-09-15

1.3.1 - Added

  • step_publisher_pkl.loaders.file_loader.build_cam_data(): shared CamDataV1 construction helper factored out of PickleActorLoader and GpxLoader, which previously duplicated the same field-mapping logic.

  • PickleCameraLoader._validate_pickle_camera_data() now returns the validated list[CpmDataV1] instead of discarding them, so __call__ no longer re-validates each item a second time when building CpmMessageV1 instances.

1.3.1 - Changed

  • MqttCredential is now a frozen, slotted dataclass instead of a NamedTuple, with fields renamed url/port/username/password -> mqtt_url/mqtt_port/mqtt_username/ mqtt_password, and validates itself on construction (mqtt_url must be non-blank, mqtt_port must be in the 1-65535 range), raising ValueError instead of allowing an invalid credential to propagate to StepBroker.

  • _get_mqtt_credential() and StepBroker.__init__ updated for the MqttCredential field rename.

  • FileLoader.get_extension/__call__’s NotImplementedError messages now name the method directly instead of introspecting the current frame with inspect.currentframe().

  • JsonlLoader now guards its per-line validation-failure warning with self._logger.isEnabledFor(level=logging.WARNING).

  • PickleActorLoader._build_cam_data (now build_cam_data) raises KeyError (previously ValueError) when the 'trajectories' or 'vehicles' key is missing from pickle actor data.

  • Corrected the STEP acronym expansion (“Smart Transportation Evolution Platform” / “Standardized Transport and Environment Protocol” -> “Safer Transport for Europe Platform”) and a step_client -> step_publisher_pkl docstring reference, across module docstrings, README.rst, and doc/source/.

  • Bumped dependencies: step_cloud_schemas to >=2.4.0, step_lib to >=2.0.7, coverage to

    =7.16.1, uv to >=0.12.15; python-dotenv added to the autoflake unused-import allowlist.

1.3.0 - 2026-09-13

1.3.0 - Added

  • New step_publisher_pkl.loaders subpackage: input-file loading is now split into one FileLoader per format (JsonlLoader, PickleActorLoader, PickleCameraLoader, GpxLoader), each raising LoaderError when a file does not match its format so Scenario.load_data() can try the next candidate.

  • Support for GPX track files as a fourth auto-detected input format, converted into CAM messages (new gpx dependency).

  • MQTT broker credentials (MQTT_URL, MQTT_PORT, MQTT_USERNAME, MQTT_PASSWORD) are now read from environment variables (via python-dotenv and a .env file) instead of the persisted JSON configuration, keeping secrets out of stepBroker.mqttClient. New MqttCredential named tuple and _get_mqtt_credential() in __main__.py; new doc/source/env/.env.example.

  • Cooperative shutdown handling: _wait_for_shutdown() and ShutdownRequestedError let _main_async() unwind its TaskGroup and disconnect cleanly on SIGINT/SIGTERM (POSIX) or SIGBREAK (Windows, via WindowsOsShutdownState), or return normally once every publisher task finishes on its own. _main_async() and main() now return an ExitCode instead of None.

  • LoaderError exception, raised by loaders on format mismatch/parse failure.

1.3.0 - Changed

  • Scenario.__init__ now takes an explicit loaders sequence instead of hard-coding the three supported formats internally.

  • StepBroker.__init__ now takes an explicit mqtt_credential: MqttCredential argument instead of reading host/port/username/password from MqttClientConfig; those fields were removed from MqttClientConfig.

  • TLS context creation now uses ssl.create_default_context() with TLSVersion.MAXIMUM_SUPPORTED instead of ssl.SSLContext(PROTOCOL_TLS_CLIENT) pinned to TLSv1_2.

  • Bumped dependencies: numpy to >=2.5.3, pydantic to >=2.13.5, step_cloud_schemas to

    =2.3.2, step_lib to >=2.0.5, plus dev/doc tooling (autoflake, coverage, isort, pylint, ruff, tox, uv, types-docutils, regex).

  • Added python-dotenv as a runtime dependency; setuptools now packages step_publisher_pkl.loaders alongside step_publisher_pkl.
