step_publisher_pkl.step_publisher_pkl_config module

STEP Publisher Pickle Configuration Module.

This module defines the configuration system for the STEP (Standardized Transport and Environment Protocol) Publisher Pickle component. It provides a comprehensive set of Pydantic models that describe the configuration structure with strong typing, validation rules, and schema generation capabilities.

The module is organized in a hierarchical structure, where the top-level StepPublisherPklConfig class contains nested configuration components for different aspects of the system:

  • MQTT Client configuration (connection parameters, security settings)

  • MQTT Protocol configuration (QoS, topic management, session parameters)

  • STEP Broker configuration (for message broker integration)

  • Logging configuration (handlers, levels, formatting)

  • Input pickle files configuration

Each configuration class provides:

  • Type validation and constraints via Pydantic fields

  • Detailed documentation

  • JSON Schema generation for configuration file validation

  • Default values through get_default() static methods

The configuration system is designed to be immutable, with strict validation to prevent configuration errors at runtime. Each component features comprehensive documentation to assist users in understanding the available options and their effects.

MqttQoS config: Enumeration class for MQTT Quality of Service levels.

The MQTT protocol provides three QoS levels for message delivery.

QOS_0

At most once delivery. The message is delivered according to the best efforts of the operating environment. Message loss can occur.

Type:

int

QOS_1

At least once delivery. The message is assured to arrive but duplicates may occur.

Type:

int

QOS_2

Exactly once delivery. The message is assured to arrive exactly once. This is the highest quality of service level and has the highest overhead.

Type:

int
