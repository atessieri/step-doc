STEP Publisher Pickle Config V1 Schema

The STEP Publisher Pickle Config Version 1 Schema defines a comprehensive configuration structure for the STEP Publisher Pickle component. This JSON Schema is automatically generated from Pydantic models and provides strong typing, validation rules, and documentation.

Overview

The STEP Publisher Pickle Configuration is organized hierarchically with the main StepPublisherPklConfig class containing several nested configuration components for different aspects of the system:

  • Base Configuration

    • templateVersion: The version of the template (currently “1”)

    • inputPklFiles: List of paths to the pickle files to read and publish

  • STEP Broker Configuration

    • MQTT Client configuration (connection parameters, security settings)

    • MQTT Protocol configuration (QoS, topic management, session parameters)

    • Cache directory configuration

  • Logging Configuration

    • Log handlers (stream, file, rotating file handlers)

    • Log levels

    • Formatting options

Features and Benefits

  • Type Validation: Strong typing and constraints via Pydantic fields

  • Immutable Design: Configuration is frozen after loading to prevent runtime errors

  • Comprehensive Documentation: Detailed field descriptions and examples

  • Default Values: Sensible defaults provided for all configuration options

  • Strict Validation: Prevents configuration errors before they cause runtime issues

Example

This example is created using JSON Schema version 1. For further information, please refer to the python classes.

Example of the configuration schema:

{
  "templateVersion": "1",
  "inputPklFiles": [
    "./pickle.pkl"
  ],
  "stepBroker": {
    "mqttClient": {
      "host": "localhost",
      "port": 8883,
      "username": "username",
      "password": "password",
      "sslEnable": true,
      "sslClientKeyFile": "/path/to/client.key",
      "sslClientKeyFilePassword": "<password>",
      "sslClientCertFile": "/path/to/client.crt",
      "sslCertRequested": true,
      "sslCaCertsFile": "/path/to/ca_certs_file.crt"
    },
    "mqttProtocol": {
      "sessionExpiry": 0,
      "timeout": 30,
      "keepalive": 600,
      "maxQueuedIncomingMessages": 60,
      "maxQueuedOutgoingMessages": 60,
      "maxInflightMessages": 60,
      "maxConcurrentOutgoingCalls": 60,
      "cleanStart": true,
      "maxSubscriptionQos": 1,
      "subscriptionTopics": [
        {
          "messageType": "CAM",
          "topic": "topic"
        }
      ],
      "publishTopics": [
        {
          "messageType": "CAM",
          "headerTopic": "v2x/cam/264421_4",
          "geohashPrecision": 8,
          "qos": 0
        }
      ]
    },
    "cacheDir": ".cache"
  },
  "log": {
    "handlersConfig": [
      {
        "handler": {
          "handlerType": "file",
          "path": "./log",
          "filenameTrailer": ".log",
          "append": true
        },
        "level": "INFO",
        "format": "%(asctime)s.%(msecs)03d [%(levelname)s][pid=%(process)d][module=%(module)s][function=%(funcName)s]: %(message)s",
        "dateFormat": "%Y-%m-%d %H:%M:%S"
      }
    ],
    "globalLevel": "INFO"
  }
}
