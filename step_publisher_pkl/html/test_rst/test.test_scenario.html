test.test_scenario module

Test module for step_publisher_pkl scenario functionality.

This module contains unit tests for the Scenario class and the TimeReference NamedTuple defined in step_publisher_pkl.scenario. It validates vehicle trajectory loading from JSONL files, pickle “actor” (vehicle trajectory) files, and pickle “camera” (CPM) files, scenario-to-real time conversion for CAM, CPM, and DENM messages, and the generator-based vehicle/message iteration API.

Key test areas:

  • TimeReference: Validates the NamedTuple’s fields and immutability.

  • Scenario: File-format detection (JSONL, pickle actor, pickle camera), pickle structure validation, JSONL/pickle loading, dictionary-to-CamDataV1 conversion, scenario-to-real time conversion for every supported message type, and the public load_data/get_vehicle_ids/pop_message API.

The tests use real temporary JSONL and pickle files (via pytest’s tmp_path fixture) for file-format detection and loading, and real Pydantic model instances (via each schema class’s get_default()) for time-conversion logic, keeping the suite close to the actual runtime behavior instead of over-mocking.

test__load_from_jsonl_file_unsupported_message_type(mocker: MockerFixture, tmp_path: Path) → None[source]

Test the defensive case _: branch reached when a validated root is neither CamDataV1, CpmDataV1, nor DenmDataV1.

This branch cannot be reached through the public API since ItsMessageRoot.root is a discriminated union of exactly those three types; it is reached here by mocking ItsMessageRoot.model_validate_json directly.

Note

As currently written, this branch logs the intended “Skipping unsupported ITS message type” warning but then does raise ValidationError(<None, the warning() return value>), which itself raises TypeError (ValidationError.__new__() requires a line_errors argument) instead of the ValidationError the surrounding except ValidationError clause expects. The TypeError is therefore left uncaught and propagates out of _load_from_jsonl_file. This test documents that current (likely unintended) behavior rather than the gracefully-skipped-line behavior the code appears to intend.

Parameters:

  • mocker (MockerFixture) – The pytest-mock fixture for creating mocks.

  • tmp_path (Path) – Pytest’s temporary directory fixture.

Returns:

None
