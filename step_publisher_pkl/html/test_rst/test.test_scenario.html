test.test_scenario module

Test module for step_publisher_pkl scenario functionality.

This module contains unit tests for the Scenario class and the TimeReference NamedTuple defined in step_publisher_pkl.scenario. It validates loader dispatch (grouping loaders by extension, falling back to every loader for an unknown extension), message storage (blacklist filtering, station queue creation/append), scenario-to-real time conversion for CAM, CPM, and DENM messages, and the generator-based vehicle/message iteration API.

File-format-specific parsing (JSONL, pickle actor, pickle camera) now lives in step_publisher_pkl.loaders and is covered by its own test modules (test_loaders_jsonl_loader.py, test_loaders_pickle_actor_loader.py, test_loaders_pickle_camera_loader.py); this module only exercises Scenario itself, using real FileLoader instances for the load_data integration tests.

Key test areas:

  • TimeReference: Validates the NamedTuple’s fields and immutability.

  • Scenario: Loader-by-suffix grouping, message storage (blacklist/queue handling), scenario-to-real time conversion for every supported message type, and the public load_data/get_vehicle_ids/pop_message API.

The tests use real temporary JSONL and pickle files (via pytest’s tmp_path fixture) for the load_data integration tests, and real Pydantic model instances (via each schema class’s get_default()) for time-conversion logic, keeping the suite close to the actual runtime behavior instead of over-mocking.

test_load_data_no_valid_files(mocker: MockerFixture, tmp_path: Path, log_enabled: bool) → None[source]

Test that load_data logs two warnings and leaves no stations populated when no input file is a valid JSONL, pickle actor, or pickle camera file.

Each per-loader LoaderError is logged at INFO level (not WARNING) as load_data tries the next candidate loader; once every loader has failed for the file, a WARNING that the file “could not be loaded by any available loader” is logged, and a second WARNING for the final “no valid vehicle trajectory data loaded” message fires once all input files have been processed. Both warnings are gated on WARNING being enabled.

Parameters:

  • mocker (MockerFixture) – The pytest-mock fixture for creating mocks.
