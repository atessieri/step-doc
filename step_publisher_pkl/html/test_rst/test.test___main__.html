test.test___main__ module

Test module for __main__ module functionality.

This test suite validates the core functionality of the STEP Publisher Pickle main module, including application startup, configuration management, signal handling, and publisher task execution.

Test Coverage:

  • ExitCode enumeration validation and member values

  • Signal handling and shutdown procedures for cross-platform compatibility

  • Exception handling in asyncio event loops

  • Per-vehicle publisher task execution with scenario-based timing

  • Asynchronous main execution flow, broker connection, and task-group creation

  • Configuration schema and template file generation

  • Command line argument parsing

  • Application lifecycle management including startup and graceful shutdown

The test suite validates both successful execution paths and error conditions to ensure the application behaves predictably under various circumstances.
