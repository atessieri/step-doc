test.facilities.test_cpm_message_v1 module

Test module for CpmMessageV1 class implementation.

This module contains comprehensive unit tests for the CpmMessageV1 class, which handles Collective Perception Messages (CPM) in vehicular communications. The tests verify the correct handling and processing of CPM messages across different formats and operations.

Key test areas include:

  • Message initialization and validation

  • Format conversions (ASN.1, ORM, dict, JSON)

  • Message properties and attributes

  • Station ID modifications

  • Error handling for invalid inputs

  • Message source identification

  • Reference position extraction

  • Schema validation

The module provides fixtures for:

  • ASN.1 message format

  • ORM message objects

  • Dictionary representations

These tests ensure reliable processing and transformation of CPM messages throughout the system’s message handling pipeline, maintaining data integrity across different message formats and operations.

Note

The perceived objects’ position field travels through a lossy cartesian ASN.1 round trip (see PerceivedObject.to_asn/from_asn in step_cloud_schemas), so message_asn below is not a hand-computed set of “nice” raw integers: it is the authoritative output of CpmMessageV1(message=message_orm).to_asn(), verified to round-trip back to an equal (to_dict()-equal) message before being copied into this fixture. See the module docstring of test_denm_message_v1.py for the same convention on the DENM side.

Complexity:

  • - Time – O(1) per test, since each test constructs a fixed, small number of objects and performs a constant number of assertions.

  • - Space – O(1) per test, since only a fixed number of objects and fixtures are held.
