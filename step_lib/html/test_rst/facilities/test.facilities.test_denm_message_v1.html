test.facilities.test_denm_message_v1 module

Test module for the DenmMessageV1 class.

This module contains the test suite for validating the functionality of the DenmMessageV1 class, which handles Decentralized Environmental Notification Messages (DENM) in vehicular communications.

The test suite covers:

  • Message initialization and validation

  • Data format conversions (ASN.1, ORM, Dictionary, JSON)

  • Message property access and manipulation

  • Station ID modifications

  • Error handling for invalid operations

The tests use fixtures to provide sample DENM messages in various formats:

  • ASN.1 structured dictionary

  • ORM (DenmDataV1) objects

  • Python dictionaries

  • JSON strings

Each test case validates specific aspects of the DenmMessageV1 class to ensure proper handling of DENM messages throughout the STEP library ecosystem.

Complexity:

  • - Time – O(1) per test, since each test constructs a fixed, small number of objects and performs a constant number of assertions.

  • - Space – O(1) per test, since only a fixed number of objects and fixtures are held.

test_to_asn(message_orm: DenmDataV1) → None[source]

Test that a DenmMessageV1 object is correctly converted to an ASN.1 dictionary using the to_asn method.

The comparison is made via a round trip (from_asn(to_asn(x))) rather than against a hand-authored ASN.1 dictionary: several fields (position confidence, speed) use ETSI ASN.1 wire encodings that are not perfectly linear, so a freshly encoded dictionary can differ from a hand-authored one by a rounding step even though both decode back to an equal (to_dict()-equal) message (see the message_orm fixture docstring for the same convention on the decode side).
