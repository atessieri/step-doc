test.test_sync_com_manager module

Unit tests for the sync_com_manager module.

This module contains comprehensive unit tests for the synchronous, thread-based MQTT communication management classes defined in step_lib.sync_com_manager, including:

  • SyncComManagerParams: Configuration parameters for the synchronous communication manager

  • ConnectionStatus: Connection status enumeration

  • SyncComManager.Command: Base class for internal queue commands

  • SyncComManager.ExitThreadsCommand: Command used to terminate background threads

  • SyncComManager.SubscribeCommand: Command used to request a topic subscription

  • SyncComManager.PublishMessageCommand: Command used to request a message publish

  • SyncComManager: Thread-based synchronous MQTT communication manager

Test coverage includes initialization, attribute assignment, slot definitions, the context-manager protocol, start/stop lifecycle handling, subscribe/publish dispatch, the background thread’s command loop and reconnection logic, and correct delegation to the underlying AsyncComManager collaborator (mocked throughout, with one deliberate exception: test_stop_during_reconnect_does_not_hang_or_raise_unexpectedly runs a real background Thread and a real asyncio event loop, since the race it guards against can only be observed with genuine cross-thread timing rather than a mocked loop/thread).

Complexity:

  • - Time – O(1) for most tests, which perform a fixed, constant number of mocked calls or assertions; O(n) for test_message_receive_thread and its nested async_message_generator, where n is message_count, and for test_subscribe_command_exec, where n is the length of topics.

  • - Space – O(1) for most tests, holding only a fixed number of local references; O(n) for the tests listed above, proportional to message_count or len(topics).
