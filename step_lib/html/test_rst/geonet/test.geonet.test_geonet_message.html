test.geonet.test_geonet_message module

Test module for the GeoNet Message container implementation.

This module contains unit tests for the GeonetMessage class defined in step_lib.geonet.geonet_message, which composes the BasicHeader, CommonHeader, and ExtendedHeader wire structures into the complete GeoNetworking packet as specified in ETSI TS 103 836-4-1 V2.1.1.

Key test areas include:

  • Byte-exact serialization as the concatenation of the three headers

  • Deserialization and round-trip parsing (from_byte_stream(to_bytes(x)) == x) for SingleHopBroadcast, GeoUnicastPacket, and GeoAnycastBroadcast payloads

  • The creation_time property delegating to the extended header

  • Error propagation from BasicHeader, CommonHeader, and ExtendedHeader parsing failures (unsupported field values, truncated streams)

Note

ExtendedHeader._sequence_sender is a mutable class-level counter shared across the whole test session. Tests involving GeoUnicastPacket and GeoAnycastBroadcast (whose serialization increments this counter) read its value immediately before serializing instead of assuming a fixed starting value, so they remain correct regardless of test execution order.

Complexity:

  • - Time – O(1) per test, since each test constructs/serializes/deserializes a single GeonetMessage built from a fixed, constant number of fixed-size header components and performs a fixed number of assertions.

  • - Space – O(1) per test, since each test holds only a fixed number of header/message objects and byte buffers of fixed size.
