Position Message
================

Position messages carry a single GNSS position fix reported by a station: the time of the
fix, the latitude and longitude, and, when available, the altitude, the speed, the bearing
and the horizontal accuracy of the fix. Unlike the ETSI messages (CAM, CPM, DENM), the
position message is a STEP message: speed and accuracy are raw GNSS measurements and are
not clamped to the ETSI ranges, so that a poor fix is never reported as a good one.

``step_lib`` derives one position message from every CAM it publishes and sends it to its
own MQTT topic, keyed by station id rather than by geohash; the mechanism is described in
:doc:`../position_data_topic`.
