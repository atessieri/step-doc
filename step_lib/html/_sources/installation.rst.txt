============
Installation
============

STEP Lib works on Windows, Linux and MacOS. Please follow the instructions below
to build and run an example in your specific environment.

------------------------------
Installing from git repository
------------------------------

The command to install the library is:

.. code-block:: bash

   $pip install --extra-index-url https://gitlab.automotive.vodafone.com/api/v4/projects/956/packages/pypi/simple step_lib
