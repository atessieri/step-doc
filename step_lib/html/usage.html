STEP Connection Guide

This guide explain how to use the STEP Library to communicate to STEP broker using both asynchronous (Coroutine) and synchronous (Non-blocking) approaches.

Prerequisites

Before using STEP Library, ensure you have:

  • Python 3.11 or higher

  • STEP Library installed

  • Valid STEP broker credentials

Basic Concepts

The main features of the STEP Library include:

  1. Publish ITS Etsi messages to the broker (STEP).

  2. Subscribe to the specific topics in order to receive ITS Etsi messages.

The library supports CAM, CPM and DENM messages.

The library provides two main approaches for MQTT communication:

  1. Synchronous (Non-blocking) using SyncComManager

  2. Asynchronous (Coroutine) using AsyncComManager

It is recommended to provide a cache folder during the initialization of the library for performance reason. This folder is used to store the ASN.1 information used during the parsing of the messages. No any part of the message is stored in the cache folder.

The information in the message is encapsulated and passed to the library using:

  1. The class

  2. A dictionary

  3. A JSON string

The communication session is managed with or without the context manager.

Synchronous Usage

The synchronous Non-blocking approach uses an transfer thread that manages the communication. The library create a message FIFO queue to avoid any block due to transmission / reception delay.

Configuration

The following snippet explains how to create the data-class of parameters.

import logging
import ssl

from aiomqtt import TLSParameters
from step_cloud_schemas import MessageId
from step_lib import MqttQoS, PublishTopicParams, SyncComManagerParams

def create_sync_com_manager_params(logger: logging.Logger) -> SyncComManagerParams:
    tls_params = TLSParameters(
        ca_certs=None,
        certfile=None,
        keyfile=None,
        cert_reqs=ssl.VerifyMode.CERT_REQUIRED,
        tls_version=ssl.PROTOCOL_TLSv1_2,
        ciphers=None,
        keyfile_password=None,
    )
    return SyncComManagerParams(
        instance_name="step_lib_test_1",
        host="step.example.com",
        port=8883,
        username="your_username",
        password="your_password",
        station_id=123,
        timeout=10,
        keepalive=30,
        bind_address="",
        bind_port=0,
        clean_start=True,
        queue_type=None,
        max_queued_incoming_messages=60,
        max_queued_outgoing_messages=60,
        max_inflight_messages=60,
        max_concurrent_outgoing_calls=60,
        tls_context=None,
        tls_params=tls_params,
        proxy=None,
        socket_options=None,
        session_expiry=0,
        receive_maximum=10,
        maximum_packet_size=4096,
        topic_alias_maximum=0,
        publish_topics_params=[
            PublishTopicParams(
                message_type=MessageId.CAM_PDU,
                header_topic="v2x/cam/264421_4",
                geohash_precision=8,
                qos=MqttQoS.QOS_0,

Using Context Manager (Recommended)

The context manager can manage resource cleanup automatically. So is recommended. The following snippet of code:

  1. Creates a SyncComManager instance (client) managed by Context Manager

  2. Subscribes to the topics

  3. Publishes CAM and CPM messages

  4. Processes the received messages in the queue

from step_cloud_schemas import ItsTime, TrafficParticipantType
from step_lib import (
    CamMessageV1,
    CpmMessageV1,
    GeoNetworkAddress,
    GpsLocation,
    MqttQoS,
    SyncComManager,
)

# Use context manager for automatic resource cleanup
params = create_sync_com_manager_params(logger=logger)
with SyncComManager(params) as client:

    # Subscribe to the topics
    client.subscribe(
        topics=[
            "v2x/cam/264421_4/g8/+/+/+/+/#",
            "v2x/cpm/264421_4/g8/+/+/+/+/#",
            "v2x/denm/264421_4/g8/+/+/+/+/#",
        ],
        max_qos=MqttQoS.QOS_1,
        no_local=True,
    )

    # Address and current position required by publish_its_message
    current_position = GpsLocation(
        time=ItsTime(),
        latitude=50.123456,
        longitude=8.123456,
        accuracy=None,
        speed=None,
        heading=None,
    )
    address = GeoNetworkAddress(
        is_manual_configured=True,
        traffic_participant_type=TrafficParticipantType.PASSENGER_CAR,
        mac_id=123,
    )

    # Publish CAM message
    cam_message = CamMessageV1()  # Create your CAM message
    client.publish_its_message(
        message=cam_message,
        address=address,
        current_position=current_position,
        is_station_mobile=True,
    )

    # Publish CPM message
    cpm_message = CpmMessageV1()  # Create your CPM message
    client.publish_its_message(
        message=cpm_message,
        address=address,
        current_position=current_position,
        is_station_mobile=True,
    )

    # Process received messages
    for message in client.its_messages_received:
        print(f"Received message: {message}")

Note

The no_local field can be:

  • True: The client will not receive messages that it has published.

  • False: The client will receive messages that it has published.

If the no_local field is True, the client isn’t able to use shared subscription.

The context manager can manage resource cleanup automatically. The following snippet of code:

def _async_com_manager_create(
    instance_name: str, station_id: int | None, config: StepBrokerConfig, logger: Logger
) -> AsyncComManager:
    """Create and configure an AsyncComManager instance for MQTT communication.

    This function initializes an AsyncComManager with all necessary parameters derived from
    a StepBrokerConfig object, including TLS settings, connection parameters, and publish topics.

    Args:
        instance_name (str): Unique identifier for this communication manager instance.
        station_id (int | None): Optional station identifier for the communication instance.
        config (StepBrokerConfig): Configuration object containing MQTT client, protocol, and
            cache settings.
        logger (Logger): Logger instance for logging communication events and errors.

    Returns:
        AsyncComManager: A configured AsyncComManager instance ready for MQTT communication.

    Note:
        - TLS parameters are only configured if ``config.mqttClient.sslEnable`` is True.
        - The function uses TLSv1.2 protocol when SSL is enabled.
        - Certificate verification mode depends on ``config.mqttClient.sslCertRequested``.
        - Publish topics are converted from config format to PublishTopicParams if provided.

    Complexity:
        Time: O(p), where p is the number of entries in
            config.mqttProtocol.publishTopics (O(1) when publishTopics is None).
        Space: O(p), for the list of PublishTopicParams built from the configuration.
    """
    tls_params: TLSParameters | None = None
    if config.mqttClient.sslEnable:
        tls_params = TLSParameters(
            ca_certs=config.mqttClient.sslCaCertsFile,
            certfile=config.mqttClient.sslClientCertFile,
            keyfile=config.mqttClient.sslClientKeyFile,
            cert_reqs=(
                VerifyMode.CERT_REQUIRED
                if config.mqttClient.sslCertRequested
                else VerifyMode.CERT_NONE
            ),
            tls_version=ssl.PROTOCOL_TLSv1_2,
            ciphers=None,
            keyfile_password=config.mqttClient.sslClientKeyFilePassword,
        )
    async_com_manager_params = AsyncComManagerParams(
        instance_name=instance_name,
        host=config.mqttClient.host,
        port=config.mqttClient.port,
        username=config.mqttClient.username or "",
        password=config.mqttClient.password or "",
        timeout=config.mqttProtocol.timeout,
        station_id=station_id,
        keepalive=config.mqttProtocol.keepalive,
        bind_address="",
        bind_port=0,
        clean_start=config.mqttProtocol.cleanStart,
        queue_type=None,
        max_queued_incoming_messages=config.mqttProtocol.maxQueuedIncomingMessages,
        max_queued_outgoing_messages=config.mqttProtocol.maxQueuedOutgoingMessages,
        max_inflight_messages=config.mqttProtocol.maxInflightMessages,
        max_concurrent_outgoing_calls=config.mqttProtocol.maxConcurrentOutgoingCalls,
        tls_context=None,
        tls_params=tls_params,
        proxy=None,
        socket_options=None,
        session_expiry=config.mqttProtocol.sessionExpiry,
        receive_maximum=10,
        maximum_packet_size=4096,
        topic_alias_maximum=0,
        publish_topics_params=(
            [
                PublishTopicParams(
                    message_type=MessageId(topic.messageType),
                    header_topic=topic.headerTopic,
                    geohash_precision=topic.geohashPrecision,
                    qos=MqttQoS(topic.qos),
                )
                for topic in config.mqttProtocol.publishTopics
            ]
            if config.mqttProtocol.publishTopics is not None
            else None
        ),
        cache_dir=config.cacheDir,
        logger=logger,
    )
    return AsyncComManager(params=async_com_manager_params)

async def _receive_messages(client: AsyncComManager, logger: Logger) -> None:
    """Asynchronously receives and logs messages from a communication manager.

    This function continuously listens for incoming messages from the provided
    AsyncComManager client and logs them with their QoS level, topic, and payload content.

    Args:
        client (AsyncComManager): The asynchronous communication manager client
            used to receive messages.
        logger (Logger): The logger instance used to log received messages.

    Returns:
        None: This function does not return any value.

    Note:
        This is a long-running coroutine that will continue processing messages
        until canceled or until the client stops yielding messages.

    Complexity:
        Time: O(k), where k is the number of messages received before the
            coroutine is canceled or the client stops yielding messages.
        Space: O(1), each message is logged as it arrives and not retained.
    """
    async for message in client.its_messages:
        if logger.isEnabledFor(level=logging.INFO):
            logger.info(
                msg=f"Message(qos:{message.qos},topic:{message.topic}): {message.its_payload}"
            )


async def _subscribe_execution(
    client: AsyncComManager, config: MqttProtocolConfig, logger: Logger
) -> None:
    """Subscribe to a list of topics with specified MQTT options.

    This method subscribes to a list of topics specified in the configuration
    with the following MQTT options:

        - QoS level from config
        - No local messages (noLocal=True)
        - Do not retain as published (retainAsPublished=False)
        - Do not send retained messages (retainHandling=RETAIN_DO_NOT_SEND)

    Args:
        client (AsyncComManager): The asynchronous communication manager client
            used to perform the subscription.
        config (MqttProtocolConfig): Configuration object containing subscription topics
            and QoS settings.
        logger (Logger): The logger instance used for logging subscription results.

    Raises:
        StepClientExceptionError: If subscription fails or QoS level doesn't match the configured
            one.

    Returns:
        None: This function does not return a value.

    Complexity:
        Time: O(t), where t is the number of entries in config.subscriptionTopics
            (O(1) when subscriptionTopics is None).
        Space: O(t), for the list of subscription tuples built from the configuration.
    """
    if config.subscriptionTopics is not None:
        sub_results = await client.subscribe(
            topic=[
                (
                    topic_param.topic,
                    SubscribeOptions(
                        qos=config.maxSubscriptionQos,
                        noLocal=False,
                        retainAsPublished=False,
                        retainHandling=SubscribeOptions.RETAIN_DO_NOT_SEND,
                    ),
                )
                for topic_param in config.subscriptionTopics
            ]
        )
        if len(sub_results) != len(config.subscriptionTopics):
            raise StepLibError(
                f"Subscription results {len(sub_results)} do not match the number "
                f"of topics {len(config.subscriptionTopics)}."
            )
        for topic_param, result in zip(
            config.subscriptionTopics, sub_results, strict=True
        ):
            if result != config.maxSubscriptionQos:
                raise StepLibError(
                    f"Failed to subscribe to {topic_param.topic}: {result}"
                )
            if logger.isEnabledFor(level=logging.INFO):
                logger.info(msg=f"Subscribed to {topic_param.topic}: {result}")

def _sync_com_manager_create(
    instance_name: str, station_id: int | None, config: StepBrokerConfig, logger: Logger
) -> SyncComManager:
    """Create a synchronous communication manager for STEP broker.

    This function initializes and configures a SyncComManager instance with the provided
    configuration parameters, including MQTT client settings, TLS/SSL options, and protocol
    parameters.

    Args:
        instance_name (str): The name identifier for this communication manager instance.
        station_id (int | None): The station identifier. Can be None if not applicable.
        config (StepBrokerConfig): Configuration object containing MQTT client, protocol,
            and cache directory settings.
        logger (Logger): Logger instance for logging operations and debug information.

    Returns:
        SyncComManager: A configured synchronous communication manager instance ready
            for STEP broker communication.

    Note:
        - TLS/SSL is configured based on config.mqttClient.sslEnable flag
        - When SSL is enabled, certificate verification mode is set based on
          config.mqttClient.sslCertRequested
        - Publish topics are configured from config.mqttProtocol.publishTopics if available
        - Default values are used for bind_address (""), bind_port (0), and various
          MQTT protocol parameters

    Complexity:
        Time: O(p), where p is the number of entries in
            config.mqttProtocol.publishTopics (O(1) when publishTopics is None).
        Space: O(p), for the list of PublishTopicParams built from the configuration.
    """
    tls_params: TLSParameters | None = None
    if config.mqttClient.sslEnable:
        tls_params = TLSParameters(
            ca_certs=config.mqttClient.sslCaCertsFile,
            certfile=config.mqttClient.sslClientCertFile,
            keyfile=config.mqttClient.sslClientKeyFile,
            cert_reqs=(
                VerifyMode.CERT_REQUIRED
                if config.mqttClient.sslCertRequested
                else VerifyMode.CERT_NONE
            ),
            tls_version=ssl.PROTOCOL_TLSv1_2,
            ciphers=None,
            keyfile_password=config.mqttClient.sslClientKeyFilePassword,
        )
    sync_com_manager_params = SyncComManagerParams(
        instance_name=instance_name,
        host=config.mqttClient.host,
        port=config.mqttClient.port,
        username=config.mqttClient.username or "",
        password=config.mqttClient.password or "",
        timeout=config.mqttProtocol.timeout,
        station_id=station_id,
        keepalive=config.mqttProtocol.keepalive,
        bind_address="",
        bind_port=0,
        clean_start=config.mqttProtocol.cleanStart,
        queue_type=None,
        max_queued_incoming_messages=config.mqttProtocol.maxQueuedIncomingMessages,
        max_queued_outgoing_messages=config.mqttProtocol.maxQueuedOutgoingMessages,
        max_inflight_messages=config.mqttProtocol.maxInflightMessages,
        max_concurrent_outgoing_calls=config.mqttProtocol.maxConcurrentOutgoingCalls,
        tls_context=None,
        tls_params=tls_params,
        proxy=None,
        socket_options=None,
        session_expiry=config.mqttProtocol.sessionExpiry,
        receive_maximum=10,
        maximum_packet_size=4096,
        topic_alias_maximum=0,
        publish_topics_params=(
            [
                PublishTopicParams(
                    message_type=MessageId(topic.messageType),
                    header_topic=topic.headerTopic,
                    geohash_precision=topic.geohashPrecision,
                    qos=MqttQoS(topic.qos),
                )
                for topic in config.mqttProtocol.publishTopics
            ]
            if config.mqttProtocol.publishTopics is not None
            else None
        ),
        cache_dir=config.cacheDir,
        logger=logger,
        reconnect_interval=2,
        max_incoming_queue_rooms=60,
        max_outgoing_queue_rooms=60,
    )
    return SyncComManager(params=sync_com_manager_params)

def _subscribe_execution(client: SyncComManager, config: MqttProtocolConfig) -> None:
    """Subscribe to MQTT topics specified in the configuration.

    This function subscribes to all topics defined in the config.subscriptionTopics list
    using the provided MQTT client. Each subscription uses the maximum QoS level specified
    in the configuration and includes subscription options for retain handling.

    Args:
        client (SyncComManager): The MQTT client manager used to subscribe to topics.
        config (MqttProtocolConfig): Configuration object containing subscription topics
            and maximum QoS level for subscriptions.

    Raises:
        StepLibError: If the number of subscription results doesn't match the
            number of topics, or if any subscription fails to achieve the requested QoS level.

    Returns:
        None: This function does not return a value.

    Note:
        - Subscriptions are configured with noLocal=False, retainAsPublished=False,
          and retainHandling set to RETAIN_DO_NOT_SEND.
        - The function logs successful subscriptions at INFO level.

    Complexity:
        Time: O(t), where t is the number of entries in config.subscriptionTopics
            (O(1) when subscriptionTopics is None).
        Space: O(t), for the list of topic strings built from the configuration.
    """
    if config.subscriptionTopics is not None:
        client.subscribe(
            topics=[topic_param.topic for topic_param in config.subscriptionTopics],
            max_qos=MqttQoS(config.maxSubscriptionQos),
            no_local=False,
        )

        for message in client.its_messages_received:
            if logger.isEnabledFor(level=logging.INFO):
                logger.info(msg=f"Message received: {message}")
    finally:
        if client is not None:
            # Start the client
            client.stop()
    if logger.isEnabledFor(level=logging.INFO):
        logger.info(msg=f"Client status: {client.connection_status}")


def sync_test_publish_with_context_manager_with_station_filter(
    instance_name: str,
    sender_latitude: float,
    sender_longitude: float,
    config: StepBrokerConfig,
    logger: Logger,
) -> None:
    """Synchronously test publishing ITS messages using a context manager with station
    filtering.

    This function demonstrates the synchronous publishing of various ITS (Intelligent Transportation Systems)
    messages including CAM (Cooperative Awareness Message) and DENM (Decentralized Environmental Notification Message)
    using a communication manager as a context manager. It publishes messages in both ORM and dictionary formats,
    and logs all received messages.

    Args:
        instance_name (str): The name identifier for the communication manager instance.
        sender_latitude (float): The latitude coordinate of the sender's position.
        sender_longitude (float): The longitude coordinate of the sender's position.
        config (StepBrokerConfig): Configuration object containing broker settings including MQTT protocol details.
        logger (Logger): Logger instance for recording operation information and status updates.

    Returns:
        None: This function does not return a value.

    Example:
        >>> sync_test_publish_with_context_manager_with_station_filter(
        ...     instance_name="test_instance",
        ...     sender_latitude=48.8566,
        ...     sender_longitude=2.3522,
        ...     config=broker_config,
        ...     logger=my_logger,
        ... )

    Note:
        - The function uses station ID 123456789 for both the station identifier and MAC address.
        - Messages are published for a road side unit (RSU) traffic participant type.
        - The function includes a 2-second sleep to simulate other operations and allow message reception.
        - All received ITS messages are logged after the sleep period.
        - The context manager ensures proper connection cleanup after execution.

    Complexity:
        Time: O(p + t + r), where p is the number of publish topics and t the number
            of subscription topics in config (client setup), and r is the number of
            ITS messages received from the broker during the 2-second wait.
        Space: O(p + t + r), for the topic structures built during setup and the
            received messages buffered in client.its_messages_received.
    """
    if logger.isEnabledFor(level=logging.INFO):
        logger.info(msg="Starting sync test with context manager")
    current_position = GpsLocation(
        time=ItsTime(),
        latitude=sender_latitude,
        longitude=sender_longitude,
        accuracy=None,
        speed=None,
        heading=None,
    )
    address = GeoNetworkAddress(
        is_manual_configured=True,
        traffic_participant_type=TrafficParticipantType.ROAD_SIDE_UNIT,
        mac_id=MAC_ID,
    )
    with _sync_com_manager_create(
        instance_name=instance_name, station_id=123456789, config=config, logger=logger
    ) as client:
        if logger.isEnabledFor(level=logging.INFO):
            logger.info(msg=f"Client status: {client.connection_status}")
        _subscribe_execution(client=client, config=config.mqttProtocol)
        # CAM message as ORM
        client.publish_its_message(
            message=_create_cam_orm_message(),
            address=address,
            current_position=current_position,
            is_station_mobile=True,
        )
        # CAM message as DICT
        client.publish_its_message(
            message=CamMessageV1().from_dict(data=_create_cam_dict_message()),
            address=address,
            current_position=current_position,
            is_station_mobile=True,
        )
        # CPM message as ORM
        client.publish_its_message(
            message=_create_cpm_orm_message(),
            address=address,
            current_position=current_position,
            is_station_mobile=True,
        )
        # DENM message as ORM
        client.publish_its_message(
            message=_create_denm_orm_message(),
            address=address,
            current_position=current_position,
            is_station_mobile=True,
        )
        # Simulate other operations
        time_sleep(2)
        # Extract messages received
        for message in client.its_messages_received:
            if logger.isEnabledFor(level=logging.INFO):
                logger.info(msg=f"Message received: {message}")
    if logger.isEnabledFor(level=logging.INFO):
        logger.info(msg=f"Client status: {client.connection_status}")
