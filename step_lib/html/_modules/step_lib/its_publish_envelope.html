  1"""ITS Publish Envelope Module.
  2
  3This module defines the wire format used to hand off a publish request from
  4the caller's process to a publish worker process (see
  5``its_publish_worker_pool.py`` and ``its_publish_worker.py``), over the ZMQ
  6``PUSH``/``PULL`` pipeline described in
  7``step_lib/doc/carla_its_multiprocess_design.md``.
  8
  9The envelope reuses ``step_cloud_schemas.ItsMessageRoot`` (a
 10``pydantic.RootModel[CamDataV1 | CpmDataV1 | DenmDataV1]``) instead of
 11inventing a parallel type registry, and flattens ``GeoNetworkAddress`` and
 12``GpsLocation`` into scalar fields so the whole envelope is a single,
 13self-contained JSON object with no nested re-encoding.
 14
 15Complexity:
 16    - Time: O(1) for envelope construction (a fixed number of fields is
 17      copied); O(n) for from_domain_objects/to_domain_objects and JSON
 18      (de)serialization, where n is the number of fields in the wrapped
 19      facility message.
 20    - Space: O(1) for envelope construction; O(n) for the same operations
 21      as above, mirroring the time complexity.

 24    DomainObjects: The facility message, address, and position
 25    reconstructed from a PublishEnvelope.

 28    the caller's process to a publish worker process.
 29    Complexity: time O(n), space O(n), n = number of fields in the
 30    wrapped facility message (dominated by from_domain_objects,
 31    to_domain_objects, and JSON (de)serialization).

508    def to_domain_objects(self) -> DomainObjects:
509        """Reconstruct the domain objects this envelope was built from.
510
511        Constructs the ``FacilityMessage`` subclass directly from
512        ``self.itsMessage.root`` (mirroring
513        ``step_lib.__main__``'s ``_encode_message`` pattern) rather than via
514        ``from_json``, which is what preserves ``is_custom`` fidelity for
515        CPM messages across the process boundary (``CpmMessageV1.from_json``
516        silently defaults ``is_custom=True``).
517
518        Returns:
519            DomainObjects: The reconstructed facility message, GeoNetworking
520            address, and GPS position.
521
522        Raises:
523            StepLibUnsupportedMessageError: If ``itsMessage.root`` is not
524                one of the supported message types.
525
526        Complexity:
527            - Time: O(1), delegates directly to each concrete
528              ``FacilityMessage`` subclass constructor with the already
529              -validated ``itsMessage.root`` model.
530            - Space: O(1), only the reconstructed message/address/position
531              objects are allocated.
532        """
533        message: FacilityMessage
534        match self.itsMessage.root:
535            case CamDataV1():
536                message = CamMessageV1(message_param=self.itsMessage.root)
537            case DenmDataV1():
538                message = DenmMessageV1(message_param=self.itsMessage.root)
539            case CpmDataV1():
540                message = CpmMessageV1(
541                    message_param=self.itsMessage.root, is_custom=self.isCustom
542                )
543            case _:
544                raise StepLibUnsupportedMessageError(
545                    f"Unsupported message type: {type(self.itsMessage.root).__name__}"
546                )
547        address = GeoNetworkAddress(
548            is_manual_configured=self.addressIsManualConfigured,
549            traffic_participant_type=self.addressTrafficParticipantType,
550            mac_id=self.addressMacId,
551        )
552        current_position = GpsLocation(
553            time=ItsTime.create_from_iso_time(time_str=self.positionTime),
554            latitude=self.positionLatitude,
555            longitude=self.positionLongitude,
556            accuracy=self.positionAccuracy,
557            speed=self.positionSpeed,
558            heading=self.positionHeading,
559        )
560        return DomainObjects(
561            message=message, address=address, current_position=current_position
562        )
