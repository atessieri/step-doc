  15aiomqtt and ItsMessageSerializer components.

  18    - Time: O(1) for most tests, which perform a fixed, constant number of mocked calls

  21      where n is the length of the parametrized message_list, and for the
  22      error-threshold tests, which loop a constant number of times bounded by
  23      MAX_RECEIVE_ERRORS/MAX_TRANSMIT_ERRORS.
