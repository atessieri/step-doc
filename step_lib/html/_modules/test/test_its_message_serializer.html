  72    """Build a complete, real ITS message byte stream (GeoNet + BTP + facility bytes).
  73
  74    This helper constructs a real single-hop broadcast GeonetMessage and a real
  75    BtpMessage, and appends an arbitrary facility payload, so that
  76    ``ItsMessageSerializer.deserialize`` can be exercised against real GeoNetworking
  77    and BTP framing while only the facility layer is mocked.

  81            vector.

  86        destination_port_info (Optional[int]): The BTP destination port info,

  89            standing in for an encoded facility message.

  95        common_NextHeader.BTP_A
  96        if btp_type == BtpMessageType.BTP_A
  97        else common_NextHeader.BTP_B
  98    )
  99    common_header = CommonHeader(
 100        next_header=next_header,
 101        header_type_subtype=HeaderTypeSubtype.SINGLE_HOP,
 102        payload_length_after_geonet=4 + len(facility_payload),
 103    )
