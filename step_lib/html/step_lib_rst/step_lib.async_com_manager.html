step_lib.async_com_manager module

This module provides asynchronous MQTT communication functionality for ITS (Intelligent Transport Systems) messages.

The module implements a custom MQTT client that handles the publishing and receiving of ITS messages through a broker using the MQTT v5 protocol. It includes:

  • MqttQoS: Enumeration for MQTT Quality of Service levels

  • PublishTopicParams: Configuration dataclass for MQTT topic publishing parameters

  • AsyncComManagerParams: Configuration dataclass for the MQTT client settings

  • AsyncComManager: Main class extending aiomqtt.Client with ITS message handling capabilities

The implementation supports:

  • Asynchronous message publishing and subscription

  • Geohash-based topic organization

  • Message serialization and deserialization

  • Configurable QoS levels

  • TLS/SSL security

  • Comprehensive logging

  • Error handling for message processing

Example

>>> async with AsyncComManager(params) as client:
...     await client.publish_its_message(
...         message=message,
...         address=address,
...         current_position=current_position,
...         is_station_mobile=True,
...     )
Complexity:

  • - Time – O(1) for construction of AsyncComManager, ItsMessage, and ItsMessagesIterator, since each stores a fixed, constant number of references and configuration values; O(n) for publishing (publish_its_message) and per-message deserialization (ItsMessagesIterator.__anext__ and its helpers), where n is the number of fields in the facility message (or the length of the raw MQTT payload bytes being serialized or deserialized).

  • - Space – O(1) for the same construction cases, since only a fixed number of references is held; O(n) for the same publish/deserialize operations, mirroring the time complexity.

class step_lib.async_com_manager.ItsMessagesIterator(message_iterator: MessagesIterator, message_serializer: ItsMessageSerializer, logger: Logger)[source]

This class wraps a message iterator from an MQTT client and handles the deserialization of incoming messages into ITS-specific message formats. It implements the asynchronous iterator protocol to allow for convenient iteration over incoming messages in an asynchronous context.

Each iteration returns an ItsMessage object containing both the original MQTT message details and the deserialized ITS payload when available.

async __anext__() → ItsMessage[source]

Retrieve and process the next message from the asynchronous message iterator. This method fetches the next message from the underlying message iterator, attempts to deserialize its payload, and constructs an ItsMessage object. If deserialization is successful, the returned ItsMessage will contain the deserialized payload in its_payload. If an error occurs during deserialization, the error is logged and the message is returned with its original payload.

Returns:

A message container with topic, payload, QoS, retain flag, message ID, properties, and the deserialized ITS payload if successful.

Return type:

ItsMessage

Raises:

StopAsyncIteration – Implicitly when the underlying iterator is exhausted.

Note

This method catches all exceptions during deserialization to ensure the iterator continues functioning even if individual messages cannot be properly deserialized.

Complexity:

  • - Time – O(n), where n is the length of the raw message payload in bytes, amortized across the (typically zero or one) messages that fail to deserialize and are skipped before a valid one is returned.

  • - Space – O(n), where n is the length of the raw message payload in bytes, for the resulting ItsMessage instance.

class step_lib.async_com_manager.MqttQoS(*values)[source]

Bases: IntEnum

Enumeration for MQTT Quality of Service levels.

The MQTT protocol provides three QoS levels for message delivery:

QOS_0

At most once delivery. The message is delivered according to the best efforts of the operating environment. Message loss can occur.

Type:

int

QOS_1

At least once delivery. The message is assured to arrive but duplicates may occur.

Type:

int

QOS_2

Exactly once delivery. The message is assured to arrive exactly once. This is the highest quality of service level and has the highest overhead.

Type:

int

Complexity:

  • - Time – O(1), enum member lookup and comparison are constant-time.

  • - Space – O(1), a fixed, three-member set of integer values.
